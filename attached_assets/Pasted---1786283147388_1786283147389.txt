Нужно доработать просмотр результата конкретного дилера в кабинете руководителя.

## Задача

Когда руководитель открывает:

`Аттестация → дилер → Посмотреть результат`

он должен видеть **тот же полный финальный отчёт Roulette, который видит дилер после ответа на последний вопрос**.

Не создавать отдельный упрощённый отчёт для Manager.

### 1. Показать исходную Roulette

На странице результата загрузить `RouletteExercise` по `assignmentId` и показать исходное игровое поле с:

* winningNumber;
* соседями;
* сериями;
* комплитами;
* комплитом дюжины;
* цветными ставками;
* cash;
* всеми остальными сохранёнными ставками.

Это должны быть именно первоначальные ставки этого дилера.

Ничего заново не генерировать.

Не вызывать Spin.

Не запускать анимацию или звук.

Roulette должна быть read-only:

* без Settings;
* без Spin;
* без изменения ставок.

По возможности переиспользовать существующий Roulette-компонент в read-only/report режиме.

### 2. Ниже показать полный существующий отчёт

После поля Roulette показать тот же отчёт, который дилер видит после завершения вопросов:

* все вопросы;
* ответ дилера;
* правильный ответ;
* верно/ошибка;
* фактические расчёты;
* правильные расчёты;
* существующие пояснения/примеры ошибок.

Сначала найди существующий компонент финального отчёта дилера и **переиспользуй его для Manager**, а не создавай его копию.

Желательно:

```text
Dealer ──┐
         ├─ общий Roulette final report
Manager ─┘
```

### 3. Источники данных

Использовать только сохранённые данные:

```text
TrainingAssignment
        ↓
assignmentId
        ├── RouletteExercise
        └── TrainingResult
```

Не пересчитывать результат заново и не создавать новый Exercise.

Если текущий `TrainingResult` не сохраняет часть данных, необходимых для полного существующего отчёта, аккуратно расширить `TrainingAnswer/TrainingResult` нужными report-данными.

Не сохранять JSX/DOM.

### 4. Проверки

Обязательно:

```text
assignment.trainingTemplateId === templateId
```

Если Exercise отсутствует:
`Исходное игровое поле недоступно.`

Если Result отсутствует:
`Результат аттестации недоступен.`

Если Dealer удалён:
показать `Дилер удалён`, но сам сохранённый отчёт оставить доступным.

### 5. Проверить

Для одного завершённого дилера:

1. открыть результат;
2. увидеть ту же первоначальную Roulette;
3. winningNumber и все ставки совпадают с его Exercise;
4. увидеть полный отчёт со всеми расчётами;
5. refresh ничего не меняет;
6. другой дилер показывает свой Exercise и свой Result.

Не менять генераторы Roulette, Spin, вопросы и `/roulette`.

После выполнения кратко напиши:

* какой компонент отчёта переиспользован;
* как отображается Exercise в read-only;
* пришлось ли расширять TrainingResult;
* подтверждение, что ничего не генерируется заново.
