Необходимо изменить условие появления вопроса:

«Какую общую сумму нужно выставить в поле со ставок "Соседи номера"?»

# Новое условие

Вопрос должен задаваться всегда, если в текущем раунде присутствует хотя бы одна ставка «Соседи номера».

Для появления вопроса достаточно наличия одной или нескольких ставок «Соседи номера».

# Когда вопрос должен задаваться

Вопрос должен появляться в следующих случаях:

- есть одна ставка «Соседи номера»;
- есть несколько ставок «Соседи номера».

Неважно, присутствуют ли при этом:

- цветные фишки;
- кэш;
- комплиты;
- серии.

Наличие любых других ставок не должно влиять на появление этого вопроса.

# Когда вопрос не должен задаваться

Если в текущем раунде отсутствуют ставки «Соседи номера», вопрос необходимо пропустить.

Даже если присутствуют:

- цветные фишки;
- кэш;
- комплиты;
- серии.

# Что нельзя менять

Не менять:

- текст вопроса;
- порядок экзаменационных вопросов;
- алгоритм расчёта суммы;
- правильный ответ;
- генерацию ставок;
- логику остальных вопросов.

Изменить только условие, при котором этот вопрос включается в экзамен.

# Обязательные проверки

Проверить минимум:

1. Есть одна ставка «Соседи номера» — вопрос появляется.

2. Есть несколько ставок «Соседи номера» — вопрос появляется.

3. Есть только ставки «Соседи номера» — вопрос появляется.

4. Есть соседи и серии — вопрос появляется.

5. Есть соседи и цветные фишки — вопрос появляется.

6. Есть соседи и кэш — вопрос появляется.

7. Есть соседи и комплиты — вопрос появляется.

8. Есть все типы ставок одновременно — вопрос появляется.

9. Есть только серии — вопрос не появляется.

10. Есть только цветные фишки — вопрос не появляется.

11. Есть только кэш — вопрос не появляется.

12. Есть только комплиты — вопрос не появляется.

13. Ставок «Соседи номера» нет — вопрос не появляется.

После выполнения кратко сообщи:

- какое условие теперь используется для появления вопроса;
- подтверждение, что достаточно наличия хотя бы одной ставки «Соседи номера»;
- подтверждение, что алгоритм расчёта и правильный ответ не изменялись.
