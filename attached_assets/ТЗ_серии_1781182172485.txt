ЗАДАЧА

Нужно добавить отображение ставок на треке рулетки для четырёх серий:

1. Serie 5/8
2. Orphelins
3. Serie 0/2/3
4. Zero Spiel

Это этап только для отображения ставок на треке.

Расчёт выигрыша по сериям пока НЕ делать.

УСЛОВИЯ ПОЯВЛЕНИЯ СТАВОК

В настройках уже есть параметры:

1. Ставка на "5/8"
2. Ставка на "Orphelins"
3. Ставка на "Seria 0/2/3"
4. Ставка на "Zero Spiel"

Если значение настройки = "Да", после нажатия Spin на соответствующем секторе трека должна появиться фишка серии.

Если значение настройки = "Нет", фишка для этой серии не отображается.

РАСПОЛОЖЕНИЕ ФИШЕК

На треке уже размечены зоны:

* Serie 5/8
* Orphelins
* Serie 0/2/3
* Zero Spiel

Для каждой активной серии нужно определить центральную точку её сектора.

Фишка должна отображаться точно в центре соответствующего сектора.

Важно:

* использовать существующую геометрию и координаты трека;
* не менять размеры трека;
* не менять положение трека;
* не менять сетку;
* не ставить фишки приблизительно вручную, если в проекте уже есть координаты/зоны.

ВНЕШНИЙ ВИД ФИШЕК СЕРИЙ

Фишки серий должны отличаться от обычных фишек на поле.

Требования:

* диаметр примерно в 3 раза больше обычной цветной фишки;
* стиль должен соответствовать текущему дизайну Chicago 1932;
* фишка должна быть поверх трека;
* внутри фишки должно отображаться значение ставки;
* значение должно быть хорошо читаемым.

НОМИНАЛ СТАВКИ СЕРИИ

Для каждой активной серии после каждого Spin нужно случайно генерировать значение.

Правила генерации:

* минимальное значение: 100;
* максимальное значение: 5000;
* значение должно быть кратно 50.

Допустимые значения:

100, 150, 200, 250, ..., 4950, 5000

Недопустимые значения:

125, 177, 333, 4999

Каждая активная серия получает своё отдельное случайное значение.

Пример:

Serie 5/8 = 350
Orphelins = 1200
Serie 0/2/3 = 500
Zero Spiel = 2750

СОХРАНЕНИЕ ДАННЫХ

После Spin нужно сохранить активные ставки трека как отдельные объекты.

Для каждой ставки сохранить:

* тип ставки;
* значение ставки;
* координаты размещения;
* признак, что это ставка трека.

Пример структуры:

type: "SERIE_5_8"
label: "Serie 5/8"
amount: 350
position: { x, y }
source: "TRACK"

type: "ORPHELINS"
label: "Orphelins"
amount: 1200
position: { x, y }
source: "TRACK"

type: "SERIE_0_2_3"
label: "Serie 0/2/3"
amount: 500
position: { x, y }
source: "TRACK"

type: "ZERO_SPIEL"
label: "Zero Spiel"
amount: 2750
position: { x, y }
source: "TRACK"

Сейчас эти данные нужны только для будущей логики.

В расчёте ответа их пока не использовать.

ОГРАНИЧЕНИЯ

* Не менять существующую генерацию фишек на основном поле.
* Не менять проверку ответа по ставкам на поле.
* Не добавлять расчёт выигрыша по сериям.
* Не добавлять соседей номера.
* Не менять настройки.
* Не менять дизайн экрана настроек.
* Не менять размеры и координаты поля рулетки.
* Не менять размеры и координаты трека.
* Не менять уже размеченную сетку.
* Не удалять существующую логику Spin.
* Вносить минимально необходимые изменения.

КРИТЕРИИ ГОТОВНОСТИ

* Если все настройки серий = "Нет", на треке нет фишек серий.
* Если включена только "5/8", появляется только фишка Serie 5/8.
* Если включена только "Orphelins", появляется только фишка Orphelins.
* Если включена только "Seria 0/2/3", появляется только фишка Serie 0/2/3.
* Если включена только "Zero Spiel", появляется только фишка Zero Spiel.
* Если включены несколько серий, отображаются все включённые серии.
* Каждая фишка стоит в центре своего сектора.
* Каждая фишка примерно в 3 раза больше обычной фишки поля.
* Внутри каждой фишки отображается значение от 100 до 5000.
* Значение всегда кратно 50.
* Значение генерируется заново после каждого Spin.
* Ставки серий сохраняются отдельно от обычных ставок поля.
* Ставки серий пока не участвуют в расчёте выплаты.
