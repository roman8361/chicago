ЗАДАЧА

Восстановить проигрывание существующего аудиофайла со звуком падения шарика при нажатии кнопки:

«Spin»

После изменений расположения кнопок звук перестал запускаться.

Нужно снова подключить аудиофайл к актуальному обработчику кнопки Spin.

---

ВАЖНО

У меня уже есть готовый аудиофайл.

Не создавать новый звук.

Не заменять его другим файлом.

Использовать существующий аудиофайл, добавленный в проект.

Если файл ещё не находится в правильной папке статических ресурсов, перенести/подключить его через существующую структуру `assets` или `public`.

---

ТЕКУЩАЯ ПРОБЛЕМА

После переноса кнопок Spin, Настройки и Отладка изменился компонент или обработчик кнопки Spin.

Визуальная анимация может продолжать работать, но звук падения шарика больше не проигрывается.

Вероятная причина:

- новая кнопка Spin не использует старый `handleSpin`;
- вызов `audio.play()` остался в старом компоненте;
- ссылка на аудиофайл стала некорректной;
- `Audio` создаётся заново при каждом render;
- звук запускается не напрямую из пользовательского клика.

Нужно найти фактический обработчик текущей кнопки Spin и подключить звук именно к нему.

---

ОЖИДАЕМЫЙ СЦЕНАРИЙ

После клика по кнопке Spin:

1. Проверить, что Spin ещё не запущен.
2. Заблокировать повторное нажатие.
3. Сразу запустить аудиофайл.
4. Одновременно запустить существующую анимацию вращения рулетки.
5. Подождать 2 секунды.
6. Завершить анимацию.
7. Запустить существующую генерацию нового раунда.
8. Показать выпавший номер и ставки.
9. Разблокировать Spin согласно существующей логике.

---

СИНХРОНИЗАЦИЯ

Звук и анимация должны начинаться одновременно непосредственно после клика.

Длительность:

2000 ms

Генерация и показ нового раунда должны происходить только после завершения двухсекундной фазы Spin.

Не добавлять отдельную задержку после звука.

---

ПОДКЛЮЧЕНИЕ АУДИО

Использовать стабильный экземпляр аудио, который не создаётся заново при каждом render.

Для React предпочтительно использовать:

- `useRef<HTMLAudioElement>`;
- либо один `<audio>`-элемент;
- либо импорт аудиофайла с сохранением объекта в ref.

Пример направления реализации:

```ts
const spinAudioRef = useRef<HTMLAudioElement | null>(null);

useEffect(() => {
  spinAudioRef.current = new Audio(spinSound);
  spinAudioRef.current.preload = "auto";

  return () => {
    spinAudioRef.current?.pause();
    spinAudioRef.current = null;
  };
}, []);

Не копировать пример вслепую, если в проекте уже существует рабочий audio-компонент. Лучше восстановить и переиспользовать существующую реализацию.

ЗАПУСК ЗВУКА

В актуальном handleSpin:

const audio = spinAudioRef.current;

if (audio) {
  audio.pause();
  audio.currentTime = 0;

  void audio.play().catch((error) => {
    console.warn("Не удалось воспроизвести звук Spin", error);
  });
}

Важно:

запускать play() непосредственно в цепочке клика пользователя;
перед каждым новым Spin сбрасывать currentTime = 0;
не включать loop;
не запускать несколько копий звука одновременно.

АКТУАЛЬНАЯ КНОПКА SPIN

Проверить, что центральная кнопка Spin над игровым полем вызывает именно единый обработчик:

handleSpin

Не должно быть:

старой скрытой кнопки с обработчиком звука;
новой кнопки с отдельным обработчиком без звука;
двух разных функций запуска Spin;
дублирования генерации.

Все действия Spin должны запускаться из одной функции.

ПОРЯДОК ВНУТРИ ОБРАБОТЧИКА

Рекомендуемый порядок:

handleSpin
→ защита от повторного клика
→ isSpinning = true
→ запуск звука
→ запуск анимации
→ ожидание 2000 ms
→ generateRound()
→ isSpinning = false

Не запускать generateRound() до завершения ожидания.

ЗАЩИТА ОТ ПОВТОРНЫХ КЛИКОВ

Пока идёт Spin:

кнопка должна быть disabled;
повторный клик не должен запускать звук сначала;
не должен создаваться второй таймер;
не должен генерироваться второй раунд.

Использовать существующую защиту isSpinning.

Если быстрые двойные клики успевают пройти до обновления React state, дополнительно использовать синхронный ref-lock.

ОБРАБОТКА ОШИБКИ

Если браузер по какой-либо причине не воспроизвёл звук:

приложение не должно падать;
анимация должна продолжиться;
через 2 секунды должен сгенерироваться раунд;
ошибку можно записать в console.

Звук не должен блокировать бизнес-логику Spin.

ПРОВЕРИТЬ ПУТЬ К ФАЙЛУ

Убедиться, что путь к аудиофайлу корректен в production-сборке Replit.

Если используется импорт:

import spinSound from "...";

проверить, что файл действительно включается в сборку.

Если файл находится в public, использовать корректный абсолютный путь от корня приложения.

Не использовать локальный путь файловой системы компьютера.

ПРЕДЗАГРУЗКА

Добавить:

preload="auto"

или эквивалентную предварительную загрузку, чтобы при первом Spin не было задержки перед звуком.

ОЧИСТКА

При размонтировании компонента или уходе со страницы:

остановить аудио;
очистить таймер Spin;
не обновлять состояние размонтированного компонента.

НЕ МЕНЯТЬ UI

Не возвращать старое расположение кнопок.

Кнопки должны остаться:

над основным полем;
по центру экрана;
в порядке Spin → Настройки → Отладка.

Задача относится только к восстановлению звука и его синхронизации с существующей анимацией Spin.

ОГРАНИЧЕНИЯ

Не менять файл звука.
Не менять длительность Spin — 2 секунды.
Не менять анимацию рулетки, если она уже работает.
Не менять генерацию ставок.
Не менять вопросы дилера.
Не менять расчёты.
Не менять rouletteRules.json.
Не создавать второй обработчик Spin.
Не запускать новый раунд до завершения анимации.

КРИТЕРИИ ГОТОВНОСТИ

При клике Spin сразу запускается существующий звук падения шарика.
Одновременно запускается анимация рулетки.
Звук проигрывается один раз.
Повторный быстрый клик не создаёт несколько звуков.
Новые ставки не появляются до завершения двух секунд.
Через 2 секунды появляется новый раунд.
При ошибке воспроизведения Spin всё равно завершается.
Центральная кнопка Spin использует единый актуальный обработчик.
Звук работает после production-сборки Replit.
