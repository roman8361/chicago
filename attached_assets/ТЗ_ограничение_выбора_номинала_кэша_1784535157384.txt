ЗАДАЧА

В разделе «Настройки» для параметра:

«Номинал кэша на поле»

нужно ограничить количество одновременно выбранных номиналов.

Пользователь должен иметь возможность выбрать:

- минимум 1 номинал;
- максимум 2 разных номинала.

Выбрать 3 и более номинала нельзя.

---

ТЕКУЩИЕ НОМИНАЛЫ

Сохранить существующий список доступных номиналов:

- 10;
- 25;
- 50;
- 100.

Не менять значения, порядок и внешний вид элементов без необходимости.

---

ОСНОВНОЕ ПОВЕДЕНИЕ

Если сейчас выбрано 0 номиналов:

- пользователь может выбрать любой номинал.

Если сейчас выбран 1 номинал:

- пользователь может выбрать ещё один номинал;
- выбранный номинал можно снять.

Если сейчас выбрано 2 номинала:

- остальные невыбранные номиналы должны стать недоступными для выбора;
- два уже выбранных номинала должны оставаться активными;
- пользователь должен иметь возможность снять один из выбранных номиналов;
- после снятия одного значения остальные номиналы снова становятся доступными.

---

ПРИМЕР

Изначально выбран:

100

Пользователь выбирает:

50

Результат:

[50, 100]

После этого номиналы:

10 и 25

нельзя выбрать, пока пользователь не снимет один из выбранных номиналов.

Если пользователь снимает:

50

остаётся:

[100]

После этого снова можно выбрать:

10, 25 или 50.

---

ОГРАНИЧЕНИЕ ДОЛЖНО РАБОТАТЬ В UI

Когда выбрано 2 номинала, невыбранные чекбоксы должны визуально переходить в состояние `disabled`.

Не просто игнорировать третий клик.

Пользователь должен сразу видеть, что лимит достигнут.

Для недоступного номинала:

- запретить клик;
- применить существующий стиль `disabled`;
- сохранить читаемость текста;
- не скрывать номинал;
- не снимать автоматически ранее выбранные значения.

---

НЕ ЗАМЕНЯТЬ ВЫБОР АВТОМАТИЧЕСКИ

При попытке выбрать третий номинал нельзя:

- автоматически снимать первый выбранный номинал;
- автоматически снимать последний выбранный номинал;
- заменять один номинал другим;
- сбрасывать весь выбор.

Пользователь должен сначала самостоятельно снять один из двух выбранных номиналов.

---

МИНИМУМ ОДИН НОМИНАЛ

Не разрешать снять последний выбранный номинал.

Если выбран только один номинал, его чекбокс должен оставаться выбранным и недоступным для снятия либо клик по нему должен быть проигнорирован.

Предпочтительный вариант:

- визуально оставить чекбокс активным;
- при попытке снять последний номинал не менять состояние;
- при необходимости показать короткую подсказку:

«Необходимо выбрать хотя бы один номинал».

Не использовать браузерный `alert`.

Если в проекте уже есть toast или inline-валидация, использовать её.

---

ЛОГИКА ОБРАБОТЧИКА

Рекомендуемая логика:

```ts
const toggleCashDenomination = (value: number) => {
  const isSelected = selectedCashDenominations.includes(value);

  if (isSelected) {
    if (selectedCashDenominations.length === 1) {
      return;
    }

    setSelectedCashDenominations(
      selectedCashDenominations.filter(item => item !== value)
    );

    return;
  }

  if (selectedCashDenominations.length >= 2) {
    return;
  }

  setSelectedCashDenominations([
    ...selectedCashDenominations,
    value
  ]);
};

Названия переменных и функций адаптировать под текущий проект.

ЛОГИКА DISABLED

Для каждого номинала:

const isSelected = selectedCashDenominations.includes(value);

const isDisabled =
  !isSelected &&
  selectedCashDenominations.length >= 2;

Таким образом:

выбранные значения не блокируются;
невыбранные блокируются только после достижения лимита;
пользователь может снять один из выбранных номиналов.

ВАЛИДАЦИЯ ДАННЫХ

Ограничение должно работать не только на уровне UI.

При чтении настроек из:

localStorage;
сохранённого состояния;
импортированного JSON;
старой версии настроек;

нужно нормализовать массив номиналов.

Если в сохранённых данных больше 2 значений:

оставить только первые 2 валидных уникальных номинала;
остальные удалить.

Если после фильтрации не осталось ни одного валидного номинала:

использовать текущее значение по умолчанию проекта;
если оно не определено — использовать [100].

НОРМАЛИЗАЦИЯ

Разрешённые значения:

const allowedCashDenominations = [10, 25, 50, 100];

Пример нормализации:

const normalizeCashDenominations = (
  values: unknown
): number[] => {
  if (!Array.isArray(values)) {
    return [100];
  }

  const normalized = Array.from(
    new Set(
      values.filter(
        (value): value is number =>
          typeof value === "number" &&
          allowedCashDenominations.includes(value)
      )
    )
  ).slice(0, 2);

  return normalized.length > 0
    ? normalized
    : [100];
};

Не дублировать список номиналов, если он уже существует в одном общем месте проекта.

СОХРАНЕНИЕ НАСТРОЕК

После изменения выбора сохранить существующий механизм:

обновление React state;
сохранение в localStorage;
применение при новом Spin;
сброс настроек;
восстановление настроек при перезагрузке.

Не менять формат хранения без необходимости.

СБРОС НАСТРОЕК

При нажатии «Сбросить настройки»:

восстановить существующий дефолтный номинал или набор номиналов;
убедиться, что в дефолтном наборе не больше 2 значений;
интерфейс должен сразу корректно обновить состояния checked и disabled.

ГЕНЕРАЦИЯ КЭШ-СТАВОК

Не менять существующую логику генерации кэш-фишек.

Генератор должен продолжать:

использовать только выбранные номиналы;
использовать оба номинала, если выбрано 2;
использовать один номинал, если выбран 1;
приблизительно равномерно распределять количество фишек между двумя номиналами;
подбирать сумму максимально близко к указанному кэшу;
не ставить две физические кэш-фишки на одну позицию;
не пересекать позиции кэш-фишек и цветных фишек;
обеспечивать минимум одну выигрышную кэш-ставку.

Меняется только максимально допустимое число выбранных номиналов.

НЕ МЕНЯТЬ

список номиналов;
дизайн раздела настроек;
расчёт общей суммы кэша;
алгоритм размещения кэш-фишек;
цвета кэш-фишек;
отображение номинала на фишке;
правила выигрыша;
итоговую выплату.

КРИТЕРИИ ГОТОВНОСТИ

Пользователь может выбрать один номинал.
Пользователь может выбрать два номинала.
Выбрать третий номинал невозможно.
После выбора двух номиналов остальные чекбоксы становятся disabled.
Выбранные чекбоксы можно снимать.
После снятия одного номинала остальные снова доступны.
Последний выбранный номинал снять нельзя.
После перезагрузки сохраняется максимум два номинала.
Старые настройки с тремя и более номиналами автоматически нормализуются.
Генерация кэш-ставок продолжает работать по прежним правилам.
