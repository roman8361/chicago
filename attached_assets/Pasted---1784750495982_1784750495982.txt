2. Какие данные участвуют в расчёте

Перечисли, какие данные используются при проверке ответа:

- какие серии находятся на треке;
- какие суммы поставлены на серии;

3. Алгоритм проверки по этапам

Опиши фактический алгоритм приложения последовательно и понятным языком.

Используй формат:

Шаг 1. ...
Шаг 2. ...
Шаг 3. ...

Обязательно объясни:

- как отдельно обрабатывается каждая серия;
- как определяется сумма на одну часть серии;
- как применяется кратность приёма;
- в какую сторону округляется значение;
- как рассчитывается сдача по каждой серии;
- как получается общая сдача;
- как итог сравнивается с ответом аттестуемого.

Не придумывай предполагаемый алгоритм. Опиши именно ту проверку, которая сейчас реализована в приложении.

4. Подробный пример с цифрами

Приведи один понятный пример, в котором участвуют несколько серий.

Для каждой серии покажи:

- исходную сумму;
- количество частей;
- результат деления;
- установленную кратность;
- по сколько фактически играет каждая часть;
- общую принятую сумму;
- получившуюся сдачу.

После этого сложи сдачу по всем сериям и покажи итоговую общую сдачу.

Пример должен полностью соответствовать фактическому алгоритму приложения.

Объясни:
