ЗАДАЧА

Исправить экран:

«Отчёт по раунду»

Сейчас при открытии отчёта ставки на треке исчезают.

Нужно сделать так, чтобы на экране отчёта поле рулетки И трек полностью отображались в первоначальном состоянии — точно так же, как сразу после завершения Spin.

---

ТЕКУЩАЯ ПРОБЛЕМА

Основное поле может восстанавливаться частично, но ставки на треке:

- Serie 5/8;
- Orphelins;
- Serie 0/2/3;
- Zero Spiel;
- ставки «Соседи номера»;

удаляются или скрываются к моменту открытия отчёта.

Причина, вероятно, в том, что компонент трека продолжает использовать текущее состояние раунда, которое меняется или очищается во время опроса дилера.

---

ГЛАВНОЕ ТРЕБОВАНИЕ

На экране:

«Отчёт по раунду»

нужно показывать точную копию всего игрового состояния, которое существовало сразу после Spin:

- все первоначальные ставки на основном поле;
- все первоначальные ставки на треке;
- все серии;
- все соседи;
- все комплиты;
- весь цвет;
- весь кэш;
- выпавший номер.

Ничего из первоначально сгенерированного не удалять.

---

ОТДЕЛЬНЫЙ SNAPSHOT ТРЕКА

Добавить отдельный неизменяемый snapshot данных трека, например:

initialTrackSnapshot

В него сразу после генерации раунда сохранить:

- generatedSeriesBets;
- generatedNeighbourBets;
- все суммы ставок серий;
- номера ставок соседей;
- суммы ставок соседей;
- координатные/визуальные данные, если компонент трека их требует.

Snapshot должен создаваться сразу после Spin, до начала опроса дилера и до любых преобразований.

---

ОТДЕЛЬНЫЙ SNAPSHOT ПОЛЯ

Также сохранить первоначальное состояние основного поля, например:

initialFieldSnapshot

В него должны входить:

- colorBets;
- cashBets;
- numberCompleteBets;
- dozenCompleteBet;
- winningNumber;
- другие данные, нужные для первоначального отображения.

---

НЕ ИСПОЛЬЗОВАТЬ ОБЩИЕ ССЫЛКИ

Нельзя делать так:

initialTrackSnapshot = currentTrackState

если затем `currentTrackState` мутируется.

Нужно создать независимую глубокую копию.

Проверить, что массивы и вложенные объекты не разделяют ссылки с текущим состоянием.

---

ИСТОЧНИК ДАННЫХ НА ЭКРАНЕ ОТЧЁТА

При открытии экрана «Отчёт по раунду» компоненты должны получать данные только из snapshot.

Для поля:

fieldData = initialFieldSnapshot

Для трека:

trackData = initialTrackSnapshot

Не использовать в отчёте:

- текущие серии;
- текущих соседей;
- очищенный track state;
- filteredTrackBets;
- activeWinningTrackBets;
- данные последнего вопроса.

---

ВАЖНО

Не восстанавливать ставки через повторную генерацию.

Не выполнять random заново.

Не пытаться вычислить первоначальный трек из текущего состояния.

Использовать только snapshot, сохранённый сразу после Spin.

---

ПРОВЕРИТЬ УСЛОВНЫЙ РЕНДЕРИНГ ТРЕКА

Найти условия, которые могут скрывать ставки трека на экране отчёта.

Например:

- currentQuestion;
- isFinalPayoutStep;
- showOnlyWinningBets;
- isRoundReport;
- filteredSeries;
- filteredNeighbours;
- activeTrackBets.length === 0.

На экране отчёта эти фильтры не должны удалять первоначальные ставки.

Если:

isRoundReport === true

компонент трека должен рендерить полный snapshot без фильтрации.

---

РЕКОМЕНДУЕМАЯ ЛОГИКА

Пример:

const displayedSeriesBets = isRoundReport
  ? initialTrackSnapshot.seriesBets
  : currentSeriesBets;

const displayedNeighbourBets = isRoundReport
  ? initialTrackSnapshot.neighbourBets
  : currentNeighbourBets;

const displayedFieldBets = isRoundReport
  ? initialFieldSnapshot
  : currentFieldState;

---

НЕ ОЧИЩАТЬ SNAPSHOT

При переходе на отчёт запрещено:

- очищать initialTrackSnapshot;
- заменять его пустым массивом;
- фильтровать только выигравшие серии;
- фильтровать только выигравших соседей;
- удалять ставки с трека;
- применять финальное очищение поля.

Snapshot очищается только при запуске нового Spin.

---

НОВЫЙ SPIN

При новом Spin:

1. Очистить snapshot старого раунда.
2. Сгенерировать новый раунд.
3. Сохранить новое исходное состояние поля.
4. Сохранить новое исходное состояние трека.
5. Начать новый опрос.

---

ПРОВЕРКА НА КОНКРЕТНОМ СЦЕНАРИИ

После Spin на треке появились:

- Serie 5/8 = 600;
- Orphelins = 350;
- Соседи 20 = 150;
- Соседи 31 = 200.

Во время опроса часть ставок была скрыта или преобразована.

После открытия «Отчёт по раунду» на треке снова должны отображаться:

- Serie 5/8 = 600;
- Orphelins = 350;
- Соседи 20 = 150;
- Соседи 31 = 200.

Точно на тех же позициях и с теми же суммами, что сразу после Spin.

---

ОГРАНИЧЕНИЯ

- Не менять генерацию ставок.
- Не менять расчёты.
- Не менять вопросы дилера.
- Не менять rouletteRules.json.
- Не делать повторный Spin при открытии отчёта.
- Не использовать финальное очищенное состояние для отчёта.
- Не менять дизайн трека.

---

КРИТЕРИИ ГОТОВНОСТИ

- На экране «Отчёт по раунду» отображается полный первоначальный трек.
- Все серии остаются видимыми.
- Все ставки соседей остаются видимыми.
- Суммы и позиции совпадают с состоянием сразу после Spin.
- Проигравшие ставки также отображаются.
- На основном поле также показаны первоначальные ставки.
- Во время открытия отчёта ничего не генерируется заново.
- Snapshot текущего раунда очищается только при новом Spin.
