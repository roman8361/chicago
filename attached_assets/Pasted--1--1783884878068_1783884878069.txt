ЗАДАЧА

В разделе настроек:

“Цвет / Кэш”

добавить два новых числовых поля:

1. “Количество номеров с цветом”
2. “Количество номеров с кэшем”

---

ЗНАЧЕНИЯ ПО УМОЛЧАНИЮ

Для обоих полей значение по умолчанию:

1

При первом запуске приложения должны отображаться:

Количество номеров с цветом = 1

Количество номеров с кэшем = 1

При нажатии кнопки сброса настроек оба поля также должны возвращаться к значению:

1

---

ТИП ПОЛЕЙ

Использовать числовые поля ввода.

Разрешать только целые неотрицательные числа.

Минимальное значение:

0

Запретить:

- отрицательные значения;
- дробные значения;
- символ минус;
- вставку отрицательного значения через copy/paste.

Использовать:

min="0"
step="1"

Также применить существующую в проекте защиту числовых полей от отрицательных значений.

---

ХРАНЕНИЕ В НАСТРОЙКАХ

Добавить два отдельных поля в существующую модель настроек.

Например:

colorNumbersCount

cashNumbersCount

Или использовать текущий стиль именования настроек проекта.

Не смешивать эти значения с уже существующими настройками:

- количество цветных фишек в поле;
- сумма кэша на поле;
- номинал цвета;
- номиналы кэша.

Это отдельные параметры.

---

РАСПОЛОЖЕНИЕ

Оба поля разместить внутри раздела:

“Цвет / Кэш”

Логически:

- “Количество номеров с цветом” — рядом с настройками цветных фишек;
- “Количество номеров с кэшем” — рядом с настройками кэша.

Сохранить текущий стиль и расположение элементов раздела.

---

ВАЖНО

На этом этапе нужно только:

- добавить поля в интерфейс;
- добавить значения в состояние настроек;
- установить дефолтное значение 1;
- поддержать сброс настроек.

Пока НЕ подключать эти поля к:

- генерации ставок;
- выбору номеров;
- расчётам;
- опросу дилера;
- отчёту.

Логику использования этих значений добавим отдельно.

---

ОГРАНИЧЕНИЯ

- Не менять текущую генерацию цветных ставок.
- Не менять генерацию кэша.
- Не менять расчёты.
- Не менять rouletteRules.json.
- Не удалять существующие настройки.
- Не менять название раздела “Цвет / Кэш”.
- Добавить только два новых поля.

---

КРИТЕРИИ ГОТОВНОСТИ

- В разделе «Цвет / Кэш» есть поле «Количество номеров с цветом».
- В разделе «Цвет / Кэш» есть поле «Количество номеров с кэшем».
- Оба поля по умолчанию равны 1.
- После сброса настроек оба поля равны 1.
- В поля нельзя ввести отрицательные или дробные значения.
- Новые значения пока не влияют на генерацию и расчёты.
