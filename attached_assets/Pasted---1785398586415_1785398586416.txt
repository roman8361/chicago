Необходимо изменить условие появления вопроса:

«Посчитайте сдачу с пересечений ставок на треке со ставками на поле.»

# Новое условие появления вопроса

Вопрос должен задаваться только при одновременном выполнении двух условий.

## Условие 1. Есть хотя бы одна ставка на поле

Должна присутствовать хотя бы одна из следующих ставок:

- цветные фишки;
- кэш;
- комплит.

Если отсутствуют одновременно:

- цветные фишки;
- кэш;
- комплиты,

то вопрос задавать нельзя.

---

## Условие 2. Есть хотя бы одна ставка на треке

Должна присутствовать хотя бы одна из следующих ставок:

- серии;
- соседи номера.

Если отсутствуют одновременно:

- серии;
- соседи,

то вопрос задавать нельзя.

---

# Итоговое правило

Вопрос:

«Посчитайте сдачу с пересечений ставок на треке со ставками на поле.»

должен появляться только если одновременно выполняются оба условия:

1. Есть хотя бы одна ставка поля:
   - цвет;
   - кэш;
   - комплит.

И

2. Есть хотя бы одна ставка трека:
   - серии;
   - соседи.

---

# Примеры

## Задавать вопрос

✔ Цвет + серии

✔ Кэш + соседи

✔ Комплит + серии

✔ Комплит + соседи

✔ Цвет + кэш + серии

✔ Цвет + комплит + соседи

✔ Цвет + кэш + комплит + серии

✔ Цвет + кэш + комплит + соседи

✔ Любая комбинация ставок поля + любая комбинация ставок трека

---

# Не задавать вопрос

✘ Только цвет

✘ Только кэш

✘ Только комплит

✘ Цвет + кэш

✘ Цвет + комплит

✘ Кэш + комплит

(нет ставок трека)

---

✘ Только серии

✘ Только соседи

✘ Серии + соседи

(нет ставок поля)

---

✘ Нет ставок вообще

---

# Что нельзя менять

Не менять:

- текст вопроса;
- порядок вопросов;
- алгоритм расчёта пересечений;
- алгоритм расчёта сдачи;
- правильный ответ;
- генерацию ставок.

Изменить только условие, при котором вопрос включается в экзамен.

---

# Обязательные проверки

Проверить минимум:

1. Цвет + серии — вопрос появляется.

2. Цвет + соседи — вопрос появляется.

3. Кэш + серии — вопрос появляется.

4. Кэш + соседи — вопрос появляется.

5. Комплит + серии — вопрос появляется.

6. Комплит + соседи — вопрос появляется.

7. Цвет + кэш + серии — вопрос появляется.

8. Цвет + кэш + комплит + соседи — вопрос появляется.

9. Только цвет — вопрос не появляется.

10. Только кэш — вопрос не появляется.

11. Только комплит — вопрос не появляется.

12. Только серии — вопрос не появляется.

13. Только соседи — вопрос не появляется.

14. Серии + соседи без ставок поля — вопрос не появляется.

15. Цвет + кэш без трека — вопрос не появляется.

16. Комплит без трека — вопрос не появляется.

После выполнения кратко сообщи:

- какое итоговое условие используется для появления вопроса;
- подтверждение, что требуется наличие хотя бы одной ставки поля и хотя бы одной ставки трека одновременно;
- подтверждение, что логика расчёта вопроса не изменялась.
