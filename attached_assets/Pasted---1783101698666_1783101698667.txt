ЗАДАЧА

Добавить новый вопрос в существующий опрос дилера:

“Какую общую сумму нужно поставить в поле с выигрышных серий?”

Вопрос относится только к выигравшим сериям на треке.

---

УСЛОВИЕ ПОЯВЛЕНИЯ ВОПРОСА

Вопрос показывать только в том случае, если сыграла хотя бы одна активная серия.

Активные серии:

- Serie 5/8
- Orphelins
- Serie 0/2/3
- Zero Spiel

Серия считается сыгравшей, если выпавший номер входит хотя бы в одну реальную ставочную позицию этой серии из:

rouletteRules.json
→ trackBets
→ соответствующая серия
→ bets

Если активные серии есть, но выпавший номер не входит ни в одну ставочную позицию ни одной серии, вопрос НЕ показывать.

---

ВАЖНО

Не определять выигрыш серии только по существующему массиву `numbers`.

Для расчёта этого вопроса использовать реальные позиции ставок из:

trackBets[seriesKey].bets

Именно `bets` является источником правды для определения:

- сыграла ли серия;
- сколько ставок этой серии сыграло;
- сколько фишек нужно поставить в поле.

---

СМЫСЛ ВОПРОСА

Пользователь должен определить общую сумму, которую нужно поставить в поле со всех выигравших серий.

Нужно учитывать:

- реальную ставку серии после уже отданной сдачи по кратности;
- все выигравшие позиции каждой серии;
- количество фишек `chips` на каждой выигравшей позиции;
- несколько выигравших серий одновременно.

Пользователь вводит одну общую сумму.

---

КАК ОПРЕДЕЛИТЬ, ПО СКОЛЬКО ИГРАЕТ СЕРИЯ

Для каждой активной серии:

1. Взять сгенерированную сумму серии:

amount

2. Взять `divisor` серии из `rouletteRules.json`.

3. Взять кратность приёма из настроек:

multiplicity

4. Посчитать:

rawPlay = amount / divisor

5. Округлить значение вниз до ближайшей кратности:

playPerUnit = floor(rawPlay / multiplicity) * multiplicity

Именно `playPerUnit` является реальной ставкой серии после уже отданной сдачи по кратности.

Не использовать исходную сумму серии напрямую для расчёта выигрышной ставки.

---

ПРИМЕР ORPHELINS

Ставка Orphelins:

380

divisor:

5

Кратность:

10

Расчёт:

380 / 5 = 76

Округляем вниз до кратности 10:

70

Значит Orphelins реально играет по:

70

---

КАК ОПРЕДЕЛИТЬ ВЫИГРАВШИЕ ПОЗИЦИИ СЕРИИ

Для каждой активной серии взять все позиции из:

trackBets[seriesKey].bets

Проверить все группы ставок, которые существуют в JSON:

- straightUp
- splits
- streets
- corners
- sixLines

Для каждой позиции проверить:

position.numbers.includes(winningNumber)

Если выпавший номер входит в `numbers`, позиция считается выигравшей.

---

КАК ПОСЧИТАТЬ СУММУ В ПОЛЕ

Для каждой выигравшей позиции:

positionAmount = playPerUnit * position.chips

После этого сложить суммы всех выигравших позиций всех выигравших серий.

Формула:

totalWinningSeriesAmount =
sum(playPerUnit * chips)

только для позиций, где:

numbers содержит winningNumber

SERIE 5/8

Для Serie 5/8 использовать ту же универсальную логику.

Не писать отдельный расчёт специально для Serie 5/8.

В JSON у Serie 5/8 все позиции являются split.

Если выпавший номер входит в один из split, серия сыграла.

Сумма выигравшей позиции:

playPerUnit * chips

---

КРИТЕРИИ ГОТОВНОСТИ

- Вопрос появляется только если сыграла хотя бы одна серия.
- Выигравшая серия определяется по реальным позициям `trackBets.bets`.
- Реальная ставка серии считается после сдачи по кратности.
- Проверяются все позиции серии.
- Учитывается `chips` каждой выигравшей позиции.
- Если в одной серии выиграло несколько позиций, их суммы складываются.
- Если сыграло несколько серий, их суммы складываются.
- Пользователь вводит одну общую сумму.
- При ошибке показывается подробный расчёт по всем выигравшим сериям и позициям.
