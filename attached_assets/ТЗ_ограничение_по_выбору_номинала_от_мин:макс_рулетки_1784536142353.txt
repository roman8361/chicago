ЗАДАЧА

Добавить ограничение на выбор номиналов кэш-фишек в зависимости от диапазона ставок рулетки.

Номинал кэш-фишки должен всегда находиться внутри диапазона:

Минимальная ставка рулетки ≤ Номинал кэша ≤ Максимальная ставка рулетки.

Если пользователь пытается выбрать недопустимый номинал, выбор не должен происходить, а пользователю необходимо показать небольшое ненавязчивое сообщение с объяснением причины.

---

ПРАВИЛО

Для каждого номинала кэш-фишки необходимо проверять:

```text
minBet <= cashDenomination <= maxBet

Только такие номиналы могут быть выбраны.

ПРИМЕР 1

Диапазон рулетки:

Минимум = 1

Максимум = 100

Допустимые номиналы:

10
25
50
100

Недопустимые:

250
500
1000
5000
10000
50000

Если пользователь нажимает:

250

или

500

или любой другой номинал больше 100,

ничего не выбирать.

Показать небольшое сообщение:

Номинал кэша не может превышать максимальную ставку рулетки (100).

ПРИМЕР 2

Диапазон рулетки:

Минимум = 100

Максимум = 1000

Допустимые номиналы:

100
250
500
1000

Недопустимые:

10
25
50
5000
10000
50000

Если пользователь нажимает:

50

Показать сообщение:

Номинал кэша не может быть меньше минимальной ставки рулетки (100).

Если пользователь нажимает:

5000

Показать сообщение:

Номинал кэша не может превышать максимальную ставку рулетки (1000).

Выбор не менять.

ПРИМЕР 3

Диапазон рулетки:

Минимум = 250

Максимум = 500

Допустимый номинал только:

250
500

Все остальные должны отклоняться соответствующим сообщением.

КОГДА ПРОВЕРЯТЬ

Проверка должна происходить сразу при клике по номиналу.

Последовательность:

Пользователь нажал номинал.
Проверить диапазон.
Если номинал допустим — выполнить существующую логику выбора (FIFO с максимум двумя выбранными номиналами).
Если номинал недопустим — не менять выбранные номиналы и показать сообщение.

СООБЩЕНИЕ

Не использовать:

alert;
confirm;
browser popup.

Использовать уже существующий компонент уведомлений проекта:

toast;
snackbar;
небольшое всплывающее уведомление;
либо компактную inline-подсказку.

Сообщение должно автоматически исчезать через 2–3 секунды.

ТЕКСТ СООБЩЕНИЙ

Если номинал меньше минимума:

Номинал кэша не может быть меньше минимальной ставки рулетки (100).

Если номинал больше максимума:

Номинал кэша не может превышать максимальную ставку рулетки (1000).

Число в сообщении должно подставляться динамически из текущих настроек.

ВИЗУАЛЬНОЕ СОСТОЯНИЕ

Недопустимые номиналы не нужно скрывать.

Не нужно делать их disabled.

Пользователь должен видеть весь список номиналов и иметь возможность нажать на любой из них.

Если выбран недопустимый номинал:

выбор не происходит;
текущие выбранные номиналы остаются без изменений;
показывается уведомление.

ПРИМЕР

Сейчас выбраны:

[100, 500]

Диапазон рулетки:

100–1000

Пользователь нажимает:

50

Результат:

Остаётся:

[100, 500]

Показывается сообщение:

Номинал кэша не может быть меньше минимальной ставки рулетки (100).

Другой пример:

Выбраны:

[100, 500]

Диапазон:

100–1000

Пользователь нажимает:

1000

Номинал допустимый.

Работает существующая FIFO-логика:

[100, 500]
→
[500, 1000]

ИЗМЕНЕНИЕ ДИАПАЗОНА РУЛЕТКИ

Если пользователь изменил:

Минимум или Максимум ставок рулетки,

необходимо сразу проверить уже выбранные номиналы.

Если какой-либо выбранный номинал перестал попадать в диапазон:

автоматически удалить его из выбранных;
сохранить только допустимые номиналы.

Если после проверки не осталось ни одного выбранного номинала:

автоматически выбрать первый допустимый номинал из списка.

Пример:

Диапазон изменился:

1–100

До изменения были выбраны:

[500, 1000]

После изменения:

[100]

Так как только 100 попадает в новый диапазон.

ГЕНЕРАЦИЯ КЭШ-ФИШЕК

Не менять существующую генерацию.

После изменения настроек генератор должен использовать только допустимые выбранные номиналы.

Дополнительная проверка генератору не требуется, так как недопустимые значения не смогут попасть в настройки.

НЕ МЕНЯТЬ

FIFO-логику выбора двух номиналов;
список доступных номиналов;
внешний вид раздела настроек;
генерацию кэш-фишек;
расчёт выигрышей;
правила размещения кэш-фишек;
сохранение настроек.

Добавляется только проверка диапазона.

КРИТЕРИИ ГОТОВНОСТИ

Пользователь не может выбрать номинал меньше минимальной ставки рулетки.
Пользователь не может выбрать номинал больше максимальной ставки рулетки.
При попытке выбора показывается небольшое уведомление.
Уже выбранные номиналы не изменяются при выборе недопустимого значения.
При выборе допустимого номинала продолжает работать FIFO-логика замены двух номиналов.
После изменения диапазона рулетки выбранные номиналы автоматически проверяются.
Недопустимые выбранные номиналы автоматически удаляются.
Если после проверки не осталось ни одного номинала, автоматически выбирается первый допустимый номинал.
Генерация кэш-фишек продолжает работать без изменений.
Все сообщения используют текущие значения минимальной и максимальной ставки рулетки.ЗАДАЧА
