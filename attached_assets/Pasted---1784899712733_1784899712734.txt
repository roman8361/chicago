Нужно расширить и исправить расчёт вопроса:

«Посчитайте сдачу с пересечений на треке серий и ставок „соседи номера“, без учета ставок на поле.»

Сейчас расчёт учитывает не все реальные пересечения ставок на треке.

Ничего не меняй в генерации ставок, составе серий, визуальном отображении и других вопросах. Изменить нужно только расчёт правильного ответа и отчёт для этого конкретного вопроса.

## Текущий общий принцип

В расчёте участвуют только:

- активные серии;
- ставки «Соседи номера».

Ставки основного поля полностью игнорируются:

- цветные ставки;
- кэш;
- комплиты номера;
- комплит дюжины.

Каждая ставка трека должна быть развёрнута в реальные ставочные позиции, после чего суммы на одинаковых позициях должны объединяться.

Важно: одинаковой позицией считается совпадение не только номера, но и типа ставки.

Например:

- Straight 1 и Straight 1 — одна позиция;
- Split 12–15 и Split 12–15 — одна позиция;
- Straight 12 и Split 12–15 — разные позиции;
- Split 12–15 и Split 15–12 — одна и та же позиция, порядок номеров не должен иметь значения.

## Шаг 1. Развернуть ставки «Соседи номера»

Каждая ставка «Соседи номера» разворачивается в 5 отдельных Straight-позиций:

- центральный номер;
- два соседа слева;
- два соседа справа.

На каждый из пяти номеров ставится одинаковая сумма baseAmount.

Для каждой позиции сохранить:

- тип ставки: Straight;
- номер;
- сумму;
- источник: конкретная ставка «Соседи номера».

Если несколько ставок «Соседи номера» включают один и тот же номер, их суммы на этом Straight должны складываться.

## Шаг 2. Развернуть все активные серии

Для каждой активной серии определить её фактическую игру на единицу:

1. Взять общую сумму серии.
2. Разделить её на фактическое количество частей серии.
3. Округлить результат вниз до установленной кратности.
4. Полученное значение использовать как игру на одну единицу.

После этого каждую серию развернуть в полный набор её реальных ставок:

- Straight;
- Split;
- Street;
- Corner;
- другие фактически используемые позиции.

Сумма на каждой позиции серии:

игра на единицу × количество фишек на этой позиции.

Для каждой позиции сохранить:

- тип ставки;
- номера позиции;
- сумму;
- источник: название серии.

## Шаг 3. Нормализовать позиции

Перед объединением привести каждую позицию к единому виду.

Для Straight ключ позиции должен содержать:

- тип Straight;
- один номер.

Для Split:

- тип Split;
- два номера, отсортированные по возрастанию.

Для Street:

- тип Street;
- три номера в нормализованном порядке.

Для Corner:

- тип Corner;
- четыре номера в нормализованном порядке.

Для Six Line:

- тип Six Line;
- шесть номеров в нормализованном порядке.

Одинаковые физические позиции должны получать одинаковый ключ независимо от:

- порядка номеров;
- серии-источника;
- места, где позиция была создана;
- названия серии.

Это необходимо, чтобы корректно находить пересечения не только между серией и соседями, но и между несколькими сериями.

## Шаг 4. Объединить одинаковые позиции

Все ставки с одинаковым нормализованным ключом объединяются.

Для каждой уникальной позиции рассчитать:

общая сумма позиции =
сумма всех вкладов ставок «Соседи номера»
+ сумма всех вкладов серий.

В расчёте должны учитываться:

1. Пересечения серии и соседей.
2. Пересечения нескольких ставок «Соседи номера».
3. Пересечения нескольких серий между собой.
4. Превышение лимита одной серией без других источников.
5. Превышение лимита одной ставкой «Соседи номера» без серии.

Сдача должна возникать на любой позиции, где итоговая сумма превышает лимит, независимо от количества источников.

## Кейс 1. Straight 26 в Zero Spiel

Проверь фактический состав Zero Spiel.

Если в текущей схеме Zero Spiel для номера 26 действительно существует отдельная ставка Straight 26, она должна участвовать в расчёте как обычная Straight-позиция.

Если одновременно одна или несколько ставок «Соседи номера» включают номер 26, суммы должны объединяться:

Straight 26 из Zero Spiel
+ Straight 26 из соседей
= общая ставка на Straight 26.

После этого общая сумма сравнивается с лимитом Straight.

Формула лимита:

максимум стола × 1.

Если лимит превышен:

сдача = общая сумма Straight 26 − лимит Straight.

Важно:

- не считать совпадение только по номеру;
- использовать именно совпадающую позицию Straight 26;
- если Zero Spiel содержит не Straight 26, а другую позицию с участием 26, она не должна объединяться со Straight соседей;
- сначала проверь фактический состав текущей схемы Zero Spiel и используй именно его.

Добавь отдельный тест:

- Zero Spiel активен;
- в Zero Spiel присутствует Straight 26;
- ставка «Соседи номера» включает 26;
- суммарная ставка превышает максимум Straight;
- сдача корректно попадает в общий ответ и отчёт.

## Кейс 2. Пересечения серий между собой

Сейчас необходимо обязательно учитывать одинаковые позиции, которые входят сразу в несколько серий.

Ключевой пример:

- Serie 0/2/3 содержит Split 12–15;
- Zero Spiel содержит тот же Split 12–15.

Обе ставки относятся к одной физической позиции Split 12–15.

Их суммы должны быть сложены до проверки лимита:

сумма Split 12–15 из Serie 0/2/3
+ сумма Split 12–15 из Zero Spiel
= общая ставка на Split 12–15.

Лимит Split:

максимальная ставка стола × 2.

Если общая сумма превышает лимит:

сдача =
общая сумма Split 12–15 − лимит Split.

Это пересечение должно учитываться даже при полном отсутствии ставок «Соседи номера».

То есть вопрос должен рассчитывать не только пересечения:

- серия + соседи,

но вообще всю сдачу по ставкам трека, сформированным сериями и соседями, включая:

- серия + серия;
- соседи + соседи;
- серия + соседи;
- превышение одного источника.

## Обязательная проверка состава серий

Проанализируй фактические расклады всех четырёх серий:

- Serie 5/8;
- Orphelins;
- Serie 0/2/3;
- Zero Spiel.

Найди все одинаковые реальные позиции между сериями.

Для каждой найденной общей позиции:

- убедись, что она нормализуется одинаково;
- убедись, что суммы складываются;
- убедись, что лимит применяется один раз к общей сумме;
- убедись, что сдача рассчитывается один раз по итоговой позиции.

Не ограничивай исправление только Split 12–15. Нужно исправить общий механизм объединения одинаковых позиций.

## Пример ошибки, которую нужно устранить

Условия:

- Serie 0/2/3 играет по 500;
- Zero Spiel играет по 200;
- выигрышный номер — 12;
- максимальная ставка в номер — 300.

На треке обе серии создают одну и ту же физическую позицию Split 12–15.

Правильная логика:

1. Определить фактическую сумму Split 12–15 от Serie 0/2/3.
2. Определить фактическую сумму Split 12–15 от Zero Spiel.
3. Сложить обе суммы.
4. Сравнить итог с лимитом Split.
5. Рассчитать сдачу только с превышения общей суммы.

При максимуме 300 лимит Split равен:

300 × 2 = 600.

Если итоговая сумма на Split 12–15 равна 700:

700 − 600 = 100 сдачи.

Если итоговая сумма равна 600:

сдача равна 0.

Если итоговая сумма равна 800:

800 − 600 = 200 сдачи.

В текущем отчёте появляется неправильное значение 700. Нужно устранить двойной или некорректный расчёт и показывать именно сдачу, а не общую сумму ставки.

## Шаг 5. Рассчитать лимит каждой позиции

Для каждой уникальной позиции использовать коэффициент её типа:

- Straight — 1;
- Split — 2;
- Street — 3;
- Corner — 4;
- Six Line — 6.

Формула:

лимит позиции =
максимальная ставка стола × коэффициент позиции.

Пример при максимуме 300:

- Straight — 300;
- Split — 600;
- Street — 900;
- Corner — 1200;
- Six Line — 1800.

## Шаг 6. Рассчитать сдачу

Для каждой уникальной позиции:

если общая сумма позиции > лимит позиции:

сдача по позиции =
общая сумма позиции − лимит позиции.

Иначе:

сдача по позиции = 0.

Не использовать:

- выплату по выигрышу;
- возврат исходной ставки;
- сумму всей позиции как ответ;
- отдельный лимит для каждого источника;
- повторное применение лимита к одной и той же позиции.

Лимит применяется один раз к общей сумме физической позиции.

## Шаг 7. Рассчитать общий ответ

Общая сдача равна сумме сдачи по всем уникальным позициям трека:

- Straight;
- Split;
- Street;
- Corner;
- Six Line.

Учитывать все положительные превышения.

Ставки основного поля не добавлять.

## Шаг 8. Проверка ответа пользователя

Пользователь вводит одно число.

Оно сравнивается с общей рассчитанной сдачей.

Сравнение точное.

Без округления и допустимой погрешности.

## Требования к отчёту

При неправильном ответе показывать только позиции с превышением лимита.

Для каждой позиции выводить:

- тип ставки;
- номера позиции;
- все источники;
- сумму от каждого источника;
- общую сумму позиции;
- коэффициент;
- лимит позиции;
- сдачу по позиции.

Пример корректного блока отчёта:

Split 12–15

- Serie 0/2/3: 500
- Zero Spiel: 200
- Общая ставка: 700
- Лимит Split: 600
- Сдача: 100

Не выводить 700 как правильную сдачу.

Если на позиции участвуют соседи:

Straight 26

- Zero Spiel: 200
- Соседи №26: 150
- Общая ставка: 350
- Лимит Straight: 300
- Сдача: 50

## Что нельзя менять

Не меняй:

- генерацию серий;
- состав серий, если он уже соответствует правилам;
- генерацию соседей;
- количество соседей;
- суммы ставок;
- визуальное расположение фишек;
- выбор выигрышного номера;
- настройки минимума, максимума и кратности;
- порядок вопросов;
- остальные алгоритмы экзамена.

Исправить нужно только:

1. Разворачивание ставок трека в реальные позиции.
2. Нормализацию одинаковых позиций.
3. Объединение сумм по одинаковым позициям.
4. Учёт пересечений серий между собой.
5. Учёт Straight 26 из Zero Spiel с соседями, если эта позиция реально есть в схеме.
6. Расчёт сдачи.
7. Формирование отчёта.

## Обязательные тестовые сценарии

Проверь минимум следующие случаи:

1. Только одна ставка «Соседи номера», лимит не превышен.

2. Только одна ставка «Соседи номера», Straight превышает лимит.

3. Несколько соседей пересекаются на одном Straight.

4. Orphelins Straight 1 пересекается с соседями, включающими 1.

5. Zero Spiel Straight 26 пересекается с соседями, включающими 26, если Straight 26 есть в текущей схеме.

6. Serie 0/2/3 и Zero Spiel пересекаются на Split 12–15.

7. Serie 0/2/3 и Zero Spiel пересекаются на Split 12–15, но общая сумма точно равна лимиту — сдача 0.

8. Пересечение двух серий превышает лимит на 1 — сдача 1.

9. Одна серия самостоятельно превышает лимит позиции.

10. Серия и соседи не имеют одинаковых позиций — суммы не объединяются.

11. Один и тот же номер встречается в Straight соседей и в Split серии — это разные позиции, объединять нельзя.

12. Одинаковый Split записан в разном порядке номеров, например 12–15 и 15–12 — он должен объединиться.

13. Одновременно есть несколько превышений на разных типах ставок — все сдачи складываются.

14. Есть ставки на основном поле — они не влияют на правильный ответ.

15. В отчёте показывается сдача, а не общая сумма ставки.

## Итоговый алгоритм

После исправления логика должна работать так:

1. Развернуть всех соседей в Straight-позиции.
2. Развернуть все активные серии в реальные позиции.
3. Нормализовать ключ каждой позиции.
4. Объединить все одинаковые позиции независимо от источника.
5. Сложить суммы всех источников по каждой позиции.
6. Рассчитать единый лимит позиции.
7. Определить превышение.
8. Сложить все превышения.
9. Сравнить ответ пользователя с общей сдачей.
10. Показать в отчёте подробный расчёт только превышающих позиций.

После выполнения кратко опиши:

- какие пересечения серий между собой были найдены;
- есть ли в фактической схеме Zero Spiel Straight 26;
- как нормализуются Split-позиции;
- как исправлен расчёт для Split 12–15;
- какие тесты подтверждают правильность результата.
