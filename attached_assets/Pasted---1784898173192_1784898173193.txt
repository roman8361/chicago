Нужно изменить логику и формулировку вопроса:

«Посчитайте общую сдачу с поля, без учета трека.»

Это задание должно проверять превышение максимальных лимитов по всем ставочным позициям основного поля.

Учитывать необходимо:

- ставки «Комплит номера»;
- ставки «Комплит дюжины»;
- обычные цветные ставки;
- денежные фишки, то есть кэш;
- пересечения перечисленных ставок на одной и той же позиции.

Ставки на треке учитывать нельзя:

- серии;
- соседи номера;
- любые другие фишки, расположенные на треке.

## Основное правило

Для каждой ставочной позиции основного поля необходимо определить общую сумму, фактически поставленную на эту позицию.

Общая сумма позиции может состоять из:

- вклада одного комплита;
- вкладов нескольких комплитов;
- цветных фишек;
- кэш-фишки;
- комбинации всех перечисленных ставок.

После этого общая сумма позиции сравнивается с максимальным лимитом, разрешённым для соответствующего типа ставки.

Если общая сумма превышает лимит, разница считается сдачей по этой позиции.

Если лимит не превышен, сдача по позиции равна нулю.

Правильный ответ — сумма сдачи по всем позициям основного поля.

## Шаг 1. Развернуть комплиты в отдельные позиции

Для каждого созданного комплита определить полный набор позиций, которые он покрывает.

Для комплита номера могут использоваться:

- Straight;
- Split;
- Street;
- Corner;
- Six Line.

Для комплита дюжины необходимо использовать полный фактический состав ставок выбранной дюжины.

Большая фишка комплита является сокращённым визуальным обозначением. Для расчёта необходимо использовать не только место отображения большой фишки, а полный внутренний расклад комплита по отдельным ставочным позициям.

Если создано несколько комплитов, необходимо развернуть каждый из них.

## Шаг 2. Рассчитать вклад комплита в каждую позицию

Для каждого комплита определить стоимость одной единицы комплита.

Вклад комплита в конкретную позицию рассчитывается с учётом количества фишек, которое по схеме комплита должно быть поставлено на эту позицию.

Например, если стоимость одной единицы комплита равна 25:

- позиция с одной фишкой получает 25;
- позиция с двумя фишками получает 50;
- позиция с тремя фишками получает 75;
- позиция с четырьмя фишками получает 100;
- позиция с шестью фишками получает 150.

Использовать фактическое количество фишек каждой позиции из текущей схемы комплита.

Не считать, что каждая позиция комплита получает одинаковую сумму.

## Шаг 3. Собрать все позиции основного поля

После разворачивания комплитов сформировать единый список всех ставочных позиций основного поля, на которых присутствует хотя бы одна ставка:

- вклад комплита;
- цветная ставка;
- кэш;
- несколько пересекающихся ставок.

В расчёт должны входить две группы позиций:

1. Позиции, входящие в один или несколько комплитов.
2. Позиции, не входящие в комплиты, но содержащие цветную ставку или кэш.

Таким образом, обычная ставка на поле должна проверяться на превышение лимита даже в том случае, если она не пересекается с комплитом.

## Шаг 4. Рассчитать сумму каждой позиции

Для каждой уникальной позиции сложить все ставки, относящиеся именно к ней.

Формула:

общая сумма позиции =
вклад первого комплита
+ вклад второго комплита
+ остальные вклады комплитов
+ сумма цветных фишек
+ сумма кэша.

### Цветные ставки

Сумма цветной ставки определяется как:

количество цветных фишек × номинал цвета.

### Кэш

Для кэш-фишки использовать её денежное значение.

### Пересечения

Если на одной позиции одновременно присутствуют:

- комплит;
- цветные фишки;
- кэш;

все суммы складываются.

Если одна позиция входит сразу в несколько комплитов, вклады всех комплитов также складываются.

Не создавать несколько независимых проверок одной и той же позиции. Сначала собрать её полную сумму, затем один раз сравнить с лимитом.

## Шаг 5. Определить тип позиции

Для каждой позиции определить её тип:

- Straight;
- Split;
- Street;
- Corner;
- Six Line.

Тип позиции должен определяться по самой ставочной позиции, а не по источнику фишки.

Например, если комплит и цветная фишка пересекаются на Split, для всей суммарной ставки применяется лимит Split.

## Шаг 6. Рассчитать лимит позиции

Лимит позиции рассчитывается на основании настройки максимальной ставки стола.

Использовать следующие коэффициенты:

- Straight — 1;
- Split — 2;
- Street — 3;
- Corner — 4;
- Six Line — 6.

Формула:

лимит позиции = максимальная ставка стола × коэффициент позиции.

Например, при максимуме стола 100:

- Straight: 100 × 1 = 100;
- Split: 100 × 2 = 200;
- Street: 100 × 3 = 300;
- Corner: 100 × 4 = 400;
- Six Line: 100 × 6 = 600.

## Шаг 7. Рассчитать сдачу по позиции

Для каждой позиции сравнить её общую сумму с лимитом.

Если:

общая сумма позиции > лимит позиции,

то:

сдача по позиции = общая сумма позиции − лимит позиции.

Если:

общая сумма позиции ≤ лимит позиции,

то:

сдача по позиции = 0.

Позиции без превышения не увеличивают итоговый ответ.

## Шаг 8. Исключить трек

Ставки на треке полностью исключить из этого расчёта.

Не учитывать:

- большие фишки серий;
- внутренний расклад серий;
- ставки «Соседи номера»;
- пересечения трека со ставками на основном поле;
- пересечения трека с комплитами.

Даже если серия или соседи попадают на те же номера, что и ставки поля, их суммы в этом вопросе не добавляются.

Расчёт относится только к ставкам, сформированным на основном поле.

## Шаг 9. Рассчитать общий правильный ответ

Сложить сдачу по всем позициям основного поля, на которых был превышен лимит.

Формула:

общая сдача =
сумма всех положительных значений
«общая сумма позиции − лимит позиции».

Это число является правильным ответом на вопрос:

«Посчитайте общую сдачу с поля, без учета трека.»

## Шаг 10. Проверить ответ пользователя

Пользователь вводит одно числовое значение.

Введённое значение сравнивается с рассчитанной общей сдачей.

Сравнение должно быть точным.

Не использовать:

- округление ответа;
- допустимую погрешность;
- частичное совпадение;
- отдельный ответ по каждой позиции.

## Подробный пример

Настройки:

- максимальная ставка стола = 100;
- стоимость одной единицы комплита = 25;
- создан один комплит номера;
- на поле также присутствуют цветные ставки и кэш;
- ставки трека в примере имеются, но полностью игнорируются.

Рассмотрим несколько позиций.

### Позиция 1 — Straight

Комплит размещает на Straight одну единицу:

1 × 25 = 25.

На этой же позиции находятся:

- 6 цветных фишек номиналом 10: 6 × 10 = 60;
- кэш-фишка 50.

Общая сумма позиции:

25 + 60 + 50 = 135.

Лимит Straight:

100 × 1 = 100.

Сдача:

135 − 100 = 35.

### Позиция 2 — Split

Комплит размещает на Split две единицы:

2 × 25 = 50.

На этой же позиции находятся:

- 12 цветных фишек номиналом 10: 120;
- кэш-фишка 75.

Общая сумма:

50 + 120 + 75 = 245.

Лимит Split:

100 × 2 = 200.

Сдача:

245 − 200 = 45.

### Позиция 3 — Street

Комплит размещает на Street три единицы:

3 × 25 = 75.

Обычных ставок на позиции нет.

Общая сумма:

75.

Лимит Street:

100 × 3 = 300.

Превышения нет.

Сдача:

0.

### Позиция 4 — Corner

Позиция не входит в комплит.

На ней находятся:

- 35 цветных фишек номиналом 10: 350;
- кэш-фишка 100.

Общая сумма:

350 + 100 = 450.

Лимит Corner:

100 × 4 = 400.

Сдача:

450 − 400 = 50.

Эта позиция обязательно участвует в расчёте, хотя она не входит в комплит.

### Позиция 5 — Six Line

Позиция не входит в комплит.

На ней находится кэш-фишка 550.

Лимит Six Line:

100 × 6 = 600.

Превышения нет.

Сдача:

0.

### Позиция 6 — пересечение двух комплитов

Предположим, одна и та же Split-позиция входит в два разных комплита.

Первый комплит даёт:

2 × 25 = 50.

Второй комплит даёт:

2 × 50 = 100.

На позиции также находится кэш 100.

Общая сумма:

50 + 100 + 100 = 250.

Лимит Split:

100 × 2 = 200.

Сдача:

250 − 200 = 50.

### Ставки на треке

Предположим, серия и ставка «Соседи номера» дают ещё 300 на номера, связанные с рассмотренными позициями.

Эти 300 полностью игнорируются и ни к одной позиции основного поля не добавляются.

### Итог

Сдачи по позициям:

- Straight: 35;
- Split: 45;
- Street: 0;
- Corner: 50;
- Six Line: 0;
- пересечение двух комплитов на Split: 50.

Общая сдача:

35 + 45 + 50 + 50 = 180.

Правильный ответ пользователя:

180.

## Отображение вопроса

Во время выполнения задания показывать точный текст:

«Посчитайте общую сдачу с поля, без учета трека.»

Этот же текст без изменений использовать:

- в итоговом отчёте;
- в истории ответов;
- в результате проверки;
- в объяснении ошибки.

## Отображение поля во время вопроса

Во время этого вопроса основное поле должно оставаться видимым.

Трек необходимо визуально затемнить, чтобы было понятно, что его ставки не участвуют в расчёте.

При этом:

- не перемещать фишки;
- не скрывать ставки основного поля;
- не менять размеры поля;
- не добавлять анимацию или свечение;
- не затемнять цветные ставки;
- не затемнять кэш;
- не затемнять комплиты и их визуальные обозначения на основном поле.

## Отчёт при неправильном ответе

При неправильном ответе показать:

- точный текст вопроса;
- ответ пользователя;
- правильную общую сдачу;
- список только тех позиций, где был превышен лимит.

Для каждой превышающей позиции показать:

- тип ставки;
- обозначение позиции;
- вклад комплита или нескольких комплитов;
- сумму цветных ставок;
- сумму кэша;
- общую сумму позиции;
- лимит позиции;
- сдачу по позиции.

Ставки без превышения можно не выводить в основном списке, но расчёт должен корректно их проверить.

Ставки трека в отчёт по этому вопросу не включать.

## Проверки

После реализации проверь следующие сценарии:

1. Есть только один комплит, превышений нет — ответ 0.

2. Есть только один комплит, одна его позиция превышает лимит.

3. Есть несколько комплитов, которые пересекаются на одной позиции.

4. Есть комплит и цветные ставки на одной позиции.

5. Есть комплит и кэш на одной позиции.

6. Есть комплит, цветные ставки и кэш одновременно.

7. Есть обычная цветная ставка с превышением на позиции, не входящей в комплит.

8. Есть кэш с превышением на позиции, не входящей в комплит.

9. Есть несколько обычных ставок на позициях, не входящих в комплит.

10. Есть ставки трека, но они не изменяют правильный ответ.

11. Общая сумма точно равна лимиту — сдача 0.

12. Общая сумма превышает лимит на единицу — сдача 1.

13. Превышения одновременно существуют на Straight, Split, Street, Corner и Six Line.

14. Одна позиция входит в несколько комплитов и содержит обычную ставку.

15. Комплиты отсутствуют, но на основном поле есть превышения цветных ставок или кэша — они должны быть посчитаны.

## Ограничения

Не меняй:

- генерацию комплитов;
- состав комплитов;
- генерацию цветных ставок;
- генерацию кэша;
- генерацию трека;
- коэффициенты выплат;
- максимальную ставку, указанную в настройках;
- порядок остальных вопросов.

Не создавай отдельные дублирующиеся позиции для одинаковой ставки.

Одна физическая ставочная позиция должна иметь одну суммарную сумму и одну проверку лимита.

После выполнения кратко опиши:

1. Как собираются уникальные позиции основного поля.
2. Как разворачиваются комплиты.
3. Как объединяются комплит, цветные ставки и кэш.
4. Как определяется лимит.
5. Как рассчитывается общая сдача.
6. Как подтверждено, что ставки трека не участвуют в расчёте.
