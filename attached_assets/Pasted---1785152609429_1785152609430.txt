Необходимо изменить алгоритм проверки вопроса:

«Какую общую сумму нужно выставить в поле с выигрышных серий?»

Изменить нужно только расчёт правильного ответа, отчёт и тесты этого вопроса.

Не менять:

- генерацию серий;
- состав серий;
- генерацию ставок на поле;
- алгоритмы остальных вопросов;
- порядок вопросов;
- максимум рулетки;
- кратность приёма серий;
- ранее рассчитанную сдачу с кратности серий.

---

# Назначение вопроса

В этом вопросе нужно определить, какую сумму дилер фактически может выставить в поле с выигрышных ставок серий с учётом уже занятых лимитов на соответствующих позициях.

Сначала необходимо определить сумму, по которой играет выигрышная серия.

После этого проверить, сколько свободного места осталось до максимума на выигрышной позиции.

Правильный ответ — не обязательно полная сумма игры серии.

Правильный ответ равен той части выигрышной ставки серии, которая помещается в оставшийся лимит позиции.

---

# Что учитывать

В расчёте необходимо учитывать только:

- выигрышный номер;
- активные серии;
- только те серии, которые сыграли на выпавшем номере;
- реальные выигрышные позиции этих серий;
- сумму, по которой играет каждая выигрышная серия;
- уже выставленные на соответствующих позициях ставки поля;
- комплиты;
- максимум рулетки.

К уже выставленным ставкам относятся:

- цветные фишки;
- кэш-фишки;
- ставки комплитов номера;
- ставки комплитов дюжины.

---

# Что не учитывать

В этом вопросе не учитывать:

- невыигрышные серии;
- ставки «Соседи номера»;
- сдачу с кратности серий;
- первоначальную сумму, поставленную на сектор серии, как прямую ставку в поле;
- выплаты;
- коэффициенты выигрыша;
- ставки на позициях, не являющихся выигрышными позициями серии;
- сдачу с обычного поля как отдельную сумму ответа.

Сдача с кратности серии была рассчитана ранее и в этом вопросе больше не участвует.

---

# Шаг 1. Определить выигрышные серии

Просмотреть все активные серии.

Для каждой серии определить, содержит ли её расклад выигрышную позицию, которая выигрывает при выпавшем номере.

Если серия не сыграла, она полностью исключается из расчёта.

Например:

- выпал №30;
- Serie 5/8 содержит выигрышную ставку Split 27–30;
- значит Serie 5/8 участвует в расчёте.

Если активная серия не имеет выигрышной позиции для выпавшего номера, её сумма не должна попадать в ответ.

---

# Шаг 2. Определить, по сколько играет серия

Использовать существующий алгоритм расчёта «по сколько играет серия».

Делители серий:

- Serie 5/8 — 6;
- Orphelins — 5;
- Serie 0/2/3 — 9;
- Zero Spiel — 4.

Расчёт должен учитывать существующие правила:

- кратность приёма серий;
- округление вниз;
- ограничение максимумом рулетки;
- текущий алгоритм определения сдачи с кратности.

Однако в этом вопросе нужна только сумма «по сколько играет серия».

Сдачу с кратности не добавлять и повторно не рассчитывать как часть ответа.

Примеры:

- Orphelins: поставлено 400, играет по 80;
- Serie 5/8: поставлено 400, играет по 60;
- Serie 0/2/3: поставлено 1000, играет по 110;
- Zero Spiel: поставлено 250, играет по 60.

Использовать фактический существующий расчёт приложения. Не подменять его жёстко заданными значениями из примеров.

---

# Шаг 3. Найти выигрышную физическую позицию серии

Для каждой выигрышной серии необходимо определить реальную ставку, которая выигрывает при выпавшем номере.

Это может быть:

- Straight;
- Split;
- Street;
- Corner;
- Six Line.

Примеры:

- выпал №30, Serie 5/8 — выигрышная позиция Split 27–30;
- выпал №1, Orphelins — выигрышная позиция Straight 1;
- выпал №32, Serie 0/2/3 и Zero Spiel — выигрышная позиция Split 32–35.

Использовать фактическую карту ставок каждой серии.

Нельзя определять выигрышную позицию только по списку номеров сектора.

Необходимо использовать реальную раскладку серии по физическим позициям поля.

---

# Шаг 4. Объединить совпадающие позиции выигрышных серий

Несколько серий могут выиграть на одной и той же физической позиции.

Одинаковые позиции необходимо объединить.

Нормализовать ключ позиции:

- тип ставки;
- отсортированный набор номеров позиции.

Например:

- Split 32–35;
- Split 35–32

должны считаться одной позицией.

Если Serie 0/2/3 играет на этой позиции по 110, а Zero Spiel по 60:

общая сумма выигрышных серий на позиции:

110 + 60 = 170.

Проверять свободный лимит нужно один раз для общей позиции.

Нельзя отдельно проверять каждую серию и дважды использовать одну и ту же свободную ёмкость позиции.

---

# Шаг 5. Рассчитать сумму, уже стоящую на позиции

Для каждой выигрышной позиции серии собрать все уже выставленные на ней ставки поля.

Сумма поля:

цветные ставки
+
кэш
+
ставки комплитов номера
+
ставки комплитов дюжины.

Комплиты необходимо развернуть в реальные физические позиции.

Учитывать только вклад комплита в конкретную выигрышную позицию.

Например, если комплит дюжины играет по 40 и содержит Split 27–30:

вклад комплита в Split:

2 × 40 = 80.

Если на этой позиции одновременно стоят цвет, кэш и несколько комплитов, все суммы складываются.

---

# Шаг 6. Учесть ранее отданную сдачу с поля

Для определения занятой ёмкости позиции нельзя использовать сумму выше лимита как фактически принятую ставку.

Если первоначальная сумма ставок поля уже превышала лимит, лишняя часть считается ранее возвращённой.

Поэтому фактически занятая сумма позиции:

занято на позиции =
минимум из:

- полной суммы ставок поля;
- лимита позиции.

Или эквивалентно:

занято на позиции =
сумма поля − ранее отданная сдача с поля.

Примеры:

## Поле ниже лимита

На Split стоит 80.

Лимит Split — 200.

Фактически занято:

80.

## Поле ровно на максимуме

На Split стоит 200.

Лимит Split — 200.

Фактически занято:

200.

## Поле превышало максимум

На Split первоначально стояло 250.

Лимит Split — 200.

Ранее должна быть возвращена сдача 50.

Фактически занято:

200.

В этом вопросе повторно считать или добавлять эти 50 не нужно.

---

# Шаг 7. Определить лимит выигрышной позиции

Использовать текущий максимум рулетки и коэффициент позиции:

- Straight — ×1;
- Split — ×2;
- Street — ×3;
- Corner — ×4;
- Six Line — ×6.

Формула:

лимит позиции =
максимум рулетки × коэффициент позиции.

При максимуме 100:

- Straight — 100;
- Split — 200;
- Street — 300;
- Corner — 400;
- Six Line — 600.

---

# Шаг 8. Определить свободную ёмкость позиции

Свободная ёмкость:

свободно =
лимит позиции − фактически занятая сумма.

Если результат меньше нуля, использовать 0.

Формула:

свободно =
max(0, лимит − занято).

---

# Шаг 9. Определить сумму, которую можно выставить с серии

Для каждой уникальной выигрышной позиции:

сумма выигрышных серий =
сумма значений «по сколько» всех серий, выигравших на этой позиции.

Фактически выставляемая сумма:

принятая сумма серии =
min(сумма выигрышных серий, свободная ёмкость позиции).

Возможны три случая.

## Вся ставка серии помещается

Если свободная ёмкость больше или равна сумме серий:

принять всю сумму серий.

## Ставка помещается частично

Если свободная ёмкость меньше суммы серий, но больше нуля:

принять только свободную ёмкость.

## Позиция уже заполнена до максимума

Если свободная ёмкость равна нулю:

с этой выигрышной позиции выставить 0.

---

# Шаг 10. Рассчитать общий ответ

Если есть несколько разных выигрышных позиций, правильный ответ равен сумме фактически принятых ставок по всем уникальным выигрышным позициям.

Формула:

правильный ответ =
сумма min(
    сумма выигрышных серий на позиции,
    свободная ёмкость позиции
).

---

# Пример 1. Serie 5/8 принимается полностью

Выпал номер:

30.

Максимум рулетки:

100.

Кратность приёма серий:

10.

На Serie 5/8 поставлено:

400.

Serie 5/8 играет по:

60.

Сдача с кратности:

40.

Сдача уже была рассчитана ранее и в этом вопросе не учитывается.

Выигрышная позиция:

Split 27–30.

На Split 27–30 уже стоит комплит третьей дюжины по 40.

Вклад комплита в Split:

2 × 40 = 80.

Лимит Split:

2 × 100 = 200.

Свободная ёмкость:

200 − 80 = 120.

Серия должна выставить:

60.

Проверка:

60 ≤ 120.

Ставка помещается полностью.

Правильный ответ:

60.

Если на Split уже стоит 200:

свободная ёмкость:

200 − 200 = 0.

Тогда правильный ответ:

0.

---

# Пример 2. Orphelins принимается частично

Выпал номер:

1.

Максимум рулетки:

100.

Кратность приёма серий:

10.

На Orphelins поставлено:

400.

Orphelins играет по:

80.

Выигрышная позиция:

Straight 1.

На Straight 1 уже стоит:

- цветом — 20;
- комплит №1 играет по 50, его вклад в Straight — 50.

Полная сумма поля:

20 + 50 = 70.

Лимит Straight:

100.

Свободная ёмкость:

100 − 70 = 30.

Orphelins должна выставить 80, но свободно только 30.

Фактически принимается:

min(80, 30) = 30.

Правильный ответ:

30.

Оставшиеся 50 в ответ не входят.

Вопрос спрашивает только, сколько нужно выставить в поле, а не какую сдачу вернуть с выигрышной ставки серии.

---

# Пример 3. Две серии на одной позиции

Выпал номер:

32.

Максимум рулетки:

100.

Кратность приёма серий:

10.

Активны:

- Serie 0/2/3 — поставлено 1000, играет по 110;
- Zero Spiel — поставлено 250, играет по 60.

Сдача с кратности серий в этом вопросе не учитывается.

Обе серии выигрывают на одной позиции:

Split 32–35.

Сумма выигрышных серий:

110 + 60 = 170.

Лимит Split:

200.

## Вариант A. На позиции ничего нет

Уже занято:

0.

Свободно:

200.

Фактически выставить:

min(170, 200) = 170.

Правильный ответ:

170.

## Вариант B. На позиции уже стоит 50

Уже занято:

50.

Свободно:

200 − 50 = 150.

Фактически выставить:

min(170, 150) = 150.

Правильный ответ:

150.

## Вариант C. На позиции уже стоит 200

Свободно:

0.

Правильный ответ:

0.

## Вариант D. На позиции первоначально стояло 250

Лимит:

200.

Ранее лишние 50 должны быть возвращены.

Фактически занято:

200.

Свободно:

0.

Правильный ответ:

0.

---

# Важное отличие от расчёта сдачи

В этом вопросе не нужно отвечать, сколько вернуть игроку.

Нужно ответить, сколько реально выставить в поле с выигрышных серий.

Например:

серия играет по 80;

свободная ёмкость позиции — 30.

Ответ:

30.

Не нужно добавлять в ответ:

80 − 30 = 50.

Эти 50 не являются суммой, которую нужно выставить в поле.

---

# Важное правило для нескольких серий

Если несколько выигрышных серий дают одну физическую позицию:

1. Сначала сложить значения «по сколько» этих серий.
2. Один раз определить сумму уже стоящих ставок.
3. Один раз определить лимит позиции.
4. Один раз вычислить свободную ёмкость.
5. Принять не больше свободной ёмкости.

Неправильно:

- сначала принять одну серию;
- затем заново рассчитать лимит для второй серии независимо;
- дважды использовать одну и ту же свободную ёмкость.

---

# Важное правило для разных позиций

Если выигрышные серии дают разные физические позиции, расчёт выполняется отдельно для каждой позиции.

Например:

- одна серия выигрывает на Straight;
- другая серия выигрывает на Split.

У каждой позиции свой лимит и своя свободная ёмкость.

После этого принятые суммы складываются в общий ответ.

---

# Отчёт при неправильном ответе

Показывать расчёт отдельно по каждой уникальной выигрышной позиции.

Для каждой позиции вывести:

- выигрышный номер;
- название выигрышной серии;
- первоначальную сумму на серии;
- по сколько играет серия;
- физическую выигрышную позицию;
- вклады всех выигрышных серий в эту позицию;
- сумму цветных ставок;
- сумму кэш-ставок;
- сумму комплитов;
- полную сумму поля;
- ранее возвращённую сдачу с поля, если она была;
- фактически занятую сумму;
- лимит позиции;
- свободную ёмкость;
- запрошенную сумму от серий;
- фактически принятую сумму.

Пример:

Выигрышная позиция: Straight 1

Orphelins:

- поставлено на серию: 400;
- играет по: 80.

Уже стоит на позиции:

- цвет: 20;
- кэш: 0;
- комплиты: 50;
- всего: 70.

Лимит Straight:

100.

Свободная ёмкость:

100 − 70 = 30.

Серия должна поставить:

80.

Фактически можно выставить:

30.

Вклад позиции в правильный ответ:

30.

---

# Отображение вопроса

Во время этого вопроса должны быть видны:

- выигрышный номер;
- активные серии на треке;
- ставки поля;
- цветные фишки;
- кэш-фишки;
- комплиты номера;
- комплиты дюжины.

Аттестуемый должен видеть ставки, которые уже занимают лимит выигрышной позиции.

Ставки «Соседи номера» не должны участвовать в расчёте, даже если визуально присутствуют.

---

# Обязательные тестовые сценарии

Проверить минимум следующие случаи:

1. Ни одна серия не сыграла — вопрос должен быть пропущен либо правильный ответ должен соответствовать текущему правилу условного показа вопроса.

2. Одна серия сыграла, позиция поля пустая — принимается вся сумма «по сколько».

3. Одна серия сыграла, на позиции есть цветные ставки, вся серия помещается.

4. Одна серия сыграла, на позиции есть кэш, вся серия помещается.

5. Одна серия сыграла, на позиции есть комплит, вся серия помещается.

6. На позиции одновременно есть цвет, кэш и комплит.

7. Сумма серии помещается только частично.

8. Позиция уже заполнена до максимума — ответ 0.

9. Поле первоначально превышало максимум — использовать фактически принятую сумму после ранее возвращённой сдачи.

10. Две выигрышные серии дают одну позицию, и обе помещаются полностью.

11. Две выигрышные серии дают одну позицию, но помещаются только частично.

12. Две выигрышные серии дают одну позицию, а позиция уже заполнена.

13. Несколько выигрышных серий дают разные позиции.

14. Невыигрышная активная серия не влияет на ответ.

15. Ставки «Соседи номера» не влияют на ответ.

16. Сдача с кратности серии не влияет на ответ.

17. Максимум рулетки отличается от 100.

18. Проверить Straight, Split, Street, Corner и Six Line, если такие позиции существуют в фактических раскладах серий.

19. Одинаковая физическая позиция с разным порядком номеров корректно объединяется.

20. В итоговом ответе складываются только фактически принятые суммы по уникальным выигрышным позициям.

---

# Что нельзя делать

Нельзя:

- всегда считать правильным ответом полное значение «по сколько играет серия»;
- игнорировать уже стоящие ставки;
- исключать комплиты из занятой суммы;
- учитывать только цвет и забывать кэш;
- учитывать только комплиты номера и забывать комплиты дюжины;
- добавлять в ответ непринятую часть серии;
- добавлять сдачу с кратности;
- учитывать невыигрышные серии;
- учитывать соседей;
- повторно возвращать сдачу с поля;
- дважды использовать свободную ёмкость одной позиции для разных серий.

После выполнения кратко сообщи:

- как определяется выигрышная серия;
- как определяется значение «по сколько»;
- как находятся реальные выигрышные позиции;
- как рассчитывается уже занятая сумма;
- как определяется свободная ёмкость;
- как объединяются несколько серий на одной позиции;
- почему правильный ответ теперь содержит только фактически выставляемую сумму.
