ЗАДАЧА

Нужно добавить экран настроек для режима рулетки перед экраном игрового поля.

Экран настроек должен открываться по отдельной кнопке “Настройки” из текущего интерфейса.

После заполнения настроек пользователь нажимает кнопку “Начать”, и приложение переходит на экран рулетки.

ДИЗАЙН

Сделать экран настроек в стиле текущего проекта Chicago 1932.

Важно:

* не делать белый минималистичный дизайн как на референсах;
* референсы нужны только для структуры формы;
* визуально экран должен быть частью текущего приложения;
* использовать текущие цвета, шрифты, фон, рамки, кнопки и общий стиль проекта.

ПОЛЯ НАСТРОЕК

На экране должны быть следующие поля:

1. Минимум рулетки

   * числовое поле
   * значение по умолчанию: 10

2. Максимум рулетки

   * числовое поле
   * значение по умолчанию: 1000

3. Количество ставок “Соседи номера”

   * числовое поле
   * значение по умолчанию: 50

4. Ставка на “5/8”

   * выпадающий список Да / Нет
   * значение по умолчанию: Нет

5. Ставка на “Orphelins”

   * выпадающий список Да / Нет
   * значение по умолчанию: Нет

6. Ставка на “Seria 0/2/3”

   * выпадающий список Да / Нет
   * значение по умолчанию: Нет

7. Ставка на “Zero Spiel”

   * выпадающий список Да / Нет
   * значение по умолчанию: Нет

8. Номинал цвета на рулетке

   * числовое поле
   * значение по умолчанию: 10

9. Количество фишек цвета в поле

   * числовое поле
   * значение по умолчанию: 100

10. Сумма кэша на поле

* числовое поле
* значение по умолчанию: 1000

ПОВЕДЕНИЕ

1. Если пользователь ничего не ввёл в числовое поле, использовать значение по умолчанию.
2. Для выпадающих списков по умолчанию всегда использовать “Нет”.
3. После нажатия “Начать” настройки должны сохраняться в состоянии приложения.
4. Эти настройки должны передаваться на экран рулетки.
5. Пока не нужно реализовывать логику ставок — только экран настроек и передачу значений на экран рулетки.

ОГРАНИЧЕНИЯ

* Не ломать текущий экран рулетки.
* Не менять размеры, пропорции и координаты поля рулетки и трека.
* Не менять уже нанесённую сетку.
* Не удалять существующую логику.
* Вносить минимально необходимые изменения.
* Не добавлять имя игрока, поле имени пока не нужно.

КРИТЕРИИ ГОТОВНОСТИ

* В интерфейсе есть отдельная кнопка “Настройки”.
* По нажатию открывается экран настроек.
* Экран настроек выполнен в стиле Chicago 1932.
* Все 10 полей отображаются.
* У всех полей есть значения по умолчанию.
* При пустом вводе подставляется значение по умолчанию.
* По кнопке “Начать” происходит переход на экран рулетки.
* Настройки доступны на экране рулетки для будущей логики ставок.
