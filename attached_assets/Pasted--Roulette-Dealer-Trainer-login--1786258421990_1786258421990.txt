Продолжаем развитие Roulette Dealer Trainer небольшими этапами.

Уже выполнено:

* есть `/login`;
* есть `/manager`;
* есть `/dealer`;
* на `/manager` отображается список дилеров;
* руководитель может добавить нового дилера;
* дилеры сохраняются в `localStorage`;
* существующая Roulette работает без изменений.

Сейчас нужно выполнить только следующий этап: добавить страницу конкретного дилера в кабинете руководителя.

## 1. Новый маршрут

Добавь маршрут:

`/manager/dealers/:dealerId`

Он должен открывать страницу выбранного дилера.

Например:

`/manager/dealers/dealer-123`

## 2. Переход из списка дилеров

На странице `/manager` каждый дилер в списке должен стать кликабельным.

При нажатии на дилера открывается его страница:

`/manager/dealers/{id}`

Не нужно открывать дилера в новом окне.

## 3. Страница дилера

Создай отдельную страницу, например:

`DealerDetailsPage`

На ней показать:

* ФИО дилера;
* текст `Тренировок: 0`;
* кнопку `Создать тренировку`;
* кнопку или ссылку `Назад к списку дилеров`.

Пример:

```text
Иванов Иван Иванович

Тренировок: 0

[ Создать тренировку ]

[ Назад к списку дилеров ]
```

## 4. Получение дилера

Дилера нужно находить по `dealerId` из URL среди существующих данных в `localStorage`.

Не передавай весь объект Dealer через navigation state как единственный источник данных.

Страница должна корректно открываться и после прямого обновления браузера.

То есть сценарий должен работать:

1. открыть `/manager/dealers/{id}`;
2. обновить страницу;
3. дилер всё равно отображается.

## 5. Если дилер не найден

Если в URL указан неизвестный `dealerId`, покажи простой экран:

```text
Дилер не найден

[ Вернуться к списку ]
```

Не должно быть runtime error или пустого экрана.

## 6. Кнопка "Создать тренировку"

Добавь кнопку:

`Создать тренировку`

На этом этапе она пока НЕ должна создавать тренировку.

Можно:

* сделать её визуально активной, но с временным сообщением;
* либо оставить без действия.

Главное — подготовить место для следующего этапа.

Не создавай сейчас форму настроек тренировки.

## 7. Модель Dealer

Модель остаётся прежней:

```ts
type Dealer = {
  id: string;
  fullName: string;
};
```

Не добавлять:

* login;
* password;
* role;
* trainingIds;
* statistics;
* другие поля.

Количество тренировок пока просто отображать как `0`.

Позже тренировки будут отдельными сущностями и связываться с дилером через `dealerId`.

## 8. Архитектурное требование

Не хранить тренировки внутри Dealer.

В будущем структура должна быть примерно:

```text
Dealer
  id
  fullName

Training
  id
  dealerId
  gameType
  status
  config
```

Поэтому сейчас не нужно добавлять в Dealer массив вида:

```ts
trainings: []
```

## 9. Навигация

Должны работать переходы:

```text
/manager
   ↓
выбор дилера
   ↓
/manager/dealers/:dealerId
   ↓
Назад к списку
   ↓
/manager
```

## 10. Пока НЕ делать

Не нужно:

* создавать Training;
* создавать настройки тренировки;
* генерировать Spin;
* назначать тренировки;
* создавать логины или пароли дилера;
* редактировать дилера;
* удалять дилера;
* делать backend;
* делать API;
* делать PostgreSQL;
* делать настоящую авторизацию;
* менять `/dealer`;
* менять Roulette.

## 11. Roulette

Не вносить изменения в существующую Roulette.

Не менять:

* Spin;
* генерацию ставок;
* поле;
* racetrack;
* настройки;
* вопросы;
* звуки;
* дизайн.

## 12. Проверка

Проверь сценарии:

1. Открываю `/manager`.
2. Вижу список дилеров.
3. Нажимаю на `Иванов Иван Иванович`.
4. Открывается `/manager/dealers/{id}`.
5. На странице отображается правильное ФИО.
6. Отображается `Тренировок: 0`.
7. Есть кнопка `Создать тренировку`.
8. Есть возврат к списку.
9. Обновление страницы дилера не ломает экран.
10. Неизвестный `dealerId` показывает `Дилер не найден`.
11. Добавленные ранее через интерфейс дилеры также корректно открываются.
12. `/login`, `/dealer` и Roulette продолжают работать.

## 13. После выполнения

Кратко сообщи:

1. какие файлы созданы;
2. какие файлы изменены;
3. какой маршрут добавлен;
4. как происходит поиск дилера по `dealerId`;
5. что происходит при неизвестном `dealerId`;
6. подтверждение, что Roulette не изменялась.

Выполни только этот этап. Не переходи самостоятельно к созданию Training или настройкам тренировки.
