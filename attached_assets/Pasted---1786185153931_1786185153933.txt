Необходимо исправить совместную генерацию выигрышного номера для случаев, когда в раунде одновременно присутствуют:

- хотя бы одна ставка «Соседи номера»;
- хотя бы одна ставка на серию.

Сейчас возможна ситуация, когда серия играет, а ни одна ставка «Соседи номера» не играет.

Это неправильное поведение.

# Главное правило

Если одновременно присутствуют:

1. хотя бы одна активная серия;
2. хотя бы одна ставка «Соседи номера»,

то при наличии совместимых вариантов выигрышный номер должен удовлетворять ОБОИМ условиям:

- должна сыграть хотя бы одна активная серия;
- должна сыграть хотя бы одна ставка «Соседи номера».

То есть нельзя выбрать выигрышный номер только из покрытия серии, если при этом ни один сосед не играет.

Аналогично нельзя выбрать номер только для соседей, если ни одна серия не играет.

# Что означает «не противоречат друг другу»

Сначала необходимо получить:

- множество номеров, на которых играет хотя бы одна активная серия;
- множество номеров, на которых играет хотя бы одна ставка «Соседи номера».

После этого найти их пересечение.

Если пересечение НЕ пустое:

выигрышный номер необходимо выбирать только из этого пересечения.

Таким образом выбранный номер гарантированно:

- принадлежит минимум одной серии;
- принадлежит минимум одной ставке соседей.

# Формально

SERIES_NUMBERS =
объединение номеров всех активных серий.

NEIGHBOUR_NUMBERS =
объединение всех номеров, покрываемых активными ставками «Соседи номера».

COMMON_NUMBERS =
SERIES_NUMBERS ∩ NEIGHBOUR_NUMBERS.

Если:

COMMON_NUMBERS не пусто,

то:

winningNumber = случайный номер из COMMON_NUMBERS.

# Важно

Не требуется, чтобы сыграли:

- все серии;
- все соседи.

Минимальное требование:

- хотя бы одна серия;
- хотя бы одна ставка соседей.

Если выбранный номер одновременно попадает:

- в несколько серий;
- в несколько ставок соседей,

то все эти ставки естественным образом считаются выигрышными.

Не нужно искусственно ограничивать результат одной серией или одним соседом.

# Пример 1

Активна:

Orphelins.

Также есть несколько ставок «Соседи номера».

Предположим:

Orphelins содержит номера:

1, 6, 9, 14, 17, 20, 31, 34 и т.д.

А объединённое покрытие соседей содержит:

5, 6, 7, 8, 9, 16, 17, 18 и т.д.

Общие номера:

6, 9, 17.

Выигрышный номер необходимо случайно выбрать из:

6, 9, 17.

Например:

выпал 9.

Результат:

- Orphelins играет;
- минимум одна ставка соседей играет.

# Пример 2. Несколько серий

Активны:

- Serie 0/2/3;
- Zero Spiel.

Также присутствуют соседи.

Сначала объединить покрытие обеих серий.

Затем найти пересечение с покрытием всех соседей.

Например общий допустимый набор:

12, 15, 26, 32.

Случайно выбираем один номер.

Если выпал 12:

может сыграть только Serie 0/2/3 и один сосед.

Если выпал 26:

может сыграть Zero Spiel и один или несколько соседей.

Если выбран номер, принадлежащий обеим сериям:

играют обе серии.

Это допустимо.

# Serie 0/2/3 + Zero Spiel

Сохраняется ранее заданное правило:

если активны одновременно:

- Serie 0/2/3;
- Zero Spiel,

не требуется, чтобы обе серии обязательно сыграли.

После ограничения по соседям всё равно возможны варианты:

- Serie 0/2/3 + соседи;
- Zero Spiel + соседи;
- Serie 0/2/3 + Zero Spiel + соседи.

Главное:

при наличии серий и соседей хотя бы одна серия и хотя бы один сосед должны сыграть.

# Если активны все серии

Если активны все серии и присутствуют соседи:

не выбирать сначала одну серию и номер только из неё без учёта соседей.

Сначала найти все номера, на которых выполняется:

хотя бы одна серия
И
хотя бы один сосед.

После этого случайно выбрать выигрышный номер из полученного набора.

Какая именно серия сыграет, определяется выбранным номером.

# Если общего номера нет

Если:

SERIES_NUMBERS ∩ NEIGHBOUR_NUMBERS = пусто,

значит текущие сгенерированные серии и соседи несовместимы с обязательным правилом.

В этом случае нельзя просто выбрать номер серии и оставить соседей проигравшими.

Также нельзя выбрать номер соседей и оставить все серии проигравшими.

Необходимо повторно сгенерировать связанные ставки или весь раунд так, чтобы появился хотя бы один совместимый номер.

После повторной генерации снова проверить пересечение.

Не использовать бесконечный цикл — использовать существующий механизм ограничения повторных попыток генерации раунда.

# Если есть только серии

Если есть серии, но соседей нет:

работает существующее правило серий.

То есть минимум одна серия должна сыграть.

# Если есть только соседи

Если есть соседи, но серий нет:

работает существующее правило соседей.

То есть минимум одна ставка соседей должна сыграть.

# Если нет ни серий, ни соседей

Никаких дополнительных ограничений на выигрышный номер от этих типов ставок нет.

# Взаимодействие с комплитами

Это правило необходимо включить в общий механизм выбора выигрышного номера.

Если одновременно присутствуют:

- комплиты;
- серии;
- соседи,

нельзя сначала выбрать номер для комплита, а затем обнаружить, что соседи или серии не играют.

Необходимо определить общий набор допустимых выигрышных номеров с учётом всех обязательных ограничений.

Например:

COMPLETE_ALLOWED
∩
SERIES_NUMBERS
∩
NEIGHBOUR_NUMBERS.

Если пересечение существует:

случайно выбрать номер из него.

Если пересечения нет:

повторно сгенерировать связанные ставки/комплиты либо весь раунд.

# Итоговый приоритет правил

Использовать следующие обязательные условия:

Если есть соседи:

- минимум один сосед должен сыграть.

Если есть серии:

- минимум одна серия должна сыграть.

Если есть одновременно серии + соседи:

- должны сыграть И минимум одна серия, И минимум один сосед.

Если дополнительно есть комплиты с обязательным касанием выигрышного номера:

- выигрышный номер должен одновременно удовлетворять и этому условию.

Нельзя выполнять эти правила независимо друг от друга.

Они должны участвовать в одном общем выборе выигрышного номера.

# Финальная валидация

После окончательной генерации раунда обязательно проверить:

1. Если есть серии:
   - сыграла минимум одна серия.

2. Если есть соседи:
   - сыграла минимум одна ставка соседей.

3. Если есть серии + соседи:
   - выполнены оба предыдущих условия одновременно.

4. Если есть обязательные условия комплитов:
   - они также выполнены.

Если хотя бы одно обязательное условие нарушено:

раунд считается сгенерированным некорректно и должен быть пересоздан.

# Обязательные тесты

Проверить минимум:

1. Только серия — серия играет.

2. Только соседи — минимум один сосед играет.

3. Одна серия + один сосед, есть общий номер — играют оба.

4. Одна серия + несколько соседей — минимум один сосед и серия играют.

5. Несколько серий + один сосед — минимум одна серия и сосед играют.

6. Несколько серий + несколько соседей — минимум по одному источнику каждого типа играет.

7. Serie 0/2/3 + Zero Spiel + соседи — может сыграть только Serie 0/2/3 и сосед.

8. Serie 0/2/3 + Zero Spiel + соседи — может сыграть только Zero Spiel и сосед.

9. Serie 0/2/3 + Zero Spiel + соседи — могут сыграть обе серии и один или несколько соседей.

10. Все серии + соседи — минимум одна серия и минимум один сосед играют.

11. Есть общий номер нескольких соседей — могут сыграть несколько соседей.

12. Есть общий номер нескольких серий — могут сыграть несколько серий.

13. Нет пересечения между сериями и соседями — запускается повторная генерация.

14. Серии + соседи + комплит — выигрышный номер удовлетворяет всем активным обязательным правилам.

15. После генерации выполняется финальная проверка всех обязательных условий.

# Что нельзя менять

Не менять:

- состав серий;
- состав ставок «Соседи номера»;
- расчёт суммы серий;
- расчёт суммы соседей;
- кратности;
- визуальное отображение;
- экзаменационные вопросы.

Изменить только общий механизм определения выигрышного номера.

После выполнения кратко сообщи:

- как формируется пересечение номеров серий и соседей;
- как гарантируется выигрыш минимум одной серии и одного соседа;
- что происходит при отсутствии совместимых номеров;
- как это правило объединено с ограничениями комплитов.
