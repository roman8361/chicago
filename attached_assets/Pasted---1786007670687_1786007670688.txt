Необходимо исправить условие отображения параметра:

«Кратность комплитов»

на общем экране с текущими настройками игры.

# Текущая проблема

Сейчас значение «Кратность комплитов» отображается только в том случае, если в настройках включён комплит номера.

Если включён только комплит дюжины, параметр «Кратность комплитов» на общем экране не показывается.

Это неправильно, потому что кратность используется как для комплита номера, так и для комплита дюжины.

# Новое условие отображения

Параметр «Кратность комплитов» должен отображаться, если включён хотя бы один тип комплита:

- комплит номера;
- комплит дюжины.

Достаточно наличия любого одного типа комплита.

# Итоговая логика

Показывать «Кратность комплитов», если выполняется условие:

есть комплит номера
ИЛИ
есть комплит дюжины.

Не требовать обязательного наличия комплита номера.

# Когда параметр должен отображаться

Показывать значение в следующих случаях:

1. Включён только комплит номера.

2. Включён только комплит дюжины.

3. Одновременно включены комплит номера и комплит дюжины.

4. Включено несколько комплитов номера.

5. Включено несколько комплитов дюжины.

6. Одновременно присутствуют разные типы комплитов и другие ставки:
   - цвет;
   - кэш;
   - серии;
   - соседи.

Наличие других ставок не должно влиять на отображение кратности комплитов.

# Когда параметр не должен отображаться

Не показывать «Кратность комплитов» только в том случае, если полностью отсутствуют оба типа комплитов:

- нет комплита номера;
- нет комплита дюжины.

Например, параметр не должен отображаться, если присутствуют только:

- цветные ставки;
- кэш;
- серии;
- соседи.

# Важно

Проверять нужно наличие включённого или фактически созданного комплита в соответствии с тем же источником данных, который используется для отображения остальных параметров на общем экране.

Не привязывать отображение только к настройке комплита номера.

Желательно использовать общее логическое условие наличия комплитов, чтобы оно учитывало оба типа:

- номер;
- дюжина.

Если в проекте уже существует общий признак или функция вида «есть любой комплит», использовать её. Не создавать отдельные несовпадающие проверки в разных местах интерфейса.

# Что нельзя менять

Не менять:

- значение кратности комплитов;
- настройку кратности;
- генерацию комплитов номера;
- генерацию комплитов дюжины;
- алгоритмы расчёта ставок;
- отображение других параметров;
- порядок элементов общего экрана.

Изменить только условие видимости параметра «Кратность комплитов».

# Обязательные проверки

Проверить минимум:

1. Включён только комплит номера — кратность отображается.

2. Включён только комплит дюжины — кратность отображается.

3. Включены оба типа комплита — кратность отображается один раз.

4. Нет комплитов — кратность не отображается.

5. Есть только цвет — кратность не отображается.

6. Есть только кэш — кратность не отображается.

7. Есть только серии — кратность не отображается.

8. Есть только соседи — кратность не отображается.

9. Есть комплит дюжины и серии — кратность отображается.

10. Есть комплит дюжины и соседи — кратность отображается.

11. Есть комплит дюжины, цвет и кэш — кратность отображается.

12. При наличии двух типов комплитов строка «Кратность комплитов» не дублируется.

После выполнения кратко сообщи:

- какое новое условие используется для отображения кратности;
- подтверждение, что комплит дюжины теперь также включает отображение параметра;
- подтверждение, что значение и логика самой кратности не изменялись.
