Необходимо точечно доработать существующую генерацию цветных фишек.

ВАЖНО: новая логика должна только ДОПОЛНИТЬ текущую генерацию цвета. Все остальные существующие правила генерации цветных ставок оставить без изменений.

## Новое обязательное правило

Цветные фишки НЕ должны генерироваться:

* на физических позициях, уже занятых кэшем;
* на ВЫИГРАВШИХ физических позициях серий, относящихся к выпавшему номеру.

Все остальные позиции продолжают работать по текущей логике без изменений.

## 1. Позиции кэша

Для всех номеров поля сохраняется правило:

если конкретная физическая позиция уже занята кэшем, цвет на неё не ставить.

Например:

Split 17-20 занят кэшем.

Цвет на Split 17-20 не генерировать.

При этом другие позиции вокруг 17 или 20 остаются доступными, если они не запрещены другими правилами.

## 2. Выигрышные позиции серий

После определения winningNumber необходимо определить, какие активные серии сыграли и какие именно их физические позиции являются выигрышными для этого номера.

Именно эти выигрышные позиции необходимо исключить из генерации цвета.

Важно:

не нужно блокировать всю серию целиком.

Не нужно блокировать все позиции номера.

Исключается только конкретная физическая позиция серии, которая выигрывает при данном winningNumber.

## Пример 1 — Serie 5/8

Активна малая серия Serie 5/8.

Выпал номер:

5.

Для этой серии выигрышной является позиция:

Split 5-8.

Следовательно:

цветную фишку на Split 5-8 НЕ генерировать.

Но цвет может продолжать генерироваться:

* на Straight 5;
* на других Split вокруг 5;
* на Street;
* Corner;
* Six Line;

если эти позиции не заняты кэшем и не запрещены другими существующими правилами.

## Пример 2 — Zero Spiel

Активен Zero Spiel.

Выпал номер:

26.

В данной раскладке Zero Spiel выигрышной позицией является:

Straight 26.

Следовательно:

цветную фишку на Straight 26 НЕ генерировать.

Остальные выигрышные позиции №26 остаются доступными для цвета по текущей логике, если не заняты кэшем.

## Пример 3 — несколько серий

Если одновременно играют несколько серий и winningNumber создаёт несколько выигрышных физических позиций серий, необходимо исключить каждую такую позицию.

Например:

одна серия выигрывает на Split;

другая — на Straight.

Тогда цвет не генерировать на обе эти конкретные позиции.

Все остальные позиции остаются доступными.

## Пример 4 — пересечение с кэшем

Если выигрышная позиция серии уже занята кэшем, она и так недоступна для цвета.

Не нужно создавать дополнительную особую обработку или дублировать исключение.

Достаточно, чтобы итоговый набор запрещённых позиций для цвета содержал объединение:

* позиций кэша;
* выигрышных позиций активных серий для winningNumber.

## Как формировать запрещённые позиции

Перед генерацией цвета сформировать набор:

blockedColorPositions

В него включить:

1. Все физические позиции, занятые кэшем.

2. Все выигрышные физические позиции активных серий относительно winningNumber.

Далее текущий генератор цвета должен выбирать позиции только из тех, которых нет в blockedColorPositions.

## Важно про серии

Использовать существующую конфигурацию и карту реальных позиций серий.

Не определять выигрыш серии просто по наличию номера внутри условного списка.

Нужно определить конкретную физическую ставку серии, которая выигрывает.

Например:

если серия содержит Split 5-8 и выпал 5,

блокируется именно:

Split 5-8.

Не нужно автоматически блокировать:

Straight 5,
Straight 8
или все остальные ставки вокруг этих номеров.

## Если серия не сыграла

Если активная серия не выигрывает на текущем winningNumber, никакие её позиции не должны дополнительно блокироваться для цвета.

То есть проигравшие серии не влияют на генерацию цвета.

## Если серий нет

Если серии отсутствуют, генерация цвета работает как раньше с учётом остальных существующих ограничений, включая занятые кэшем позиции.

## Что нельзя менять

Не менять:

* количество цветных фишек;
* номинал цвета;
* количество номеров для генерации;
* существующую плотность генерации;
* алгоритм выбора типов ставок;
* правила комплитов;
* генерацию кэша;
* генерацию серий;
* генерацию соседей;
* winningNumber;
* расчёты сдачи и выплаты;
* экзаменационные вопросы.

Добавить только дополнительный фильтр запрещённых физических позиций.

## Итоговое правило

Цвет генерируется по текущему алгоритму, но позиция недоступна, если:

1. она занята кэшем;

ИЛИ

2. она является выигрышной физической позицией сыгравшей серии для текущего winningNumber.

Все остальные позиции остаются доступными.

## Обязательные проверки

Проверить минимум:

1. Кэш занимает позицию — цвет туда не генерируется.

2. Serie 5/8 + winningNumber 5 — цвет не генерируется на Split 5-8.

3. Zero Spiel + winningNumber 26 — цвет не генерируется на Straight 26.

4. Серия проиграла — её позиции не блокируют цвет.

5. Несколько сыгравших серий — блокируются все их выигрышные физические позиции.

6. Выигрышная позиция серии и кэш совпали — цвет всё равно не генерируется, без дублей и ошибок.

7. Остальные позиции winningNumber продолжают получать цвет по текущей логике.

8. Не блокируется весь номер из-за одной выигрышной позиции серии.

9. Не блокируется вся серия целиком.

10. При отсутствии серий генерация цвета остаётся прежней.

После выполнения кратко сообщи:

* как формируется список запрещённых позиций для цвета;
* как определяется конкретная выигрышная позиция серии;
* подтверждение, что блокируется только эта физическая позиция, а не весь номер или вся серия;
* подтверждение, что остальная генерация цвета не изменялась.
