ЗАДАЧА

Реализовать первый режим визуальной фокусировки (Focus Mode) для вопроса:

«Посчитайте сдачу с кратности приема ставок "комплит".»

Цель — помочь аттестуемому сразу понять, какие элементы стола участвуют в расчёте.

---

КОГДА АКТИВИРОВАТЬ

Режим включается автоматически только на вопросе:

«Посчитайте сдачу с кратности приема ставок "комплит".»

При переходе к следующему вопросу режим полностью отключается.

---

ЧТО ПОДСВЕЧИВАЕТСЯ

Все ставки "Комплит", присутствующие на поле.

Подсветка должна оставить их без изменений:

- яркость 100%;
- непрозрачность 100%;
- цвета без изменений;
- все суммы читаются как обычно.

Если комплитов несколько — подсвечиваются все.

---

ЧТО ЗАТЕМНЯЕТСЯ

Все остальные элементы игрового поля должны стать менее заметными.

В частности:

- весь трек;
- большие фишки серий;
- чёрные фишки соседей;
- цветные фишки;
- кэш-фишки;
- обычные ставки поля.

При этом элементы остаются видимыми.

Их нельзя скрывать полностью.

---

СТЕПЕНЬ ЗАТЕМНЕНИЯ

Рекомендуемая непрозрачность:

30–40%.

Например:

opacity: 0.35

или

filter: brightness(35%)

Главная задача — чтобы взгляд автоматически цеплялся именно за комплиты.

---

ЧТО НЕ ЗАТЕМНЯТЬ

Не затемнять:

- текст текущего вопроса;
- область ввода ответа;
- кнопки интерфейса;
- таймер (если есть).

Затемнение касается только рулеточного поля.

---

СПОСОБ РЕАЛИЗАЦИИ

Рекомендуется добавить единое состояние:

```ts
focusMode
```

Например:

```ts
type FocusMode =
    | "none"
    | "complete-multiplicity";
```

На первом вопросе:

```ts
focusMode = "complete-multiplicity";
```

На остальных:

```ts
focusMode = "none";
```

Это позволит в дальнейшем легко добавлять новые режимы подсветки для других вопросов.

---

ПРАВИЛО ОТРИСОВКИ

При отрисовке каждого элемента проверять его принадлежность к активной группе.

Например:

```ts
const isHighlighted =
    focusMode === "complete-multiplicity"
        ? element.type === "complete"
        : true;
```

Если элемент относится к активной группе:

```ts
opacity = 1;
```

Если нет:

```ts
opacity = 0.35;
```

---

ПЛАВНОЕ ПЕРЕКЛЮЧЕНИЕ

При включении и отключении режима использовать небольшую анимацию.

Например:

```css
transition:
    opacity 180ms ease,
    filter 180ms ease;
```

Это сделает переключение значительно приятнее.

---

НЕ ИЗМЕНЯТЬ

Не менять:

- размеры элементов;
- положение элементов;
- цвета элементов;
- генерацию ставок;
- расчёты;
- выплаты;
- логику вопросов.

Изменяется только визуальный акцент.

---

КРИТЕРИИ ГОТОВНОСТИ

1. При вопросе «Посчитайте сдачу с кратности приема ставок "комплит"» все комплиты отображаются с обычной яркостью.
2. Все остальные элементы рулеточного поля затемняются примерно до 30–40% яркости.
3. Все элементы остаются видимыми и читаемыми.
4. После перехода к следующему вопросу затемнение полностью исчезает.
5. Переключение происходит плавно без мерцания.
6. Реализация выполнена через универсальный режим Focus Mode, чтобы в дальнейшем можно было добавить подсветку для остальных вопросов.
