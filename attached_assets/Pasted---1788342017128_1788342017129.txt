Нужно дополнить существующую логику таймера аттестации.

## Новое правило

После завершения каждого спина счётчик времени должен полностью обнуляться.

Каждый новый спин должен иметь собственный независимый отсчёт времени.

Например:

В настройках:

Время = 5 минут.

### Спин №1

При появлении первого вопроса запускается:

05:00 → 04:59 → 04:58...

Аттестуемый закончил спин за:

03:42.

Фиксируем фактическое время прохождения этого спина:

03:42.

После завершения спина активный таймер остановить и очистить его состояние.

### Спин №2

До появления первого вопроса нового спина таймер не должен продолжать отсчёт предыдущего спина.

При появлении первого вопроса Спина №2 запускается НОВЫЙ отсчёт:

05:00 → 04:59 → 04:58...

То есть каждый спин получает полный лимит времени из настроек.

## Важно

Обнулять необходимо не только визуальное значение таймера, но и внутреннее состояние:

- время старта предыдущего спина;
- elapsed time;
- remaining time;
- overtime;
- признак превышения времени;
- интервалы/таймеры предыдущего спина.

Данные уже завершённого спина при этом НЕ удалять.

Его фактическое время должно остаться сохранённым в результате/отчёте этого спина.

## Жизненный цикл

Для каждого спина:

1. Создан новый спин.
2. Таймер находится в начальном состоянии и ещё не идёт.
3. Появился первый вопрос.
4. Запоминаем новый `startTime`.
5. Запускаем обратный отсчёт от значения «Время» из настроек.
6. Пользователь проходит вопросы.
7. Ответил на последний вопрос.
8. Фиксируем фактическое время именно этого спина.
9. Останавливаем таймер.
10. Сохраняем результат времени в отчёте спина.
11. Сбрасываем активное состояние таймера.
12. Следующий спин начинает новый независимый цикл.

## Главное

Нельзя переносить время между спинами.

Если Спин №1 закончился на:

01:17

это НЕ означает, что Спин №2 должен начинаться с 01:17.

Спин №2 снова получает полное значение из настроек:

05:00.

Если Спин №1 закончен уже с превышением:

-02:15

Спин №2 всё равно начинается с:

05:00.

## Не менять

Не менять:

- настройку «Время»;
- момент запуска таймера — первый вопрос;
- обратный отсчёт;
- отрицательное время после 00:00;
- расчёт фактического времени;
- отображение времени в отчёте;
- вопросы и их порядок;
- остальные механики аттестации.

Добавить только корректный сброс таймера между спинами.

Проверить несколько последовательных спинов и убедиться, что каждый новый спин при появлении первого вопроса начинает отсчёт с полного значения «Время» из настроек.
