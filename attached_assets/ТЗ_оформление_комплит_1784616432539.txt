ЗАДАЧА

Исправить визуальное отображение выигрышного комплита номера 0.

---

ТЕКУЩАЯ ПРОБЛЕМА

Когда одновременно выполняются условия:

- выпадает номер 0;
- на номере 0 установлен комплит;

плашка выигрышного комплита растягивается на всю область ячейки Zero.

Из-за этого выигрышный комплит 0 визуально отличается от выигрышного комплита любого другого номера.

---

ТРЕБУЕМОЕ ПОВЕДЕНИЕ

Для выигрышного комплита 0 необходимо отображать обычную компактную плашку такого же размера, как плашка выигрышного комплита для номеров 1–36.

Плашка не должна повторять размеры и форму всей ячейки Zero.

Габаритные размеры должны быть одинаковыми для всех выигрышных комплитов:

- комплит 0;
- комплиты 1–36.

---

ЧТО НЕОБХОДИМО ИЗМЕНИТЬ

При отрисовке выигрышного комплита не использовать размеры ячейки номера в качестве размеров плашки.

Для номера 0 использовать те же фиксированные параметры плашки, которые применяются для остальных номеров:

- одинаковую ширину;
- одинаковую высоту;
- одинаковый радиус скругления;
- одинаковый размер символа `C`;
- одинаковую толщину рамки;
- одинаковые внутренние отступы.

Плашку комплита 0 необходимо расположить по центру области номера 0, но не растягивать до её границ.

---

РЕКОМЕНДУЕМАЯ РЕАЛИЗАЦИЯ

Вынести размеры плашки комплита в общую константу:

```ts
const COMPLETE_MARKER_SIZE = {
  width: 48,
  height: 48,
};

Использовать эту константу для всех номеров, включая 0:

const markerWidth = COMPLETE_MARKER_SIZE.width;
const markerHeight = COMPLETE_MARKER_SIZE.height;

const markerX = cellCenterX - markerWidth / 2;
const markerY = cellCenterY - markerHeight / 2;

Конкретные значения ширины и высоты взять из уже существующей плашки комплита обычного номера.

Не создавать отдельный увеличенный размер для Zero.

ЕСЛИ ИСПОЛЬЗУЕТСЯ SVG

Не использовать для плашки 0:

width={zeroCell.width}
height={zeroCell.height}

Вместо этого использовать размеры обычного маркера:

<rect
  x={zeroCenterX - completeMarkerWidth / 2}
  y={zeroCenterY - completeMarkerHeight / 2}
  width={completeMarkerWidth}
  height={completeMarkerHeight}
  rx={completeMarkerRadius}
/>

Символ C также центрировать относительно центра плашки:

<text
  x={zeroCenterX}
  y={zeroCenterY}
  textAnchor="middle"
  dominantBaseline="central"
>
  C
</text>

ЕСЛИ ИСПОЛЬЗУЕТСЯ HTML/CSS

Не задавать плашке комплита 0:

width: 100%;
height: 100%;

Для всех номеров использовать общий класс:

.complete-marker {
  width: var(--complete-marker-width);
  height: var(--complete-marker-height);
  position: absolute;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}

Для Zero не должно быть отдельного CSS-правила, растягивающего плашку на всю ячейку.

ОФОРМЛЕНИЕ ВЫИГРЫШНОГО КОМПЛИТА 0

Сохранить текущее оформление выигрышного комплита:

жёлтый фон;
голубая рамка;
крупный символ C;
отсутствие чёрной фишки поверх комплита.

Изменить только габаритные размеры плашки.

НЕ ИЗМЕНЯТЬ

размеры и геометрию самой ячейки Zero;
положение номера 0;
основную разметку рулеточного поля;
размеры плашек комплитов 1–36;
логику определения выигрышного номера;
логику генерации комплита;
расчёт выплат;
ставки, входящие в комплит 0;
отображение комплита, когда выиграл другой номер.

КРИТЕРИИ ГОТОВНОСТИ

При выпадении 0 и наличии комплита 0 отображается компактная плашка.
Плашка не растягивается на всю ячейку Zero.
Размер плашки комплита 0 совпадает с размером плашки любого номера 1–36.
Плашка расположена по центру области Zero.
Жёлтый фон, голубая рамка и символ C сохранены.
Геометрия самой ячейки Zero не изменилась.
Отображение остальных комплитов осталось без изменений.
