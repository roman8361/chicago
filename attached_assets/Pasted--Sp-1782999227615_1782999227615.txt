ЗАДАЧА

Нужно добавить генерацию комплитов на номера рулетки.

Генерация должна срабатывать после Spin, если в настройках включено правило:

Комплит в поле = Да

Если “Комплит в поле” = Нет, комплиты номеров не генерировать.

---

ИСПОЛЬЗУЕМЫЕ НАСТРОЙКИ

Использовать настройки:

1. Комплит в поле

   * Да / Нет

2. Количество комплитов сразу

   * число от 1 до 3
   * определяет, сколько комплитов номеров нужно сгенерировать

3. Минимум рулетки

4. Максимум рулетки

5. Комплит дюжины

   * Да / Нет

---

ПРАВИЛА ВЫБОРА НОМЕРОВ

Если включён “Комплит в поле”, нужно случайно выбрать номера от 0 до 36.

Количество выбранных номеров = значение настройки “Количество комплитов сразу”.

Правила:

* номера не должны повторяться;
* каждый комплит ставится строго на straight up выбранного номера;
* если на номер поставлен комплит, обычные цветные фишки не должны попадать на этот straight up;
* остальные обычные ставки поля могут генерироваться как раньше.

---

ПРАВИЛО ДЛЯ КОМПЛИТА ДЮЖИНЫ

Если включён “Комплит дюжины”:

1. В дюжине, где стоит фишка комплита дюжины, должен быть ровно один комплит номера.

2. Если “Количество комплитов сразу” = 1:

   * единственный комплит номера должен быть внутри выбранной дюжины.

3. Если “Количество комплитов сразу” = 2:

   * один комплит номера должен быть внутри дюжины с комплитом дюжины;
   * второй комплит номера должен быть в другой дюжине.

4. Если “Количество комплитов сразу” = 3:

   * один комплит номера должен быть внутри дюжины с комплитом дюжины;
   * остальные два комплита должны быть в двух других дюжинах;
   * в итоге три комплита должны находиться в трёх разных дюжинах.

Важно:

* В одной дюжине не должно быть больше одного комплита номера, если включён комплит дюжины.
* Номера комплитов не должны совпадать.

Дюжины:

1ST 12:
1–12

2ND 12:
13–24

3RD 12:
25–36

Число 0 не входит ни в одну дюжину.

Если включён “Комплит дюжины”, для распределения комплитов по дюжинам использовать только номера 1–36.

---

ПРАВИЛО ДЛЯ НУЛЯ

Если “Комплит дюжины” = Нет, комплит номера может быть сгенерирован на любом числе от 0 до 36, включая 0.

Если “Комплит дюжины” = Да, число 0 не использовать для комплитов номера, потому что оно не принадлежит ни одной дюжине.

---

ПОЛУЧЕНИЕ ДАННЫХ ИЗ JSON

После выбора номера нужно получить правило комплита из `rouletteRules.json` через `rouletteRulesService`.

Для выбранного номера взять:

* `chipsRequired`

Пример:

Для номера 17:

```json
"17": {
  "chipsRequired": 40,
  "payoutInChips": 392
}
```

Значит:

chipsRequired = 40

---

ГЕНЕРАЦИЯ СУММЫ КОМПЛИТА

Для каждого выбранного номера:

1. Взять случайное целое значение X в диапазоне:

от “Минимум рулетки” до “Максимум рулетки”

2. Умножить X на `chipsRequired` из JSON:

rawAmount = X × chipsRequired

3. Округлить сумму вниз до ближайшего числа, которое заканчивается на 5.

То есть итоговая сумма должна быть меньше или равна `rawAmount` и оканчиваться на 5.

Формула:

completeAmount = Math.floor((rawAmount - 5) / 10) * 10 + 5

---

17

Из JSON:

chipsRequired = 40

Диапазон рулетки:

5–200

Случайное X:

156

Расчёт:

156 × 40 = 6240

Округляем вниз до ближайшего числа, заканчивающегося на 5:

6235

Итоговая ставка комплита:

6235

ПРИМЕР 2

Номер комплита:

3

Из JSON:

chipsRequired = 27

Диапазон рулетки:

5–200

Случайное X:

77

Расчёт:

77 × 27 = 2079

Округляем вниз до ближайшего числа, заканчивающегося на 5:

2075

Итоговая ставка комплита:

2075

---

ОТОБРАЖЕНИЕ

Каждый комплит номера должен отображаться как специальная крупная фишка на straight up выбранного номера.

Требования:

* фишка ставится строго в центр номера;
* размер примерно в 3 раза больше обычной цветной фишки;
* внутри фишки отображается сумма комплита;
* стиль соответствует текущему дизайну Chicago 1932;
* фишка комплита должна визуально отличаться от обычных цветных фишек.

---

ВЗАИМОДЕЙСТВИЕ С ОБЫЧНЫМИ ФИШКАМИ

Если на номере стоит комплит, обычные цветные фишки не должны попадать на straight up этого номера.

Пример:

Если сгенерирован комплит на номер 17, обычные цветные фишки не должны ставиться на Straight Up 17.

Но обычные цветные фишки могут ставиться на другие позиции, даже если эти позиции касаются 17, например:

* Split 17-20
* Corner 14-15-17-18
* Street 16-17-18

На этом этапе запрещаем только прямое попадание обычной фишки в straight up номера комплита.

---

ВАЖНО

На этом этапе нужно только:

* сгенерировать комплиты;
* отобразить их;
* сохранить данные комплитов.

Пока НЕ нужно:

* считать выплату по комплитам;
* считать сдачу по комплитам;
* учитывать пересечения комплитов;
* учитывать пересечения комплитов с обычными ставками;
* добавлять комплиты в отчёт;
* спрашивать пользователя по комплитам.

---

ОГРАНИЧЕНИЯ

* Не менять геометрию рулеточного поля.
* Не менять координаты сетки.
* Не менять трек.
* Не менять генерацию серий.
* Не менять расчёт серий.
* Не менять выплату по обычным ставкам поля.
* Не менять экран правил.
* Не хардкодить `chipsRequired` в коде.
* Все данные комплитов брать из `rouletteRulesService`.
* Вносить минимально необходимые изменения.

---

КРИТЕРИИ ГОТОВНОСТИ

* Если “Комплит в поле” = Нет, комплиты номеров не появляются.
* Если “Комплит в поле” = Да, после Spin появляются комплиты номеров.
* Количество комплитов равно настройке “Количество комплитов сразу”.
* Количество комплитов может быть от 1 до 3.
* Номера комплитов не повторяются.
* Для каждого номера `chipsRequired` берётся из `rouletteRules.json`.
* Сумма комплита считается как X × chipsRequired.
* Итоговая сумма округляется вниз до ближайшего числа, заканчивающегося на 5.
* Комплит отображается крупной фишкой в центре выбранного номера.
* Если включён “Комплит дюжины”, один комплит номера обязательно находится в выбранной дюжине.
* Если включён “Комплит дюжины” и комплитов 2 или 3, они распределяются по разным дюжинам.
* Если включён “Комплит дюжины”, число 0 не используется для комплита номера.
* Обычные цветные фишки не ставятся на straight up номеров, где стоит комплит.
