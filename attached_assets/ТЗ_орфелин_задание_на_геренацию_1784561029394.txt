ЗАДАЧА

Добавить отдельное правило генерации суммы ставки для серии:

«Orphelins»

Новая сумма должна рассчитываться на основании максимальной ставки рулетки, количества ставок в серии Orphelins и кратности приёма серий.

---

ИСХОДНЫЕ ДАННЫЕ

Для расчёта использовать:

- `maxBet` — максимальная ставка рулетки;
- `seriesMultiplicity` — кратность приёма серий;
- количество ставок в Orphelins = 5.

Состав серии Orphelins не менять:

- straight 1;
- split 6/9;
- split 14/17;
- split 17/20;
- split 31/34.

Общее количество единиц ставки:

```text
5

НОВЫЙ АЛГОРИТМ

Шаг 1. Рассчитать нижнюю границу

Взять максимальную ставку рулетки и разделить на 1,5:

minAmountPerBet = maxBet / 1.5

Пример:

maxBet = 300

300 / 1.5 = 200
Шаг 2. Определить верхнюю границу

Верхняя граница равна максимальной ставке рулетки:

maxAmountPerBet = maxBet

Пример:

maxAmountPerBet = 300
Шаг 3. Выбрать случайную сумму на одну ставку

Случайным образом выбрать целое число в диапазоне:

от maxBet / 1.5 до maxBet включительно

Для диапазона рулетки 5–300:

диапазон генерации: 200–300

Пример случайного значения:

265

Минимальная ставка рулетки minBet в этом расчёте напрямую не используется.

Основой расчёта является только maxBet.

Шаг 4. Рассчитать общую сумму Orphelins

Умножить выбранную сумму на количество ставок серии:

rawOrphelinsAmount = randomAmountPerBet * 5

Пример:

265 × 5 = 1325
Шаг 5. Округлить сумму по кратности серии

Если полученная сумма не делится на seriesMultiplicity без остатка, округлить её вниз до ближайшего значения, которое делится на кратность без остатка.

Формула:

finalOrphelinsAmount =
  Math.floor(rawOrphelinsAmount / seriesMultiplicity)
  * seriesMultiplicity

Пример:

rawOrphelinsAmount = 1325
seriesMultiplicity = 50

1325 / 50 = 26.5

Math.floor(26.5) = 26

26 × 50 = 1300

Итоговая ставка на Orphelins:

1300

Результат:

Ставка Orphelins = 1300

ОКРУГЛЕНИЕ ГРАНИЦ

Максимальная ставка может не делиться на 1,5 без остатка.

Для нижней границы использовать округление вверх:

const minAmountPerBet = Math.ceil(maxBet / 1.5);

Верхняя граница остаётся максимальной ставкой:

const maxAmountPerBet = Math.floor(maxBet);

Пример:

maxBet = 305

305 / 1.5 = 203.333...

нижняя граница:
Math.ceil(203.333...) = 204

верхняя граница:
305

Диапазон генерации:

204–305

СЛУЧАЙНОЕ ЧИСЛО

Число должно выбираться целым и включать обе границы.

const randomIntInclusive = (
  min: number,
  max: number
): number => {
  return Math.floor(Math.random() * (max - min + 1)) + min;
};

РЕКОМЕНДУЕМАЯ РЕАЛИЗАЦИЯ

const ORPHELINS_CHIPS_COUNT = 5;

const generateOrphelinsAmount = (
  maxBet: number,
  seriesMultiplicity: number
): number => {
  if (!Number.isFinite(maxBet) || maxBet <= 0) {
    return 0;
  }

  if (
    !Number.isFinite(seriesMultiplicity) ||
    seriesMultiplicity <= 0
  ) {
    return 0;
  }

  const minAmountPerBet = Math.ceil(maxBet / 1.5);
  const maxAmountPerBet = Math.floor(maxBet);

  const randomAmountPerBet = randomIntInclusive(
    minAmountPerBet,
    maxAmountPerBet
  );

  const rawOrphelinsAmount =
    randomAmountPerBet * ORPHELINS_CHIPS_COUNT;

  const roundedAmount =
    Math.floor(
      rawOrphelinsAmount / seriesMultiplicity
    ) * seriesMultiplicity;

  return Math.max(seriesMultiplicity, roundedAmount);
};

Названия функций и переменных адаптировать под текущую структуру проекта.

ВАЖНО ПРО ОКРУГЛЕНИЕ

Использовать только округление вниз.

Правильно:

1325 при кратности 50 → 1300

Неправильно:

1325 → 1350

Даже если ближайшие значения сверху и снизу находятся на одинаковом расстоянии, всегда выбирать меньшее значение.

ПРОВЕРКА КРАТНОСТИ

Итоговая сумма обязательно должна удовлетворять условию:

finalOrphelinsAmount % seriesMultiplicity === 0

Примеры:

1300 % 50 = 0
1250 % 50 = 0
1350 % 50 = 0

МИНИМАЛЬНАЯ СУММА

После округления вниз итоговая сумма не должна стать равной нулю.

Защитное правило:

return Math.max(seriesMultiplicity, roundedAmount);

Это применяется только для некорректно маленьких значений максимума или слишком большой кратности.
