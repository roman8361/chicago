Необходимо изменить алгоритм проверки вопроса:

«Какую общую сумму нужно выставить в поле со ставок "Соседи номера"?»

Изменить нужно только алгоритм расчёта правильного ответа, отчёт и тесты этого вопроса.

Не менять:

- генерацию ставок «Соседи номера»;
- генерацию серий;
- генерацию комплитов;
- генерацию обычных ставок поля;
- алгоритмы остальных экзаменационных вопросов;
- порядок вопросов;
- максимум рулетки;
- кратность приёма соседей.

---

# Назначение вопроса

В этом вопросе необходимо определить, какую сумму дилер фактически может выставить в поле с выигрышных ставок «Соседи номера».

Важно:

Ответом является **не сумма ставок на соседях**, а только та часть выигрышной ставки соседей, которая ещё помещается в свободный лимит соответствующей выигрышной позиции.

Если свободного места меньше, чем должна играть ставка соседей, принимается только свободная часть.

---

# Что учитывать

В расчёте участвуют только:

- выигрышный номер;
- выигрышные ставки «Соседи номера»;
- сумма, по которой играет каждый выигрышный сосед;
- уже выставленные ставки поля;
- комплиты;
- выигрышные серии;
- максимум рулетки.

---

# Что считается уже выставленными ставками

При определении занятой ёмкости позиции учитывать:

- цветные ставки;
- кэш;
- комплиты номера;
- комплиты дюжины;
- выигрышные серии.

Выигрышные серии необходимо учитывать по фактически принятой сумме, которая была рассчитана в предыдущем вопросе:

«Какую общую сумму нужно выставить в поле с выигрышных серий?»

То есть учитывать не первоначальную ставку серии и не сумму на секторе, а именно ту сумму, которая реально выставляется в поле после проверки лимитов.

---

# Что не учитывать

Не учитывать:

- невыигрышные соседи;
- невыигрышные серии;
- сдачу с кратности соседей;
- сдачу с кратности серий;
- выплаты;
- коэффициенты выигрыша;
- проигравшие ставки поля.

---

# Шаг 1. Найти выигрышные ставки "Соседи номера"

Просмотреть все активные ставки соседей.

Определить, какие из них содержат выпавший номер.

Только эти ставки участвуют в расчёте.

Все остальные соседи полностью игнорируются.

---

Например:

Не изменять ограничение максимумом.

Сдачу здесь не учитывать.

Нас интересует только итоговая сумма, по которой играет сосед.

---

# Шаг 3. Если несколько соседей попадают в одну позицию

Несколько выигрышных соседей могут требовать поставить фишку в одну и ту же физическую позицию.

Такие позиции необходимо объединять.

Например:

выпал №6

соседи:

13 → играет по 40

17 → играет по 80

оба требуют поставить Straight 6.

Получаем:

40 + 80 = 120.

Именно эта сумма считается выигрышной ставкой соседей на данной позиции.

Проверка свободной ёмкости должна выполняться только один раз.

Нельзя отдельно принимать сначала одного соседа, потом второго.

---

# Шаг 4. Найти физическую выигрышную позицию

Использовать существующую карту ставок соседей.

Получить реальные позиции поля.

Например:

Straight

Split

Street

Corner

Six Line

В зависимости от того, какая позиция выигрывает у данного соседа.

---

# Шаг 5. Определить уже занятую сумму

Для каждой выигрышной позиции собрать:

цветные ставки
+
кэш
+
комплиты
+
выигрышные серии.

Комплиты необходимо развернуть в реальные позиции.

Серии учитывать только выигрышные и только по фактически принятой сумме.

Не использовать сумму первоначальной ставки серии.

---

# Шаг 6. Учесть ранее возвращённую сдачу поля

Если ранее сумма ставок поля превышала максимум,

лишняя часть уже была возвращена.

Следовательно,

занятая сумма позиции

равна

минимуму между:

- полной суммой ставок;
- лимитом позиции.

Или:

сумма поля
−
ранее возвращённая сдача.

Именно эта сумма считается уже занимающей лимит позиции.

---

# Шаг 7. Определить лимит

Использовать существующие коэффициенты:

Straight ×1

Split ×2

Street ×3

Corner ×4

Six Line ×6.

Лимит позиции:

максимум рулетки × коэффициент позиции.

---

# Шаг 8. Рассчитать свободную ёмкость

Свободная ёмкость:

лимит
−
занятая сумма.

Если результат меньше нуля,

использовать

0.

---

# Шаг 9. Определить принимаемую сумму соседей

Если сумма выигрышных соседей меньше либо равна свободной ёмкости,

принимается полностью.

Если больше,

принимается только свободная ёмкость.

Формула:

принятая сумма соседей

=

min(
сумма соседей,
свободная ёмкость
)

Если выигрышных позиций несколько,

правильный ответ

—

сумма фактически принятых ставок соседей по всем уникальным позициям.

# Важное правило

Если несколько соседей дают одну физическую позицию,

необходимо:

1. сначала объединить суммы соседей;

2. затем проверить максимум;

3. затем проверить уже стоящие ставки;

4. только потом определить принимаемую сумму.

Нельзя рассчитывать каждого соседа отдельно.

# Обязательные тестовые сценарии

Проверить минимум следующие случаи:

1. Нет выигрышных соседей.

2. Один выигрышный сосед.

3. Один сосед, позиция пустая.

4. Один сосед, на позиции есть цвет.

5. Один сосед, на позиции есть кэш.

6. Один сосед, на позиции есть комплит.

7. Один сосед, на позиции есть выигрышная серия.

8. На позиции одновременно есть цвет, кэш, комплит и серия.

9. Несколько соседей дают одну позицию.

10. Сумма соседей меньше максимума.

11. Сумма соседей превышает максимум.

12. Позиция уже полностью заполнена.

13. Свободного места хватает только частично.

14. Поле ранее превышало максимум — использовать фактически принятую сумму.

15. Серии учитывать только выигрышные.

16. Проигравшие серии не учитывать.

17. Проверить Straight, Split, Street, Corner и Six Line.

18. Проверить разные значения максимума рулетки.
