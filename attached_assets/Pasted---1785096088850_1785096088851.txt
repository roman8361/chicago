Нужно добавить в экзамен новый вопрос:

«Какую общую сумму нужно поставить в номер с выигрышных ставок „комплит“?»

## Положение вопроса в экзамене

Этот вопрос должен задаваться сразу после вопроса:

«Посчитайте сдачу с пересечений ставок на треке со ставками на поле.»

Пример:

- если вопрос «Посчитайте сдачу с пересечений ставок на треке со ставками на поле.» имеет номер 5;
- новый вопрос должен получить номер 6;
- все следующие вопросы должны автоматически сдвинуться на один номер вперёд;
- нумерация должна оставаться последовательной без пропусков и повторов.

Не привязывать номер жёстко к значению 6. Номер должен определяться по позиции вопроса в актуальном списке.

---

# Условие появления вопроса

Этот вопрос задаётся только в том случае, если после выпадения выигрышного номера есть хотя бы одно выигрышное касание от комплита.

Проверять нужно только комплиты.

Не учитывать:

- серии;
- ставки «Соседи номера»;
- цветные ставки;
- кэш;
- обычные ставки на поле;
- ставки трека;
- пересечения комплитов с обычными ставками;
- пересечения комплитов со ставками трека.

Для решения вопроса важны только:

- выигрышный номер;
- активные комплиты;
- выигрышные касания этих комплитов;
- сумма, по которой играет каждый комплит;
- пересечения выигрышных касаний нескольких комплитов;
- максимум рулетки.

Если ни один комплит не даёт выигрышных касаний по выпавшему номеру, вопрос необходимо пропустить.

Следующий вопрос должен получить корректный порядковый номер без пустого шага.

---

# Назначение вопроса

Нужно определить общую сумму, которую дилер должен поставить непосредственно в выпавший номер с выигрышных ставок «комплит».

Для этого необходимо:

1. Найти все выигрышные касания всех активных комплитов.
2. Определить, по сколько играет каждое касание.
3. Учесть совпадающие физические позиции нескольких комплитов.
4. Для совпадающих позиций проверить лимит.
5. Если общая сумма на позиции превышает лимит, считать это касание играющим по максимуму.
6. Сложить значения всех выигрышных касаний.
7. Полученная сумма является правильным ответом.

---

# Что такое выигрышное касание

Каждый комплит должен быть развёрнут в реальные позиции:

- Straight;
- Split;
- Street;
- Corner;
- Six Line.

После выпадения номера выигрышными считаются только те позиции комплита, которые содержат выпавший номер.

Пример:

выпал №17.

Из полного расклада комплита №17 необходимо выбрать только позиции, которые выигрывают на №17.

Количество таких позиций определяется фактической картой комплита.

Нельзя использовать заранее заданное число касаний без проверки реального расклада.

---

# Шаг 1. Найти выигрышные комплиты

Просмотреть все активные комплиты номера.

Для каждого комплита определить, есть ли среди его реальных позиций ставки, содержащие выигрышный номер.

Если есть хотя бы одна такая позиция, комплит считается выигрышным и участвует в расчёте.

Комплиты, у которых нет ни одного выигрышного касания, полностью игнорируются.

---

# Шаг 2. Развернуть выигрышные комплиты в позиции

Для каждого выигрышного комплита получить список всех его выигрышных физических позиций.

Для каждой позиции сохранить:

- тип ставки;
- номера позиции;
- коэффициент лимита;
- сумму игры комплита;
- источник — номер комплита.

Сумма вклада комплита в позицию определяется так:

сумма позиции =
ставка комплита «по сколько»
× коэффициент типа позиции.

Использовать коэффициенты:

- Straight — 1;
- Split — 2;
- Street — 3;
- Corner — 4;
- Six Line — 6.

Примеры:

комплит играет по 50:

- Straight = 50;
- Split = 100;
- Street = 150;
- Corner = 200;
- Six Line = 300.

---

# Шаг 3. Нормализовать физические позиции

Одинаковые физические позиции разных комплитов должны объединяться.

Для этого использовать нормализованный ключ позиции:

- Straight: тип + один номер;
- Split: тип + два номера в отсортированном порядке;
- Street: тип + три номера в нормализованном порядке;
- Corner: тип + четыре номера в нормализованном порядке;
- Six Line: тип + шесть номеров в нормализованном порядке.

Например:

- Split 17–20 и Split 20–17 — одна позиция;
- Six Line 16–21 у двух комплитов — одна позиция;
- Corner 17–18–20–21 у двух комплитов — одна позиция.

Нельзя объединять позиции только по выигрышному номеру.

Straight, Split, Street, Corner и Six Line являются разными физическими позициями.

---

# Шаг 4. Рассчитать общую сумму по каждой выигрышной позиции

Для каждой уникальной выигрышной позиции сложить вклады всех комплитов.

Например:

Six Line 16–21:

- комплит №17 играет по 50:
  6 × 50 = 300;
- комплит №20 играет по 70:
  6 × 70 = 420.

Общая ставка:

300 + 420 = 720.

---

# Шаг 5. Проверить лимит позиции

Лимит позиции:

максимум рулетки × коэффициент типа позиции.

Например, при максимуме 100:

- Straight — 100;
- Split — 200;
- Street — 300;
- Corner — 400;
- Six Line — 600.

Если общая ставка на физической позиции не превышает лимит, каждое касание продолжает играть по своей исходной ставке комплита.

Если общая ставка превышает лимит, данная физическая позиция считается играющей по максимуму.

Для итоговой постановки в выигрышный номер такое касание даёт:

максимум рулетки.

Важно:

независимо от типа исходной позиции одно выигрышное касание, достигшее лимита позиции, даёт в номер одну ставку, равную максимуму рулетки.

Пример:

Corner:

- комплит №17 по 50:
  4 × 50 = 200;
- комплит №20 по 70:
  4 × 70 = 280;
- всего 480;
- лимит Corner при максимуме 100 = 400.

Позиция превышает лимит.

Следовательно, это одно выигрышное касание играет по максимуму и в итог даёт 100.

Не добавлять отдельно 50 и 70.

---

# Шаг 6. Рассчитать значение каждого выигрышного касания

Для каждой уникальной выигрышной физической позиции:

## Если позиция не превысила лимит

Если позиция принадлежит только одному комплиту:

вклад в итог =
«по сколько» этого комплита.

Если одинаковая позиция принадлежит нескольким комплитам, но общая сумма не превысила лимит:

вклад в итог =
сумма значений «по сколько» всех участвующих комплитов.

Пример:

два комплита играют по 30 и 40 на одной позиции.

Если лимит не превышен:

вклад этого касания в номер = 70.

## Если позиция достигла или превысила лимит

Если общая сумма позиции равна лимиту или превышает его:

вклад касания в итог =
максимум рулетки.

Проверку использовать так:

если общая ставка позиции >= лимит позиции,

позиция играет по максимуму.

Это важно для случаев, когда ставка ровно достигла лимита.

---

# Шаг 7. Рассчитать общий ответ

Правильный ответ:

сумма значений всех уникальных выигрышных касаний.

Формула:

общая сумма в номер =
сумма касаний, играющих по максимуму
+
сумма остальных касаний по фактической игре комплитов.

Каждая уникальная физическая позиция учитывается только один раз.

---

# Пример 1. Один выигрышный комплит

Максимум рулетки:

100.

Выпал №17.

Есть комплит №17, который играет по 50.

У комплита №17 по выигрышному номеру найдено:

12 выигрышных касаний.

Пересечений с другими комплитами нет.

Все позиции находятся в пределах лимитов.

Расчёт:

12 × 50 = 600.

Правильный ответ:

600.

---

# Пример 2. Два комплита и позиции по максимуму

Максимум рулетки:

100.

Выпал №18.

На поле:

- комплит №17 играет по 50;
- комплит №20 играет по 70.

Выигрышные касания:

- 6 касаний от комплита №17;
- 2 касания от комплита №20.

Два касания являются общими физическими позициями двух комплитов:

- Six Line 16–21;
- Corner, общий для комплитов №17 и №20.

## Six Line

Комплит №17:

6 × 50 = 300.

Комплит №20:

6 × 70 = 420.

Общая ставка:

720.

Лимит:

6 × 100 = 600.

Позиция играет по максимуму.

Вклад в ответ:

100.

## Corner

Комплит №17:

4 × 50 = 200.

Комплит №20:

4 × 70 = 280.

Общая ставка:

480.

Лимит:

4 × 100 = 400.

Позиция играет по максимуму.

Вклад в ответ:

100.

После объединения двух общих позиций остаются ещё четыре уникальных касания комплита №17 по 50.

Расчёт:

2 × 100
+
4 × 50
=
400.

Правильный ответ:

400.

Важно:

два касания комплита №20 уже вошли в две общие позиции и не должны учитываться повторно как отдельные касания по 70.

---

# Пример 3. Несколько пересечений

Максимум рулетки:

100.

Выпал №8.

На поле:

- комплит №9 играет по 50;
- комплит №7 играет по 70.

Найдены:

- 3 общих физических касания двух комплитов, которые играют по максимуму;
- 3 уникальных касания комплита №9 по 50;
- 3 уникальных касания комплита №7 по 70.

Расчёт:

3 × 100
+
3 × 50
+
3 × 70
=
300 + 150 + 210
=
660.

Правильный ответ:

660.

---

# Важное правило против двойного учёта

Если физическая позиция входит сразу в несколько комплитов:

1. Она объединяется в одну позицию.
2. Проверяется её общий лимит.
3. В итог добавляется один раз.
4. Исходные касания участвующих комплитов отдельно больше не добавляются.

Например:

общий Six Line двух комплитов — это одно итоговое касание, а не два.

---

# Что нельзя учитывать

В этом вопросе нельзя добавлять:

- суммы обычных ставок;
- цветные фишки;
- кэш;
- ставки серий;
- ставки «Соседи номера»;
- сдачу из предыдущих вопросов;
- выплаты по выигрышу;
- полный номинал физической позиции;
- коэффициент выплаты рулетки.

Нужно считать только сумму, которую надо поставить в выигрышный номер с выигрышных касаний комплитов.

---

# Отображение вопроса

Во время этого вопроса необходимо использовать режим:

WINNING_NUMBER_AND_COMPLETE_ONLY.

Должны быть хорошо видны:

- выигрышный номер;
- все активные комплиты;
- их фишки и обозначения;
- выигрышные касания комплитов.

Нужно затемнить или визуально убрать из фокуса:

- трек;
- серии;
- соседей;
- обычные цветные ставки;
- кэш.

Фишки комплитов нельзя затемнять.

---

# Отчёт

При неправильном ответе показать:

1. Выпавший номер.
2. Все выигрышные комплиты.
3. По сколько играет каждый комплит.
4. Все уникальные выигрышные позиции.
5. Источники каждой позиции.
6. Общую сумму ставки на позиции.
7. Лимит позиции.
8. Играет ли позиция по максимуму.
9. Вклад позиции в итоговую сумму.
10. Общий правильный ответ.

Пример блока:

Six Line 16–21

- Комплит №17, по 50: 300
- Комплит №20, по 70: 420
- Общая ставка: 720
- Лимит Six Line: 600
- Позиция играет по максимуму
- В номер поставить: 100

Пример обычного касания:

Split 17–20

- Комплит №17, по 50: 100
- Лимит Split: 200
- Превышения нет
- В номер поставить: 50

---

# Обязательные тестовые сценарии

Проверить минимум следующие случаи:

1. Нет выигрышных комплитов — вопрос пропускается.

2. Есть комплит, но его позиции не содержат выигрышный номер — вопрос пропускается.

3. Один выигрышный комплит без пересечений.

4. Один выигрышный комплит, одна из его позиций ровно достигает лимита.

5. Один выигрышный комплит, одна из его позиций превышает лимит.

6. Два комплита имеют одну общую выигрышную позицию, лимит не превышен.

7. Два комплита имеют одну общую выигрышную позицию, лимит превышен.

8. Два комплита имеют несколько общих выигрышных позиций.

9. Общий Six Line двух комплитов.

10. Общий Corner двух комплитов.

11. Общий Street двух комплитов.

12. Общий Split двух комплитов.

13. Общий Straight двух комплитов, если такая ситуация возможна по текущей карте.

14. Позиция, записанная с разным порядком номеров, корректно объединяется.

15. Общая позиция учитывается один раз и не дублируется в уникальных касаниях комплитов.

16. Одновременно есть уникальные касания по разным значениям и касания по максимуму.

17. Максимум рулетки отличается от 100.

18. Есть ставки трека и обычные ставки поля — они не влияют на ответ.

19. После условного пропуска вопроса нумерация следующих вопросов остаётся последовательной.

20. При наличии выигрышного комплита новый вопрос идёт сразу после вопроса «Посчитайте сдачу с пересечений ставок на треке со ставками на поле.»

---

# Что нельзя менять

Не менять:

- состав и расклад комплитов;
- генерацию комплитов;
- значение «по сколько»;
- максимум рулетки;
- алгоритмы остальных вопросов;
- генерацию поля;
- генерацию трека;
- порядок остальных вопросов, кроме автоматического сдвига номеров;
- итоговую оценку экзамена, кроме добавления нового условного вопроса.

После выполнения кратко сообщи:

- как определяется наличие выигрышного комплита;
- как формируется список уникальных выигрышных касаний;
- как определяется касание по максимуму;
- как исключён двойной учёт общих позиций;
- как работает условная нумерация вопросов.
