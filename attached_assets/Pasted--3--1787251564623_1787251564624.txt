Необходимо доработать существующую генерацию для случая, когда в настройках выбрано 3 комплита номера.

ВАЖНО: новое требование должно ДОПОЛНИТЬ существующую реализацию, а не заменить уже работающие правила для одного и двух комплитов.

Существующие требования для первых двух комплитов должны сохраниться:

- оба задевают выигрышный номер;
- оба пересекаются между собой;
- по возможности имеют разное значение «по сколько играет комплит»;
- если получить разные значения невозможно из-за min/max рулетки и кратности комплитов, одинаковое значение разрешается.

Новая логика касается именно ТРЕТЬЕГО комплита.

# Основные требования для третьего комплита

Третий комплит должен:

1. ОБЯЗАТЕЛЬНО не пересекаться с выигрышным номером.

2. По возможности иметь другое значение «по сколько играет комплит».

3. Если в игре присутствует несколько серий и среди них есть проигравшая серия, третий комплит по возможности должен относиться именно к проигравшей серии.

При этом требования имеют разный приоритет.

---

# Приоритет 1 — третий комплит не должен пересекаться с выигрышным номером

Это обязательное условие, которое нельзя нарушать.

После разворачивания третьего комплита в реальные позиции:

- Straight;
- Split;
- Street;
- Corner;
- Six Line

ни одна выигрышная позиция этого комплита не должна содержать winningNumber.

Важно проверять именно реальные физические позиции комплита, а не только номер, на котором находится сам комплит.

Например:

выпал №17.

Если комплит стоит на другом номере, но среди его позиций присутствует Split, Street, Corner или Six Line, который выигрывает на №17, такой комплит нельзя использовать в качестве третьего.

---

# Приоритет 2 — проигравшая серия

Это новое дополнительное правило.

Если в игре присутствует несколько активных серий, после окончательного определения winningNumber необходимо определить:

- какие серии сыграли;
- какие серии проиграли.

Если существует хотя бы одна проигравшая серия, третий комплит желательно выбирать таким образом, чтобы он входил в одну из проигравших серий.

Но только если это возможно без нарушения обязательного правила:

третий комплит НЕ пересекается с выигрышным номером.

То есть сначала определяем допустимые комплиты, которые не задевают winningNumber, и уже среди них ищем комплиты, относящиеся к проигравшим сериям.

---

# Пример

В игре стоят несколько серий:

- Serie 5/8;
- Orphelins.

Выпал номер, при котором:

- Serie 5/8 сыграла;
- Orphelins проиграла.

При выборе третьего комплита сначала исключаем все комплиты, которые имеют касание с выигрышным номером.

После этого среди оставшихся кандидатов проверяем, какие подходят под Orphelins.

Если такие кандидаты существуют:

третий комплит выбираем случайно среди них.

Таким образом третий комплит:

- не играет;
- находится в проигравшей серии.

---

# Если проигравших серий несколько

Например активны:

- Serie 5/8;
- Orphelins;
- Serie 0/2/3;
- Zero Spiel.

После выпадения номера:

- Serie 5/8 сыграла;
- Orphelins проиграла;
- Serie 0/2/3 проиграла;
- Zero Spiel проиграла.

Тогда для третьего комплита доступны три проигравшие серии.

Не нужно всегда отдавать приоритет одной конкретной серии.

Необходимо сформировать допустимых кандидатов из проигравших серий и выбирать случайно.

В разных генерациях третий комплит может относиться к разным проигравшим сериям.

---

# Если несколько серий сыграли

Например:

- Serie 0/2/3 сыграла;
- Zero Spiel сыграл;
- Orphelins проиграл.

Тогда при наличии подходящих кандидатов третий комплит должен относиться к Orphelins.

Не выбирать его специально из сыгравших Serie 0/2/3 или Zero Spiel, если существует корректный вариант в проигравшей серии.

---

# Если подходящего комплита в проигравшей серии нет

Это правило НЕ должно ломать остальные ограничения.

Если среди проигравших серий невозможно подобрать третий комплит, который одновременно:

- не пересекается с winningNumber;
- удовлетворяет остальным существующим ограничениям генерации,

тогда требование проигравшей серии разрешается игнорировать.

В таком случае третий комплит выбирается из остальных допустимых кандидатов.

Главное обязательное правило сохраняется:

ТРЕТИЙ КОМПЛИТ НИКОГДА НЕ ДОЛЖЕН ПЕРЕСЕКАТЬСЯ С ВЫИГРЫШНЫМ НОМЕРОМ.

Не нужно ради попадания в проигравшую серию нарушать это условие.

---

# Если активна только одна серия

Если присутствует только одна серия, специальное требование проигравшей серии не применять.

Сохраняются обычные правила третьего комплита:

- не пересекается с выигрышным номером;
- по возможности имеет другое значение «по сколько».

---

# Если серий нет

Если серий вообще нет, правило проигравшей серии полностью игнорируется.

Генерация третьего комплита продолжается по остальным правилам.

---

# Приоритет 3 — другое значение «по сколько играет»

После выбора подходящего номера третьего комплита необходимо определить его ставку.

По возможности значение «по сколько играет» должно отличаться от значений первых двух комплитов.

Например доступны:

20, 30, 40, 50, 60.

Первый комплит:

40.

Второй:

60.

Для третьего желательно использовать:

20, 30 или 50.

Конкретное значение выбирается случайно.

---

# Если уникального значения для третьего комплита нет

Если доступно только два значения:

50 и 100,

а первые два комплита уже используют:

50 и 100,

третий может получить:

50

или

100.

Это допустимо.

Если существует только одно допустимое значение:

100,

то все три комплита могут играть по 100.

Не пытаться искусственно создавать другое значение за пределами существующих правил.

---

# Итоговый приоритет требований для третьего комплита

Использовать именно такой порядок:

1. ОБЯЗАТЕЛЬНО:
   третий комплит не пересекается с winningNumber.

2. ПО ВОЗМОЖНОСТИ:
   если активны несколько серий и есть проигравшая серия, третий комплит должен находиться в проигравшей серии.

3. ПО ВОЗМОЖНОСТИ:
   третий комплит должен иметь другое значение «по сколько играет».

При этом нельзя ради требований 2 или 3 нарушать требование 1.

Также нельзя нарушать другие ранее реализованные обязательные ограничения генерации.

---

# Последовательность генерации

1. Определить winningNumber с учётом существующих правил.

2. Определить первый комплит по существующей логике.

3. Определить второй комплит:
   - задевает winningNumber;
   - пересекается с первым;
   - по возможности имеет другое значение «по сколько».

4. Перед генерацией третьего комплита определить результат активных серий относительно winningNumber.

5. Разделить серии на:
   - выигравшие;
   - проигравшие.

6. Получить кандидатов для третьего комплита.

7. Исключить ВСЕ комплиты, которые пересекаются с winningNumber.

8. Если активны несколько серий и есть проигравшие серии:
   - найти среди оставшихся кандидатов комплиты, относящиеся к проигравшим сериям;
   - если такие есть — выбирать третий комплит только среди них.

9. Если подходящих кандидатов в проигравших сериях нет:
   - использовать остальных допустимых кандидатов;
   - не нарушать обязательные правила ради серии.

10. После выбора номера третьего комплита определить его значение «по сколько».

11. Если возможно получить значение, отличное от первых двух, выбрать другое значение.

12. Если невозможно — разрешить совпадение.

---

# Важно про определение серии

Использовать существующую конфигурацию серий.

Не создавать отдельные захардкоженные списки номеров специально для генерации третьего комплита.

Определение:

- входит ли комплит в серию;
- сыграла ли серия;
- проиграла ли серия

должно основываться на тех же правилах и конфигурации, которые уже используются приложением.

---

# Пример полного сценария

Допустим активны:

- Serie 5/8;
- Orphelins;
- Serie 0/2/3.

После определения winningNumber:

- Serie 5/8 сыграла;
- Orphelins проиграла;
- Serie 0/2/3 проиграла.

Первые два комплита уже выбраны и оба задевают winningNumber.

Теперь выбираем третий.

Шаг 1.

Исключаем все комплиты, которые хоть каким-либо касанием пересекаются с winningNumber.

Шаг 2.

Среди оставшихся ищем комплиты, относящиеся к:

- Orphelins;
- Serie 0/2/3.

Шаг 3.

Если кандидаты есть, случайно выбираем одного из них.

Шаг 4.

После этого пытаемся дать ему значение «по сколько», отличное от первых двух.

Если это возможно — значения должны отличаться.

Если невозможно — совпадение разрешается.

В результате третий комплит:

- гарантированно не выигрывает;
- по возможности находится в проигравшей серии;
- по возможности имеет другую кратность приёма.

---

# Итоговая валидация

После генерации проверить:

- создано 3 комплита номера;
- номера комплитов различаются;
- первый комплит задевает winningNumber;
- второй комплит задевает winningNumber;
- первые два пересекаются между собой;
- третий комплит НЕ имеет ни одного выигрышного касания;
- если есть несколько серий и существует подходящий кандидат в проигравшей серии — третий комплит относится к проигравшей серии;
- если такого кандидата нет — отсутствие попадания в проигравшую серию допустимо;
- если возможно получить другое значение «по сколько» — оно используется;
- если невозможно — совпадение разрешено.

---

# Что нельзя менять

Не менять:

- генерацию одного комплита;
- существующую генерацию двух комплитов;
- правила выбора winningNumber;
- существующие правила серий;
- существующие правила соседей;
- генерацию комплита дюжины;
- диапазон генерации ставки;
- кратность комплитов;
- расчёты сдачи;
- расчёты выплат;
- экзаменационные вопросы.

Новое требование должно только ДОПОЛНИТЬ существующую генерацию трёх комплитов.

---

# Обязательные проверки

1. Третий комплит никогда не пересекается с winningNumber.

2. Есть две серии: одна сыграла, другая проиграла — при наличии подходящего кандидата третий комплит попадает в проигравшую серию.

3. Есть несколько проигравших серий — выбор между ними остаётся случайным.

4. Есть несколько серий, но все сыграли — правило проигравшей серии игнорируется.

5. Есть проигравшая серия, но все её подходящие комплиты пересекаются с winningNumber — правило серии игнорируется, третий комплит всё равно остаётся проигрышным.

6. Есть только одна серия — дополнительное правило проигравшей серии не применяется.

7. Серий нет — генерация работает по остальным правилам.

8. Есть возможность сделать все три значения «по сколько» разными — они различаются.

9. Нет возможности получить третье уникальное значение — совпадение разрешено.

10. Нельзя ради проигравшей серии сделать третий комплит выигрышным.

11. Нельзя ради другого значения ставки нарушить правило отсутствия пересечения с winningNumber.

12. Предыдущая логика первого и второго комплитов продолжает работать без изменений.

После выполнения кратко сообщи:

- как определяется проигравшая серия;
- как третий комплит подбирается под проигравшую серию;
- что происходит, если подходящего комплита в проигравшей серии нет;
- как обеспечивается отсутствие пересечения третьего комплита с winningNumber;
- когда разрешается одинаковое значение «по сколько»;
- подтверждение, что предыдущие требования генерации сохранены.
