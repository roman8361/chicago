Нужно исправить экран результата дилера в кабинете руководителя.

Сейчас Roulette на странице результата отображается слишком маленькой.

## Главное требование

Не делать отдельный уменьшенный вариант отчёта для руководителя.

Когда руководитель нажимает:

`Аттестация → дилер → Посмотреть результат`

нужно показать **один в один существующий экран «Отчёт по спину»**, который дилер видит после ответа на последний вопрос.

Переиспользуй существующий компонент/экран `Отчёт по спину`, а не создавай его уменьшенную копию.

Должны полностью сохраниться его:

* размеры Roulette;
* размеры игрового поля и racetrack;
* расположение элементов;
* первоначальные ставки;
* winningNumber;
* масштаб;
* блоки расчётов;
* вопросы;
* ответы дилера;
* правильные ответы;
* фактические расчёты;
* существующие ошибки/пояснения;
* общий внешний вид.

То есть визуально Manager должен видеть тот же отчёт, что и Dealer.

Разница только в источнике данных:

```text
Manager
→ assignmentId
→ RouletteExercise этого дилера
→ TrainingResult этого дилера
→ существующий "Отчёт по спину"
```

Ничего заново не генерировать.

Не запускать Spin, анимацию или звук.

Не показывать Settings/Spin и другие игровые действия.

### Важно

Не помещай существующий Roulette report внутрь маленькой карточки или контейнера с ограниченной шириной.

Используй те же размеры/layout, которые используются на настоящем экране `Отчёт по спину` у дилера.

Если сейчас manager result page имеет `max-width`, `scale`, уменьшенный wrapper или отдельный preview-компонент — убери это ограничение для самого отчёта.

Лучший вариант: вынести существующий `Отчёт по спину` в общий reusable-компонент и использовать его без изменений:

```text
Dealer ──┐
         ├── SpinReport
Manager ─┘
```

Для Manager сверху можно оставить только небольшую информацию:

* ФИО дилера;
* дата начала;
* дата завершения;
* итоговый результат.

А ниже — полноценный существующий `Отчёт по спину` в оригинальном размере.

Проверь:

1. отчет Manager визуально совпадает с отчетом Dealer;
2. Roulette имеет тот же размер;
3. ставки расположены идентично;
4. используются Exercise и Result выбранного дилера;
5. refresh сохраняет тот же отчёт;
6. ничего заново не генерируется;
7. обычный дилерский `Отчёт по спину` не изменился.

Не менять генераторы Roulette и игровую логику.
