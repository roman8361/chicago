ЗАДАЧА

Добавить второй сценарий Focus Mode для вопроса:

«Посчитайте сдачу с пересечений ставок "комплит" со ставками на поле, без учета трека.»

Для этого вопроса необходимо затемнить только трек.

Основное поле рулетки, ставки на поле и комплиты должны остаться в обычном виде, без дополнительного свечения и без мерцания.

---

ЛОГИКА ВИЗУАЛЬНОГО АКЦЕНТА

При появлении данного вопроса:

1. Затемняется только область трека.
2. Основное игровое поле не затемняется.
3. Все ставки на основном поле остаются яркими.
4. Все комплиты остаются яркими.
5. Свечение комплитов, которое использовалось в первом вопросе, отключается.
6. Пульсация и мерцание отсутствуют.

Так аттестуемый визуально понимает:

- комплиты участвуют в расчёте;
- ставки на основном поле участвуют в расчёте;
- трек в данном вопросе учитывать не нужно.

---

НОВЫЙ РЕЖИМ FOCUS MODE

Добавить отдельный режим:

```ts
type FocusMode =
    | "none"
    | "complete-multiplicity"
    | "complete-field-intersections";

Для второго вопроса:

focusMode = "complete-field-intersections";

ЧТО ЗАТЕМНЯЕТСЯ

Затемняется только весь трек, включая:

фон трека;
геометрию трека;
цифры трека;
названия серий;
фишки серий;
фишки ставок «соседи номера»;
другие ставки, расположенные внутри трека.

Все элементы трека должны находиться под единым полупрозрачным чёрным слоем.

Не уменьшать отдельно opacity фишек и текста трека.

ЧТО ОСТАЁТСЯ БЕЗ ИЗМЕНЕНИЙ

Не затемнять и не подсвечивать:

основное числовое поле;
Zero;
дюжины;
колонки;
внешние ставки основного поля;
цветные фишки;
кэш-фишки;
ставки комплитов;
буквы C;
суммы комплитов;
выигрышный номер.

Все эти элементы должны выглядеть так же, как в обычном режиме игры.

БЕЗ СВЕЧЕНИЯ КОМПЛИТОВ

Для режима:

"complete-field-intersections"

не применять класс свечения:

.complete-bet.focus-highlight

Не использовать:

filter: drop-shadow(...);
animation: complete-focus-glow ...;

Комплиты должны быть яркими только потому, что они не находятся под затемнением.

БЕЗ МЕРЦАНИЯ И ПУЛЬСАЦИИ

В этом режиме не должно быть:

анимации свечения;
изменения яркости;
пульсации;
мигания;
увеличения или уменьшения элементов.

Допускается только плавное одноразовое появление затемнения трека.

Например:

transition: opacity 180ms ease;

ЗАТЕМНЯЮЩИЙ СЛОЙ ТРЕКА

Не использовать общий overlay на всё рулеточное поле.

Необходимо создать отдельный overlay, который точно повторяет область трека.

Пример для HTML-контейнера:

.track-focus-overlay {
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.62);
    pointer-events: none;
    z-index: 40;
    transition: opacity 180ms ease;
}

Этот overlay должен находиться внутри контейнера трека, а не внутри контейнера всего стола.

Пример:

<div className="roulette-field">
    <MainBettingField />
    <CompleteBets />
</div>

<div className="roulette-track">
    <TrackBackground />
    <TrackNumbers />
    <TrackBets />

    {focusMode === "complete-field-intersections" && (
        <div className="track-focus-overlay" />
    )}
</div>

ЕСЛИ ТРЕК ОТРИСОВАН В SVG

Внутри SVG трека добавить затемняющий элемент после всех элементов трека:

<g id="track">
    <TrackBackground />
    <TrackGeometry />
    <TrackLabels />
    <TrackBets />

    {focusMode === "complete-field-intersections" && (
        <path
            className="track-focus-overlay"
            d={trackOverlayPath}
        />
    )}
</g>

CSS:

svg .track-focus-overlay {
    fill: rgba(0, 0, 0, 0.62);
    pointer-events: none;
}

Лучше использовать форму трека, а не прямоугольник, если прямоугольное затемнение выходит за границы овального трека.

ФОРМА ЗАТЕМНЕНИЯ

Затемняющий слой должен покрывать только визуальную область трека.

Не должно затемняться:

пространство между основным полем и треком;
основной стол;
фон приложения вокруг трека;
область вопросов и кнопок.

Если трек имеет овальную форму, затемняющий overlay должен повторять овальную форму трека.

Для HTML можно использовать:

.track-focus-overlay {
    border-radius: 50%;
    overflow: hidden;
}

Но предпочтительно использовать точный SVG-контур трека.

РАЗДЕЛЕНИЕ ДВУХ РЕЖИМОВ

Первый вопрос:

focusMode === "complete-multiplicity"

Поведение:

затемняется всё поле и трек;
комплиты отображаются поверх затемнения;
комплиты светятся.

Второй вопрос:

focusMode === "complete-field-intersections"

Поведение:

затемняется только трек;
поле остаётся обычным;
комплиты остаются обычными;
свечения нет.

Эти режимы не должны накладываться друг на друга.

ПРИМЕР УПРАВЛЕНИЯ КЛАССАМИ

const isCompleteMultiplicityFocus =
    focusMode === "complete-multiplicity";

const isCompleteFieldIntersectionFocus =
    focusMode === "complete-field-intersections";

Для комплитов:

<CompleteBets
    highlighted={isCompleteMultiplicityFocus}
/>

Для трека:

<Track>
    {isCompleteFieldIntersectionFocus && (
        <TrackDarkOverlay />
    )}
</Track>

ВАЖНО

При втором вопросе не нужно подсвечивать отдельные точки пересечения комплита со ставками на поле.

На текущем этапе достаточно:

оставить всё основное поле без изменений;
оставить комплиты без изменений;
затемнить только трек.

ПЕРЕХОД МЕЖДУ ВОПРОСАМИ

При переходе с первого вопроса на второй:

Удалить общий overlay всего стола.
Отключить свечение комплитов.
Добавить затемнение только поверх трека.

При переходе со второго вопроса на следующий:

focusMode = "none";

Затемнение трека должно полностью исчезнуть.

НЕ ИЗМЕНЯТЬ

Не менять:

геометрию поля;
геометрию трека;
положение элементов;
размеры ставок;
цвета ставок;
генерацию ставок;
расчёты;
правильный ответ;
порядок вопросов.

Изменяется только визуальное отображение во время второго вопроса.

КРИТЕРИИ ГОТОВНОСТИ

На втором вопросе затемняется только трек.
Затемняется весь трек вместе с расположенными на нём ставками.
Основное поле остаётся без затемнения.
Все ставки на основном поле остаются яркими.
Комплиты остаются яркими и без свечения.
Нет мерцания или пульсации.
Затемнение не выходит за границы трека.
Первый и второй режимы Focus Mode не конфликтуют.
При переходе к следующему вопросу затемнение трека исчезает.
