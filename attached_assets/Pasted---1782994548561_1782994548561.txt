ЗАДАЧА

Нужно добавить в приложение централизованный словарь правил рулетки.

Словарь правил должен быть единственным источником данных для:

* выплат;
* серий;
* соседей номера;
* комплитов;
* специальных правил ставок;
* количества фишек;
* делителей серий;
* правил расчёта сдачи.

---

ЦЕЛЬ

Не хранить правила ставок внутри компонентов интерфейса.

Все правила должны быть вынесены в отдельный JSON-файл, чтобы их можно было легко смотреть, править и расширять.

---

ФАЙЛ ПРАВИЛ

Создать отдельный файл, например:

roulette-rules.json

или

src/data/rouletteRules.json

Файл должен содержать структуру:

{
"version": "1.0.0",
"insideBets": {},
"trackBets": {},
"completeBets": {},
"neighbours": {},
"payouts": {}
}

---

БАЗОВАЯ СТРУКТУРА

1. payouts

Хранит коэффициенты выплат:

straightUp = 35
split = 17
street = 11
corner = 8
sixLine = 5

---

2. trackBets

Хранит правила серий:

Serie 5/8:

* label
* divisor = 6
* numbers
* settingKey
* displayZoneKey

Orphelins:

* label
* divisor = 5
* numbers
* settingKey
* displayZoneKey

Serie 0/2/3:

* label
* divisor = 9
* numbers
* settingKey
* displayZoneKey

Zero Spiel:

* label
* divisor = 4
* numbers
* settingKey
* displayZoneKey

---

3. completeBets

Хранит таблицу комплитов.

Для каждого номера 0–36 нужно хранить:

* number
* chipsRequired
* payoutInChips
* touchMap или winningTouches
* positions

На первом этапе можно заполнить только поля:

* number
* chipsRequired
* payoutInChips

из таблицы:

0:
chipsRequired = 17
payoutInChips = 235

1:
chipsRequired = 27
payoutInChips = 297

3:
chipsRequired = 27
payoutInChips = 297

2:
chipsRequired = 36
payoutInChips = 396

4–31 и 6–33:
chipsRequired = 30
payoutInChips = 294

5–32:
chipsRequired = 40
payoutInChips = 392

35:
chipsRequired = 24
payoutInChips = 264

34:
chipsRequired = 18
payoutInChips = 198

36:
chipsRequired = 18
payoutInChips = 198

---

4. neighbours

Пока создать пустую структуру для будущих правил соседей номера.

---

ЭКРАН ПРОСМОТРА ПРАВИЛ

В настройках добавить кнопку:

Правила игры

По нажатию открывать экран или секцию просмотра правил.

На этом этапе редактирование не нужно.

Только просмотр.

---

ИНТЕРФЕЙС ПРОСМОТРА

Экран “Правила игры” должен показывать:

1. Версию правил.
2. Раздел выплат.
3. Раздел серий.
4. Раздел комплитов.
5. Раздел соседей номера.

Можно отображать в виде карточек или таблиц.

Дизайн должен соответствовать текущему стилю Chicago 1932.

---

ВАЖНО

На этом этапе нужно только:

* создать JSON-словарь;
* подключить его в приложение;
* добавить экран просмотра;
* начать использовать payouts и trackBets из этого словаря там, где уже есть логика.

---

МИГРАЦИЯ СУЩЕСТВУЮЩЕЙ ЛОГИКИ

Если в коде сейчас хардкодятся коэффициенты:

35, 17, 11, 8, 5

их нужно заменить на значения из rouletteRules.payouts.

Если в коде хардкодятся делители серий:

6, 5, 9, 4

их нужно заменить на значения из rouletteRules.trackBets.

---

ОГРАНИЧЕНИЯ

* Не менять визуальную геометрию поля.
* Не менять координаты сетки.
* Не менять существующий Spin.
* Не менять уже работающую генерацию фишек.
* Не менять расчёт выплат, кроме замены хардкода на значения из словаря.
* Не добавлять редактирование правил.
* Не добавлять сохранение на сервер.
* Не добавлять базу данных.
* Правила пока должны быть локальным JSON-файлом проекта.

---

КРИТЕРИИ ГОТОВНОСТИ

* В проекте есть отдельный JSON-файл с правилами рулетки.
* Коэффициенты выплат берутся из JSON.
* Делители серий берутся из JSON.
* В настройках есть кнопка “Правила игры”.
* По кнопке открывается просмотр правил.
* Видны разделы выплат, серий, комплитов и соседей.
* Экран правил выполнен в стиле текущего проекта.
* Существующая логика Spin продолжает работать.
