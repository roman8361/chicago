Теперь необходимо убрать стрелки увеличения/уменьшения значения из всех числовых полей ответов аттестуемого.

Требования:

1. Найти все поля ввода, которые показываются аттестуемому при ответе на вопросы.

Это могут быть поля для ввода:

- суммы ставки;
- суммы сдачи;
- суммы постановки в поле;
- значения «по сколько играет»;
- количества фишек;
- других числовых ответов.

2. Во всех этих полях убрать встроенные стрелки ▲▼.

Пользователь должен вводить ответ только с клавиатуры.

3. Поля должны остаться числовыми:

```html
<input type="number" />

Не заменять type="number" на type="text".

Сохранить существующую логику:
проверку правильности ответа;
ограничения min и max;
обработку пустого значения;
блокировку недопустимых символов;
отправку ответа;
переход к следующему вопросу;
работу клавиши Enter.
Применить стили не только к настройкам, но и ко всему блоку аттестации.

Лучше использовать общий глобальный стиль для всех числовых полей приложения:

/* Chrome, Edge, Safari */
input[type="number"]::-webkit-outer-spin-button,
input[type="number"]::-webkit-inner-spin-button {
    -webkit-appearance: none;
    margin: 0;
}

/* Firefox */
input[type="number"] {
    -moz-appearance: textfield;
    appearance: textfield;
}
Если для настроек и вопросов используются разные компоненты или CSS-файлы, убедиться, что стиль подключён глобально и применяется в обоих местах.

Например, разместить его в:

index.css;
globals.css;
app.css;

а не только в локальных стилях компонента настроек.

Не менять внешний вид полей:
размеры;
высоту;
ширину;
рамку;
цвет;
шрифт;
отступы;
расположение.

Нужно убрать только стрелки.

Проверить все типы вопросов, в которых аттестуемый вводит числовой ответ, включая вопросы с несколькими полями.

Например:

первое поле — «по сколько играет»;
второе поле — «сдача»;
несколько ответов для разных серий.

Стрелок не должно быть ни в одном числовом поле.

Итоговый результат:

Во всех вопросах аттестуемому числовые поля отображаются без стрелок ▲▼. Ответ вводится только с клавиатуры, а существующая логика проверки и отправки ответа остаётся без изменений.
