ЗАДАЧА

Нужно изменить визуальное отображение комплитов номеров на основном поле рулетки.

Сейчас сгенерированный комплит номера отображается как большая чёрная кэш-фишка с суммой внутри.

Нужно убрать эту фишку и заменить её специальной подсветкой самого номера.

---

ОБЛАСТЬ ИЗМЕНЕНИЙ

Изменение относится только к:

- комплитам отдельных номеров от 0 до 36;
- настройке «Комплит в поле».

Не менять отображение:

- комплита дюжины;
- цветных фишек;
- кэш-фишек;
- серий;
- соседей;
- выпавшего номера.

Комплит дюжины пока оставить в текущем виде.

---

НОВОЕ ОТОБРАЖЕНИЕ КОМПЛИТА НОМЕРА

Если в текущем раунде сгенерирован комплит определённого номера:

1. Не показывать на этом номере чёрную фишку комплита.
2. Подсветить всю область Straight Up этого номера розовым цветом.
3. На фоне области номера показать большую букву:

C

Буква означает Complete.

---

ПОДСВЕТКА НОМЕРА

Подсветка должна занимать всю область конкретного номера согласно существующей сетке Straight Up.

Не создавать новую геометрию и не вычислять позицию приблизительно.

Использовать существующие координаты/границы номера.

Розовая подсветка должна быть похожа по принципу на существующую ярко-жёлтую подсветку выпавшего номера, но отличаться цветом и приоритетом.

Пример стиля:

- розовый или малиново-розовый фон;
- полупрозрачность, чтобы число оставалось читаемым;
- лёгкое внутреннее свечение;
- стиль должен соответствовать Chicago 1932.

Не использовать слишком яркий неоновый цвет.

---

БУКВА C

Внутри подсвеченной области номера показать большую букву:

C

Требования:

- буква находится по центру сектора;
- занимает значительную часть фона;
- не перекрывает полностью сам номер;
- имеет низкую прозрачность;
- слегка размыта;
- располагается позади текста номера и других активных элементов.

Пример визуальных параметров:

opacity: 0.2–0.35
filter: blur(1px–2px)
font-weight: bold

Использовать шрифт, совместимый с текущим стилем Chicago 1932 / Art Deco.

---

СЛОИ ОТОБРАЖЕНИЯ

Рекомендуемый порядок слоёв внутри сектора:

1. исходный фон номера;
2. розовая подсветка комплита;
3. размытая буква C;
4. штатный текст номера;
5. другие разрешённые элементы интерфейса.

Буква C не должна мешать чтению номера.

---

СУММА КОМПЛИТА

После удаления чёрной фишки сумма комплита всё равно должна быть сохранена в данных текущего раунда.

Не удалять:

- amount комплита;
- номер комплита;
- chipsRequired;
- данные для расчёта сдачи;
- данные для пересечений;
- данные для итоговой выплаты.

Меняется только визуальное представление.

Логика расчётов должна продолжать использовать исходную сумму комплита.

---

НЕ СОЗДАВАТЬ ФИШКУ

Для комплита номера на первоначальном поле больше не рендерить:

- чёрную кэш-фишку;
- большую фишку с суммой;
- текст суммы поверх номера.

Комплит обозначается только:

- розовой подсветкой;
- буквой C.

---

НЕСКОЛЬКО КОМПЛИТОВ

Если сгенерировано несколько комплитов номеров:

- каждый соответствующий номер подсветить отдельно;
- на каждом показать букву C;
- не объединять подсветки;
- не менять остальные номера.

---

КОМПЛИТ И ВЫПАВШИЙ НОМЕР

Возможен случай, когда номер с комплитом одновременно является выпавшим номером.

Нужно сохранить оба состояния визуально.

Приоритет:

- ярко-жёлтая подсветка выпавшего номера должна оставаться заметной;
- обозначение комплита буквой C не должно пропадать.

Рекомендуемый вариант:

- для фона использовать штатную жёлтую подсветку выигрышного номера;
- поверх или внутри оставить розовый контур/внутреннее свечение комплита;
- букву C оставить видимой на фоне.

Не заменять выигрышную жёлтую подсветку полностью розовой.

---

КОМПЛИТ И ДРУГИЕ СТАВКИ

Если на Straight Up номера с комплитом по другим правилам может находиться цветная или кэш-ставка, не менять бизнес-логику таких ставок.

Подсветка комплита должна находиться под фишками и не блокировать взаимодействие или отображение ставок.

---

ОТЧЁТ ПО РАУНДУ

На экране «Отчёт по раунду», где показываются первоначальные ставки, комплиты номеров также должны отображаться новым способом:

- розовая подсветка номера;
- буква C;
- без чёрной фишки.

Не возвращать старый вид комплита только на экране отчёта.

---

ОГРАНИЧЕНИЯ

- Не менять генерацию комплитов.
- Не менять сумму комплита.
- Не менять расчёт сдачи.
- Не менять пересечения.
- Не менять итоговую выплату.
- Не менять rouletteRules.json.
- Не менять геометрию поля.
- Не менять комплит дюжины.
- Изменить только визуальное отображение комплита номера.

---

КРИТЕРИИ ГОТОВНОСТИ

- Чёрная фишка комплита номера больше не отображается.
- Номер с комплитом подсвечивается розовым.
- На фоне номера отображается большая размытая буква C.
- Сам номер остаётся читаемым.
- Несколько комплитов подсвечиваются независимо.
- Совмещение комплита и выигрышного номера отображается корректно.
- Комплит дюжины остаётся без изменений.
- Все расчёты комплита продолжают работать как раньше.
