Необходимо изменить условие появления вопроса:

«Посчитайте сдачу с пересечений на треке серий и ставок „соседи номера“, без учета ставок на поле.»

# Новое условие

Вопрос должен задаваться, если на треке присутствует хотя бы один тип ставки:

- серии;
- «Соседи номера».

Для появления вопроса достаточно наличия любой одной ставки на треке.

# Когда вопрос должен задаваться

Вопрос должен появляться в следующих случаях:

- есть только серии;
- есть только ставки «Соседи номера»;
- одновременно есть серии и ставки «Соседи номера».

Наличие ставок на поле не должно влиять на появление вопроса.

Неважно, присутствуют ли:

- цветные фишки;
- кэш;
- комплиты.

# Когда вопрос не должен задаваться

Вопрос не должен появляться только в том случае, если одновременно отсутствуют:

- серии;
- ставки «Соседи номера».

То есть если ставок на треке нет, вопрос необходимо пропустить.

# Важно

Несмотря на название вопроса, для его появления не требуется одновременное наличие и серий, и соседей.

Достаточно хотя бы одного из этих типов ставок:

- серии ИЛИ соседи.

# Что нельзя менять

Не менять:

- текст вопроса;
- порядок экзаменационных вопросов;
- алгоритм расчёта сдачи;
- правильный ответ;
- расчёт пересечений серий и соседей;
- генерацию ставок;
- поведение других вопросов.

Изменить только условие включения этого вопроса в экзамен.

# Обязательные проверки

Проверить минимум:

1. Есть только одна серия — вопрос появляется.

2. Есть несколько серий — вопрос появляется.

3. Есть только одна ставка «Соседи номера» — вопрос появляется.

4. Есть несколько ставок «Соседи номера» — вопрос появляется.

5. Есть серии и соседи одновременно — вопрос появляется.

6. Есть серии и ставки поля — вопрос появляется.

7. Есть соседи и ставки поля — вопрос появляется.

8. Есть серии, соседи и ставки поля — вопрос появляется.

9. Есть только цветные фишки — вопрос не появляется.

10. Есть только кэш — вопрос не появляется.

11. Есть только комплиты — вопрос не появляется.

12. Есть цвет, кэш и комплиты, но нет серий и соседей — вопрос не появляется.

13. Ставок нет вообще — вопрос не появляется.

После выполнения кратко сообщи:

- какое условие теперь используется для появления вопроса;
- подтверждение, что достаточно наличия серий или соседей;
- подтверждение, что ставки поля не влияют на появление вопроса;
- подтверждение, что алгоритм расчёта не изменялся.
