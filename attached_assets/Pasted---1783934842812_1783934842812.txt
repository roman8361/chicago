ДОПОЛНЕНИЕ К ТЗ

Нужно изменить визуальное отображение комплита дюжины.

Сейчас комплит дюжины отображается большой чёрной фишкой с суммой внутри.

Нужно убрать эту фишку и заменить её прямоугольной плашкой с буквой:

C

---

ОБЛАСТЬ ИЗМЕНЕНИЙ

Изменение относится только к:

- комплиту первой дюжины;
- комплиту второй дюжины;
- комплиту третьей дюжины.

Комплиты отдельных номеров продолжают отображаться ранее согласованным способом:

- голубая подсветка клетки;
- большая буква C.

---

НОВОЕ ОТОБРАЖЕНИЕ КОМПЛИТА ДЮЖИНЫ

Если в текущем раунде сгенерирован комплит дюжины:

1. Не показывать текущую чёрную фишку.
2. Не показывать сумму комплита на поле.
3. Вместо неё показать прямоугольную плашку.
4. В центре плашки показать большую букву C.

---

РАЗМЕР ПЛАШКИ

Прямоугольная плашка должна иметь примерно те же габариты, которые сейчас занимает большая чёрная фишка комплита дюжины.

Не увеличивать область и не менять геометрию дюжины.

Плашка должна:

- полностью помещаться внутри зоны выбранной дюжины;
- не перекрывать соседние дюжины;
- не выходить за границы сетки;
- располагаться по центру выбранной дюжины.

Использовать существующие координаты отображения комплита дюжины.

---

ФОРМА

Форма:

- прямоугольник;
- допускаются слегка скруглённые углы;
- не делать плашку круглой или овальной.

Рекомендуемый `border-radius`:

4–10 px

Стиль должен соответствовать текущему оформлению Chicago 1932 / Art Deco.

---

ЦВЕТ ПЛАШКИ

Фон прямоугольника должен использовать тот же цвет, что и визуальное обозначение комплита номера.

Использовать яркий голубой цвет Electric Cyan.

Например:

#00D4FF

или ближайший оттенок из уже созданного стиля комплита.

Не создавать другой цвет специально для комплита дюжины.

Комплиты номера и дюжины должны восприниматься как один тип ставок.

---

РЕКОМЕНДУЕМЫЙ СТИЛЬ

Пример:

background: rgba(0, 212, 255, 0.55);

border: 2px solid rgba(160, 240, 255, 0.95);

box-shadow:
  inset 0 0 12px rgba(120, 230, 255, 0.85),
  0 0 10px rgba(0, 212, 255, 0.75);

Допускается адаптировать параметры под существующий CSS-компонент комплита номера.

---

БУКВА C

В центре прямоугольника показать одну букву:

C

Требования:

- никаких цифр;
- никаких сумм;
- никаких дополнительных подписей;
- буква находится строго по центру;
- буква занимает большую часть высоты плашки;
- хорошо читается на голубом фоне;
- не выходит за границы прямоугольника.

Рекомендуемые параметры:

- font-size: 70–85% высоты плашки;
- font-weight: 900;
- color: почти белый или светло-голубой;
- opacity: 0.85–1;
- минимальное размытие или без размытия;
- лёгкое текстовое свечение.

Пример:

text-shadow:
  0 0 4px rgba(255, 255, 255, 0.95),
  0 0 8px rgba(0, 160, 220, 0.9);

---

СУММА КОМПЛИТА

Сумму комплита дюжины больше не отображать внутри плашки.

При этом сумма должна остаться в данных раунда и продолжать использоваться для:

- расчёта сдачи кратности;
- расчёта пересечений;
- подготовки выигрышного поля;
- итоговой выплаты;
- отчёта дилера.

Меняется только визуальное отображение.

---

ВЫБРАННАЯ ДЮЖИНА

Плашка должна отображаться только в той дюжине, на которую сгенерирован комплит.

Пример:

- выбран комплит второй дюжины;
- плашка C отображается только в зоне второй дюжины;
- первая и третья дюжины остаются без изменений.

---

ОТЧЁТ ПО РАУНДУ

На экране «Отчёт по раунду», где показывается первоначальное состояние после Spin, комплит дюжины также должен отображаться новым способом:

- голубая прямоугольная плашка;
- буква C;
- без чёрной фишки;
- без суммы.

---

ФИНАЛЬНОЕ ВЫИГРЫШНОЕ ПОЛЕ

Когда перед вопросом об общей выплате поле перестраивается и отображаются реальные выигравшие ставки, плашка комплита дюжины может быть скрыта вместе с исходным маркером ставки.

На финальном выигрышном поле должны отображаться уже реальные суммы ставок на выигравших позициях согласно существующей логике.

Не использовать прямоугольную плашку C как денежную фишку.

---

ОГРАНИЧЕНИЯ

- Не менять генерацию комплита дюжины.
- Не менять сумму комплита.
- Не менять выбранную дюжину.
- Не менять расчёты.
- Не менять `rouletteRules.json`.
- Не менять геометрию сетки дюжин.
- Не менять отображение обычных дюжин.
- Не возвращать чёрную фишку.
- Изменить только визуальный маркер комплита дюжины.

---

КРИТЕРИИ ГОТОВНОСТИ

- Чёрная фишка комплита дюжины больше не отображается.
- В выбранной дюжине показывается прямоугольная голубая плашка.
- Размер плашки примерно соответствует размеру старой чёрной фишки.
- В центре отображается большая буква C.
- На плашке нет цифр и суммы.
- Плашка не выходит за границы дюжины.
- Остальные дюжины не изменяются.
- На экране отчёта используется такое же отображение.
- Все расчёты комплита дюжины продолжают работать без изменений.
