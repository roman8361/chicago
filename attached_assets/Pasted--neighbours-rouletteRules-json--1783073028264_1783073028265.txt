ЗАДАЧА

Нужно заполнить существующий раздел `neighbours` в файле правил рулетки `rouletteRules.json`.

Сейчас структура содержит пустой объект:

"neighbours": {}

Нужно сохранить в нём правила соседей для всех номеров европейской рулетки от 0 до 36.

ВАЖНО

Не создавать новый JSON-файл.

Не создавать отдельный файл для соседей.

Нужно использовать существующий `rouletteRules.json` и заполнить уже существующий объект:

"neighbours"

---

ПРАВИЛО СОСЕДЕЙ

Соседи номера — это 5 номеров:

1. два номера слева от выбранного номера по порядку колеса;
2. сам выбранный номер;
3. два номера справа от выбранного номера по порядку колеса.

Используется существующий европейский порядок колеса:

0, 32, 15, 19, 4, 21, 2, 25, 17, 34, 6, 27, 13, 36, 11, 30, 8, 23, 10, 5, 24, 16, 33, 1, 20, 14, 31, 9, 22, 18, 29, 7, 28, 12, 35, 3, 26

Порядок циклический.

ВАЖНО ПО СТРУКТУРЕ

Ключ объекта — номер рулетки в строковом формате.

Пример:

"26"

Значение — массив ровно из 5 чисел.

Пример:

"26": [35, 3, 26, 0, 32]

Сам номер всегда должен находиться на третьей позиции массива, индекс `2`.

Не сортировать номера по возрастанию.

Не менять порядок элементов массива.

Порядок массива соответствует физическому порядку номеров на колесе рулетки.

---

ОГРАНИЧЕНИЯ

- Не менять `completeBets`.
- Не менять `dozenComplete`.
- Не менять серии.
- Не менять выплаты.
- Не менять Track.
- Не менять генерацию Spin.
- Не добавлять расчёт соседей программно на этом этапе.
- Не создавать новую сущность или новый файл.
- Только заполнить существующий объект `neighbours` в `rouletteRules.json`.

---

КРИТЕРИИ ГОТОВНОСТИ

В `rouletteRules.json` объект `neighbours` содержит 37 записей — для номеров от 0 до 36.

У каждой записи массив содержит ровно 5 номеров.

Сам номер находится на позиции с индексом 2.

Для номера 26:

"26": [35, 3, 26, 0, 32]

Для номера 1:

"1": [16, 33, 1, 20, 14]

JSON остаётся валидным.

Приложение запускается без ошибок.

На этом этапе данные нужно только сохранить в правилах рулетки. Не подключать `neighbours` к генерации ставок и расчётам.
