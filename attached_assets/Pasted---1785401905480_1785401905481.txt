Необходимо изменить условие появления вопроса:

«Какую общую сумму нужно поставить в номер с выигрышных ставок „комплит“?»

# Новое условие

Вопрос должен задаваться всегда, если в текущем раунде присутствует хотя бы одна ставка «Комплит».

Для появления вопроса достаточно наличия одного комплита любого типа.

# Какие комплиты учитывать

Вопрос должен появляться, если присутствует хотя бы один:

- комплит номера;
- комплит дюжины.

Также вопрос должен появляться при наличии нескольких комплитов любого типа.

# Когда вопрос должен задаваться

Вопрос должен появляться в следующих случаях:

- есть один комплит номера;
- есть несколько комплитов номера;
- есть один комплит дюжины;
- есть несколько комплитов дюжины;
- одновременно есть комплиты номера и дюжины.

Неважно, присутствуют ли при этом:

- цветные фишки;
- кэш;
- серии;
- ставки «Соседи номера».

Наличие других ставок не должно влиять на появление вопроса.

# Когда вопрос не должен задаваться

Если в текущем раунде отсутствуют любые ставки «Комплит», вопрос необходимо пропустить.

Даже если присутствуют:

- цветные фишки;
- кэш;
- серии;
- ставки «Соседи номера».

# Важно

Условие появления вопроса зависит от наличия сгенерированного комплита, а не от того, оказался ли этот комплит выигрышным.

Если в раунде есть хотя бы один комплит, вопрос должен быть задан.

Правильный ответ при этом рассчитывается по существующей логике с учётом выигрышного номера.

# Что нельзя менять

Не менять:

- текст вопроса;
- порядок экзаменационных вопросов;
- алгоритм определения выигрышных комплитов;
- алгоритм расчёта суммы;
- правильный ответ;
- генерацию комплитов;
- логику остальных вопросов.

Изменить только условие, при котором вопрос включается в экзамен.

# Обязательные проверки

Проверить минимум:

1. Есть один комплит номера — вопрос появляется.

2. Есть несколько комплитов номера — вопрос появляется.

3. Есть один комплит дюжины — вопрос появляется.

4. Есть несколько комплитов дюжины — вопрос появляется.

5. Есть комплит номера и комплит дюжины — вопрос появляется.

6. Есть комплит и цветные фишки — вопрос появляется.

7. Есть комплит и кэш — вопрос появляется.

8. Есть комплит и серии — вопрос появляется.

9. Есть комплит и соседи — вопрос появляется.

10. Есть все виды ставок — вопрос появляется.

11. Комплит присутствует, но не является выигрышным — вопрос всё равно появляется.

12. Есть только цветные фишки — вопрос не появляется.

13. Есть только кэш — вопрос не появляется.

14. Есть только серии — вопрос не появляется.

15. Есть только соседи — вопрос не появляется.

16. Комплиты полностью отсутствуют — вопрос не появляется.

После выполнения кратко сообщи:

- какое условие теперь используется для появления вопроса;
- подтверждение, что достаточно наличия хотя бы одного комплита;
- подтверждение, что выигрышность комплита не влияет на появление вопроса;
- подтверждение, что алгоритм расчёта и правильный ответ не изменялись.
