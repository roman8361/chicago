ЗАДАЧА

Добавить отдельное правило генерации суммы ставки для серии:

«Serie 0/2/3»

Сумма должна рассчитываться на основании:

- максимальной ставки рулетки;
- количества единиц ставки в Serie 0/2/3;
- кратности приёма серий.

---

ИСХОДНЫЕ ДАННЫЕ

Для расчёта использовать:

- `maxBet` — максимальная ставка рулетки;
- `seriesMultiplicity` — кратность приёма серий;
- количество единиц ставки в Serie 0/2/3 = 18.

Для новой формулы использовать коэффициент:

```text
18

Не использовать старый коэффициент 9.

СОСТАВ SERIE 0/2/3

Состав серии не менять:

2 фишки на street 0-2-3;
split 4/7;
split 12/15;
split 18/21;
split 19/22;
2 фишки на corner 25-26-28-29;
split 32/35.

Общее расчётное количество единиц ставки для генерации суммы:

18

НОВЫЙ АЛГОРИТМ

Шаг 1. Рассчитать нижнюю границу

Взять максимальную ставку рулетки и разделить на 2:

minAmountPerBet = maxBet / 2

Пример:

maxBet = 1000

1000 / 2 = 500
Шаг 2. Определить верхнюю границу

Верхняя граница равна максимальной ставке рулетки:

maxAmountPerBet = maxBet

Пример:

maxAmountPerBet = 1000
Шаг 3. Выбрать случайное значение

Случайным образом выбрать целое число из диапазона:

от maxBet / 2 до maxBet включительно

Для максимума рулетки 1000:

диапазон генерации: 500–1000

Допустим, случайно выбрано:

765
Шаг 4. Рассчитать исходную сумму серии

Умножить случайное значение на 18:

rawSeriesAmount = randomAmountPerBet × 18

Пример:

765 × 18 = 13770
Шаг 5. Округлить сумму вниз по кратности

Взять кратность приёма серий.

Пример:

seriesMultiplicity = 100

Если исходная сумма не делится на кратность без остатка, округлить её вниз до ближайшего меньшего числа, которое делится на кратность без остатка.

Формула:

finalSeriesAmount =
  Math.floor(rawSeriesAmount / seriesMultiplicity)
  * seriesMultiplicity

Пример:

13770 / 100 = 137.7

Math.floor(137.7) = 137

137 × 100 = 13700

Итоговая ставка Serie 0/2/3:

13700

ПОЛНЫЙ ПРИМЕР

Настройки:

Минимум рулетки: 5
Максимум рулетки: 1000
Кратность серии: 100

Расчёт:

1. Максимум рулетки делим на 2:

1000 / 2 = 500

2. Формируем диапазон:

500–1000

3. Случайно выбираем:

765

4. Умножаем на 18:

765 × 18 = 13770

5. Округляем вниз до кратности 100:

13770 → 13700

Результат:

Ставка Serie 0/2/3 = 13700

ОКРУГЛЕНИЕ НИЖНЕЙ ГРАНИЦЫ

Если максимальная ставка нечётная, нижнюю границу необходимо округлить вверх до целого числа.

Использовать:

const minAmountPerBet = Math.ceil(maxBet / 2);

Пример:

maxBet = 305

305 / 2 = 152.5

нижняя граница = 153

Верхняя граница:

const maxAmountPerBet = Math.floor(maxBet);

Итоговый диапазон:

153–305

СЛУЧАЙНОЕ ЗНАЧЕНИЕ

Случайное число должно быть целым.

Обе границы включаются.

const randomIntInclusive = (
  min: number,
  max: number
): number => {
  return Math.floor(Math.random() * (max - min + 1)) + min;
};

РЕКОМЕНДУЕМАЯ РЕАЛИЗАЦИЯ

const SERIE_ZERO_TWO_THREE_MULTIPLIER = 18;

const generateSerieZeroTwoThreeAmount = (
  maxBet: number,
  seriesMultiplicity: number
): number => {
  if (!Number.isFinite(maxBet) || maxBet <= 0) {
    return 0;
  }

  if (
    !Number.isFinite(seriesMultiplicity) ||
    seriesMultiplicity <= 0
  ) {
    return 0;
  }

  const minAmountPerBet = Math.ceil(maxBet / 2);
  const maxAmountPerBet = Math.floor(maxBet);

  const randomAmountPerBet = randomIntInclusive(
    minAmountPerBet,
    maxAmountPerBet
  );

  const rawSeriesAmount =
    randomAmountPerBet *
    SERIE_ZERO_TWO_THREE_MULTIPLIER;

  const roundedAmount =
    Math.floor(
      rawSeriesAmount / seriesMultiplicity
    ) * seriesMultiplicity;

  return Math.max(seriesMultiplicity, roundedAmount);
};

Названия функций и переменных адаптировать под текущую структуру проекта.

ВАЖНО ПРО КОЭФФИЦИЕНТ 18

Для генерации общей суммы Serie 0/2/3 использовать именно:

randomAmountPerBet × 18

Не использовать:

× 9

Даже если в старой логике Serie 0/2/3 использовался коэффициент 9 для расчёта количества позиций или дилерской раскладки.

Новое правило генерации суммы задаётся отдельно:

коэффициент генерации = 18

При этом состав и расклад серии на поле не меняются.

ОКРУГЛЕНИЕ ТОЛЬКО ВНИЗ

Всегда выбирать ближайшее меньшее значение, которое делится на кратность без остатка.

Правильно:

13770 при кратности 100 → 13700

Неправильно:

13770 → 13800

Не использовать:

Math.round(...)

Использовать только:

Math.floor(...)

ПРОВЕРКА КРАТНОСТИ

Итоговая ставка должна удовлетворять условию:

finalSeriesAmount % seriesMultiplicity === 0

Пример:

13700 % 100 = 0

КРИТЕРИИ ГОТОВНОСТИ

Нижняя граница Serie 0/2/3 равна половине максимума рулетки.
Верхняя граница равна максимуму рулетки.
Обе границы входят в диапазон случайного выбора.
Случайное значение является целым числом.
Случайное значение умножается на 18.
Итог округляется только вниз.
Итог делится на кратность серии без остатка.
При maxBet = 1000 диапазон равен 500–1000.
При случайном значении 765 исходная сумма равна 13770.
При кратности 100 итоговая ставка равна 13700.
Новая формула применяется только к Serie 0/2/3.
Состав серии и расклад фишек остаются без изменений.
