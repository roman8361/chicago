ЗАДАЧА

Изменить генерацию ставок «Соседи номера».

Если в настройках указано 2 или больше ставок соседей, необходимо гарантировать, что хотя бы две сгенерированные ставки соседей пересекаются между собой.

---

ЧТО СЧИТАЕТСЯ ПЕРЕСЕЧЕНИЕМ

Каждая ставка «Соседи номера» состоит из пяти чисел:

- центральный номер;
- два числа слева от него на колесе;
- два числа справа от него на колесе.

Две ставки считаются пересекающимися, если центральный номер одной ставки входит в набор из пяти чисел другой ставки.

При этом центральные номера самих ставок не должны совпадать.

---

ПРИМЕР

Для ставки:

«Соседи 4»

набор чисел:

[2, 21, 4, 19, 15]

Если требуется сгенерировать ещё одну пересекающуюся ставку, её центральный номер должен быть выбран из:

[2, 21, 19, 15]

Сам номер 4 исключается, потому что центральные номера ставок не должны повторяться.

Допустимые варианты второй ставки:

- «Соседи 2»;
- «Соседи 21»;
- «Соседи 19»;
- «Соседи 15».

Например:

- первая ставка — «Соседи 4»;
- вторая ставка — «Соседи 21».

Такие ставки гарантированно пересекаются.

---

УСЛОВИЯ ГЕНЕРАЦИИ

Если количество ставок соседей равно 0:

- ставки соседей не генерировать.

Если количество ставок соседей равно 1:

- сгенерировать одну случайную ставку;
- пересечение не требуется.

Если количество ставок соседей равно 2:

- первая ставка выбирается случайно;
- центральный номер второй ставки обязательно выбирается из четырёх соседних номеров первой ставки;
- две ставки должны пересекаться.

Если количество ставок соседей больше 2:

- минимум две ставки должны пересекаться;
- остальные ставки можно выбирать случайно;
- дополнительные пересечения разрешены, но не обязательны.

---

АЛГОРИТМ

1. Получить требуемое количество ставок соседей из настроек.

2. Случайно выбрать центральный номер первой ставки от 0 до 36.

3. Получить из `rouletteRules.json → neighbours` массив из пяти чисел для первой ставки.

4. Исключить из этого массива центральный номер первой ставки.

5. Из оставшихся четырёх чисел случайно выбрать центральный номер второй ставки.

6. Добавить первую и вторую ставки в результат.

7. Остальные ставки, если они нужны, выбирать случайно среди ещё не использованных центральных номеров от 0 до 36.

---

ПРИМЕР ДЛЯ ТРЁХ СТАВОК

Настройка:

Количество ставок «Соседи номера» = 3

Допустимый результат:

- Соседи 4;
- Соседи 21;
- Соседи 31.

Ставки 4 и 21 гарантированно пересекаются.

Ставка 31 может не пересекаться с ними.

---

ПРИМЕР ДЛЯ ПЯТИ СТАВОК

Настройка:

Количество ставок «Соседи номера» = 5

Допустимый результат:

- Соседи 4;
- Соседи 19;
- Соседи 1;
- Соседи 26;
- Соседи 7.

Минимальное требование выполнено:

- Соседи 4;
- Соседи 19

образуют гарантированно пересекающуюся пару.

Остальные ставки могут случайно образовать дополнительные пересечения.

---

УНИКАЛЬНОСТЬ

Центральные номера всех сгенерированных ставок соседей должны быть уникальными.

Запрещено генерировать:

- Соседи 4;
- Соседи 4.

Даже если набор содержит центральный номер первой ставки, при выборе второй ставки сам центральный номер нужно исключить.

---

ИСТОЧНИК ДАННЫХ

Использовать данные из:

`rouletteRules.json → neighbours`

Не хардкодить порядок колеса и конкретные наборы соседей в генераторе.

Для примера с номером 4 данные должны браться из JSON, а не из отдельного массива в коде.

---

ПРОВЕРКА ПОСЛЕ ГЕНЕРАЦИИ

После формирования полного набора ставок выполнить проверку:

- если количество ставок меньше 2 — проверка не нужна;
- если количество ставок 2 или больше — должна существовать хотя бы одна пара, для которой центральный номер одной ставки входит в набор соседей другой.

Если такой пары нет:

- не оставлять результат;
- заменить одну из ставок на пересекающуюся;
- не перегенерировать весь Spin без необходимости.

---

РЕКОМЕНДУЕМАЯ ПРОВЕРКА

Условие для пары ставок с центральными номерами `a` и `b`:

```ts
const intersects =
  neighbours[a].includes(b) ||
  neighbours[b].includes(a);

При этом:

a !== b

Это пример направления реализации. Использовать текущие типы и структуру данных проекта.

СОХРАНИТЬ СУЩЕСТВУЮЩУЮ ЛОГИКУ

Не менять:

количество ставок соседей из настроек;
ограничение от 0 до 37;
генерацию суммы каждой ставки;
кратность соседей;
размещение ставок на треке;
расчёт сдачи с пересечений;
определение выигрышных соседей;
последующие вопросы дилера;
итоговую выплату.

Меняется только выбор центральных номеров ставок.

ОГРАНИЧЕНИЯ

Не менять rouletteRules.json.
Не менять состав пяти чисел каждой ставки.
Не допускать повторения центральных номеров.
Не требовать пересечения при одной ставке.
Не требовать, чтобы все ставки пересекались между собой.
Не фиксировать количество дополнительных пересечений.
Не хардкодить пример с номером 4.

КРИТЕРИИ ГОТОВНОСТИ

При 0 ставках соседей ничего не генерируется.
При 1 ставке пересечение не требуется.
При 2 ставках они обязательно пересекаются.
При 3 и более ставках минимум одна пара обязательно пересекается.
Центральные номера ставок не повторяются.
Остальные ставки могут пересекаться случайно, но это необязательно.
Данные соседей берутся из rouletteRules.json.
Существующие суммы, расчёты и отображение ставок не изменились.
