ДОПОЛНЕНИЕ К ТЗ

После изменения генерации обнаружены две проблемы, которые необходимо исправить.

---

1. НЕ ПРОПАДАТЬ КЭШ

После переработки генерации цветных ставок перестал отображаться кэш.

Это поведение неверно.

Если в настройках:

- Количество номеров с кэшем > 0
- Сумма кэша на поле > 0

то кэш ОБЯЗАТЕЛЬНО должен генерироваться.

Причём должны выполняться все ранее согласованные правила:

- создаётся указанное количество кэш-номеров;
- одна жирная кэш-позиция обязательно содержит выпавший номер;
- общая сумма кэша полностью совпадает с настройкой;
- кэш не может занимать одну позицию с цветом;
- каждая кэш-позиция отображается одной стандартной кэш-фишкой.

Не менять существующую логику кэша.

Исправить только проблему, из-за которой кэш перестал генерироваться.

---

2. ЦВЕТНЫЕ СТАВКИ ВЫГЛЯДЯТ СЛИШКОМ ИСКУССТВЕННО

Сейчас цветные фишки распределяются практически равномерно по всем возможным позициям.

Получается слишком "идеальная" картина.

В реальной игре так практически не ставят.

Нужно сделать распределение более естественным.

---

НОВОЕ ПРАВИЛО

Внутри каждого выбранного номера-центра количество фишек на разных позициях должно быть случайным.

Допускается:

- некоторые позиции вообще не использовать;
- на одной позиции поставить 1–2 фишки;
- на другой поставить значительно больше;
- на третьей вообще ничего не поставить.

Главное:

общая сумма цветных фишек для этого номера должна сохраниться.

---

ПРИМЕР

Для номера 17 нужно поставить:

24 цветные фишки.

Плохо:

Straight Up → 3

Split → 3

Split → 3

Street → 3

Corner → 3

Corner → 3

Six-Line → 3

Six-Line → 3

Получается слишком линейно.

---

Хорошо:

Straight Up → 6

Split 14-17 → 0

Split 17-20 → 2

Street → 5

Corner → 7

Corner → 1

Six-Line → 0

Six-Line → 3

Итого:

24

Такое распределение выглядит значительно естественнее.

---

АЛГОРИТМ

При распределении цветных фишек:

1. Получить список допустимых позиций вокруг номера.
2. Перемешать его случайным образом.
3. Для каждой позиции случайным образом определить, участвует ли она в ставке.
4. Если участвует — выделить ей случайное количество фишек.
5. Постепенно распределить все фишки между выбранными позициями.
6. Последней позиции передать остаток, чтобы общая сумма совпала.

При этом:

- нельзя потерять ни одной фишки;
- нельзя превысить общее количество;
- распределение должно быть случайным.

---

ВАЖНО

Не стремиться использовать все доступные позиции.

Часть позиций вполне может остаться пустой.

Именно это делает поле похожим на реальные ставки игроков.

---

ПРИОРИТЕТЫ

Главный приоритет:

1. сохранить общее количество цветных фишек;
2. сохранить обязательную выигрышную жирную позицию;
3. сохранить отсутствие пересечения цвета и кэша;
4. сделать распределение максимально естественным.

Не нужно стремиться к равномерности.

Наоборот, небольшая хаотичность делает поле более реалистичным.

---

КРИТЕРИИ ГОТОВНОСТИ

- Кэш снова корректно генерируется.
- Все правила генерации кэша продолжают работать.
- Цветные ставки больше не распределяются равномерно.
- Некоторые позиции могут отсутствовать полностью.
- Некоторые позиции могут содержать заметно больше фишек, чем соседние.
- Общее количество цветных фишек полностью совпадает с настройкой.
- Выигрышная жирная позиция по-прежнему гарантирована.
- Остальная логика приложения работает без изменений.
