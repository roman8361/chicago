ДОПОЛНЕНИЕ К ТЗ

Нужно доработать визуальное отображение комплита номера на поле.

Сейчас:

- розовая подсветка сливается с красными номерами рулетки;
- буква C почти не видна;
- не до конца определено отображение, когда номер одновременно является комплитом и выпавшим номером.

---

1. ЗАМЕНИТЬ РОЗОВУЮ ПОДСВЕТКУ

Отказаться от розовой подсветки.

Причина:

На красных номерах рулетки она плохо различима и теряется на фоне.

Вместо неё использовать яркий голубой (Electric Cyan).

Например один из оттенков:

#00D4FF

#00C8FF

#1ECFFF

Допускается подобрать близкий оттенок, если он лучше вписывается в текущий стиль Chicago 1932.

Подсветка должна быть:

- яркой;
- хорошо читаемой на зелёном, красном и чёрном фоне;
- полупрозрачной;
- иметь внутреннее и внешнее свечение.

Например:

background: rgba(0, 212, 255, 0.45);

box-shadow:
  inset 0 0 14px rgba(120,230,255,0.9),
  0 0 10px rgba(0,212,255,0.8);

Не использовать пастельные оттенки.

Комплит должен сразу бросаться в глаза.

---

2. СДЕЛАТЬ БУКВУ C ЗАМЕТНЕЕ

Буква `C` должна быть явно видна внутри номера.

Увеличить:

- размер шрифта;
- насыщенность;
- прозрачность;
- контраст.

Рекомендуемые параметры:

- font-weight: 800–900;
- opacity: 0.7–0.85;
- filter: blur(0–0.5px);
- text-shadow для контраста.

Не использовать сильное размытие.

Сейчас буква практически исчезает из-за blur и низкой opacity.

Пример:

opacity: 0.8;

filter: blur(0.3px);

text-shadow:

0 0 4px rgba(255,255,255,0.9),

0 0 8px rgba(0,212,255,0.9);

Цвет буквы:

- почти белый;
- либо светло-голубой с голубым свечением.

Буква должна оставаться фоновым элементом, но пользователь должен сразу понимать, что на номере стоит комплит.

---

3. КОМПЛИТ СОВПАЛ С ВЫПАВШИМ НОМЕРОМ

Нужно корректно отображать ситуацию, когда:

completeNumber === winningNumber

В этом случае номер имеет одновременно два состояния:

- комплит;
- выигрышный номер.

Нельзя показывать только одно из них.

---

ПРАВИЛО СОВМЕЩЕНИЯ

Когда номер является только комплитом:

- голубая подсветка;
- буква C.

Когда номер является только выигрышным:

- существующая ярко-жёлтая подсветка.

Когда номер одновременно комплит и выигрышный:

- сохранить ярко-жёлтый фон выигрышного номера;
- добавить яркую голубую рамку и внутреннее свечение;
- сохранить хорошо видимую букву C.

Таким образом:

- жёлтый цвет показывает, что номер выпал;
- голубая рамка и буква C показывают, что на номере был комплит.

---

РЕКОМЕНДУЕМЫЙ ДИЗАЙН СОВПАДЕНИЯ

Для состояния `winning + complete`:

Фон:

- существующий жёлтый фон выигрышного номера.

Рамка:

- яркая голубая рамка толщиной 3–5 px;
- либо яркий голубой inset outline.

Свечение:

box-shadow:

inset 0 0 0 4px rgba(0,212,255,0.95),

inset 0 0 14px rgba(120,230,255,0.85),

0 0 10px rgba(255,220,50,0.9);

Буква C:

- остаётся хорошо видимой;
- светло-голубая или белая;
- opacity примерно 0.8;
- не перекрывает текст номера.

---

ПРИОРИТЕТ СЛОЁВ

Для номера `winning + complete`:

1. исходный фон сектора;
2. жёлтая подсветка выигрышного номера;
3. голубая рамка/свечение комплита;
4. буква C;
5. штатный текст номера;
6. разрешённые фишки и другие элементы.

Текст номера должен оставаться самым читаемым элементом.

---

ПРОВЕРКА КЕЙСА

Нужно специально проверить сценарий:

- включён «Комплит в поле»;
- сгенерирован комплит номера, например 17;
- выпавший номер также 17.

Ожидаемое отображение:

- сектор 17 ярко-жёлтый;
- по краям яркая голубая рамка;
- внутри хорошо видна буква C;
- число 17 читается;
- чёрной фишки комплита нет.

---

ОТЧЁТ ПО РАУНДУ

На экране «Отчёт по раунду» сохранить ту же логику:

- комплит — голубая подсветка и C;
- выигрышный номер — жёлтая подсветка;
- совпадение — жёлтый фон + голубая рамка + C.

---

ОГРАНИЧЕНИЯ

- Не менять расчёты комплита.
- Не менять генерацию комплита.
- Не менять сумму комплита.
- Не менять комплит дюжины.
- Не возвращать чёрную фишку.
- Не менять геометрию поля.
- Изменить только визуальное оформление и обработку состояния совпадения.

---

КРИТЕРИИ ГОТОВНОСТИ

- Голубая подсветка хорошо читается на красных, чёрных и зелёных элементах поля.
- Буква C хорошо видна.
- Номер остаётся читаемым.
- Комплит без выигрыша отображается голубым.
- Выигрыш без комплита отображается жёлтым.
- Совпадение комплита и выигрыша отображается одновременно:
  жёлтый фон + голубая рамка + буква C.
- Комплит дюжины не изменился.
