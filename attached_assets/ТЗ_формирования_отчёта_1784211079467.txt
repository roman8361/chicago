ЗАДАЧА

Доработать экран:

«Отчёт по спину»

Сейчас поле рулетки, трек и текст отчёта расположены последовательно по вертикали. При просмотре длинного отчёта пользователь прокручивает страницу вниз и перестаёт видеть ставки на поле и треке.

Нужно сделать так, чтобы пользователь мог одновременно:

- видеть первоначальные ставки на поле рулетки;
- видеть первоначальные ставки на треке;
- прокручивать и проверять подробный отчёт по спину.

---

ОСНОВНОЕ РЕШЕНИЕ ДЛЯ ДЕСКТОПА

Разделить экран «Отчёт по спину» на две колонки:

Левая колонка:

- основное поле рулетки;
- трек;
- выпавший номер;
- первоначальные ставки текущего спина.

Правая колонка:

- заголовок «Отчёт по спину»;
- результаты ответов;
- правильные и неправильные ответы;
- подробные расчёты;
- вертикальный скролл.

Пример структуры:

[ Поле рулетки + трек ] [ Прокручиваемый отчёт ]

---

ЛЕВАЯ КОЛОНКА

Левая колонка должна оставаться видимой во время прокрутки отчёта.

Использовать:

position: sticky;
top: 12px;

или аналогичное значение с учётом существующей шапки приложения.

Поле и трек должны прокручиваться вместе как один блок.

Нельзя отдельно закреплять только основное поле и оставлять трек за пределами экрана.

---

ПРАВАЯ КОЛОНКА

Правая колонка должна иметь собственный вертикальный скролл.

Рекомендуемое поведение:

- высота ограничена доступной высотой окна;
- `overflow-y: auto`;
- прокручивается только содержимое отчёта;
- поле и трек слева остаются неподвижными.

Пример направления реализации:

```css
.spin-report-layout {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(320px, 1fr);
  gap: 20px;
  align-items: start;
}

.spin-report-table {
  position: sticky;
  top: 12px;
  max-height: calc(100vh - 24px);
}

.spin-report-results {
  max-height: calc(100vh - 24px);
  overflow-y: auto;
}

Не копировать размеры вслепую. Адаптировать их под текущую структуру приложения.

РАЗМЕРЫ КОЛОНОК

Поле должно занимать большую часть ширины.

Примерное соотношение:

поле и трек — 65–70%;
отчёт — 30–35%.

Не делать колонку отчёта слишком узкой: текст расчётов должен оставаться читаемым.

Рекомендуемая минимальная ширина отчёта:

360–420 px.

МАСШТАБ ПОЛЯ

Поле вместе с треком должно полностью помещаться по высоте экрана настолько, насколько это возможно.

На экране отчёта разрешается немного уменьшить визуальный масштаб поля и трека, например до 75–90% от игрового размера.

При этом запрещено менять:

внутреннюю геометрию;
координаты сетки;
пропорции поля;
пропорции трека;
расположение ставок.

Масштабировать нужно весь контейнер равномерно.

Предпочтительно использовать адаптивную ширину SVG, а не transform: scale, если текущая реализация это поддерживает.

ПЕРВОНАЧАЛЬНЫЕ СТАВКИ

В левой колонке показывать именно первоначальное состояние текущего спина:

исходный цвет;
исходный кэш;
исходные комплиты;
комплит дюжины;
все серии;
все ставки «соседи номера»;
выпавший номер.

Использовать существующий неизменяемый snapshot первоначальных ставок.

Не показывать очищенное поле выплаты.

Не генерировать ставки повторно.

СВЯЗЬ ОТЧЁТА С ПОЛЕМ

При прокрутке отчёта поле не должно:

очищаться;
перестраиваться;
менять ставки;
повторно рендерить случайные значения;
терять ставки на треке.

Все данные должны оставаться неизменными до нового Spin.

АДАПТИВНОСТЬ

Для широких экранов использовать две колонки.

Для узких экранов, где две колонки не помещаются:

Поле и трек размещаются сверху.
Блок поля становится sticky в верхней части экрана.
Отчёт прокручивается под ним.

При этом блок поля можно уменьшить по высоте.

Если sticky-поле занимает слишком много места на мобильном экране, добавить кнопку:

«Свернуть поле»

После сворачивания оставить компактную панель:

выпавший номер;
кнопку «Показать поле».

На десктопе сворачивание не обязательно.

НЕ ИСПОЛЬЗОВАТЬ ОБЩИЙ СКРОЛЛ ДЛЯ ДЕСКТОПА

На широком экране не заставлять пользователя прокручивать всю страницу вместе с полем.

Главная цель:

при прокрутке подробного отчёта поле и трек всегда остаются перед глазами.

ОГРАНИЧЕНИЯ

Не менять:

расчёты отчёта;
тексты вопросов;
результаты ответов;
генерацию ставок;
snapshot первоначального состояния;
геометрию поля;
геометрию трека;
rouletteRules.json.

Изменить только компоновку экрана «Отчёт по спину».

КРИТЕРИИ ГОТОВНОСТИ

На десктопе поле и трек отображаются слева.
Отчёт отображается справа.
Правая колонка прокручивается независимо.
Поле и трек остаются видимыми при прокрутке отчёта.
Показываются первоначальные ставки текущего спина.
Ставки на треке не исчезают.
Поле не генерируется повторно.
На узких экранах интерфейс переходит в удобный вертикальный режим.
Все расчёты и содержимое отчёта остаются без изменений.
