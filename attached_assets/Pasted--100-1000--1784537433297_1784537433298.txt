ДОРАБОТКА

Сейчас при диапазоне ставок рулетки, например:

Минимум = 100
Максимум = 1000

недопустимые номиналы кэша нельзя выбрать, но при нажатии на них пользователь не получает объяснения.

Нужно сохранить текущий запрет выбора, но дополнительно показывать небольшое всплывающее уведомление с причиной отказа.

---

ВАЖНО

Недопустимый номинал не должен быть полностью некликабельным через HTML-атрибут:

```tsx
disabled

Если элемент имеет disabled, обработчик onClick не вызывается, поэтому показать сообщение невозможно.

Нужно:

визуально отображать номинал как недоступный;
сохранить возможность обработать нажатие;
внутри обработчика запретить выбор;
показать уведомление с причиной.

ПРИМЕР

Диапазон рулетки:

100–1000

Допустимые номиналы:

100, 250, 500, 1000

Недопустимые номиналы:

10, 25, 50, 5000, 10000, 50000

При нажатии на 50:

номинал 50 не выбирается;
текущий выбор не изменяется;
появляется сообщение:
Номинал 50 меньше минимальной ставки рулетки — 100.

При нажатии на 5000:

номинал 5000 не выбирается;
текущий выбор не изменяется;
появляется сообщение:
Номинал 5000 превышает максимальную ставку рулетки — 1000.

ПОВЕДЕНИЕ ЭЛЕМЕНТОВ

Недопустимые номиналы должны:

оставаться видимыми;
выглядеть визуально недоступными;
иметь пониженную прозрачность или существующий disabled-стиль;
сохранять возможность нажатия для показа сообщения;
не менять выбранные номиналы.

Не использовать настоящий disabled, если он блокирует обработчик клика.

Вместо него использовать:

aria-disabled={isOutOfRange}

и CSS-класс:

className={isOutOfRange ? "cash-denomination--unavailable" : ""}

ОБРАБОТЧИК НАЖАТИЯ

Проверку диапазона выполнять в самом начале обработчика выбора номинала.

Пример:

const toggleCashDenomination = (value: number) => {
  if (value < minBet) {
    showCashDenominationMessage(
      `Номинал ${value} меньше минимальной ставки рулетки — ${minBet}.`
    );
    return;
  }

  if (value > maxBet) {
    showCashDenominationMessage(
      `Номинал ${value} превышает максимальную ставку рулетки — ${maxBet}.`
    );
    return;
  }

  setSelectedCashDenominations(current => {
    const isSelected = current.includes(value);

    if (isSelected) {
      if (current.length === 1) {
        return current;
      }

      return current.filter(item => item !== value);
    }

    if (current.length < 2) {
      return [...current, value];
    }

    return [...current.slice(1), value];
  });
};

Названия переменных и функций адаптировать под текущий проект.

ОТОБРАЖЕНИЕ УВЕДОМЛЕНИЯ

Использовать существующий компонент проекта:

toast;
snackbar;
notification;
всплывающую подсказку.

Не использовать:

alert(...)

Если в проекте нет готового компонента уведомлений, добавить компактное локальное всплывающее сообщение в окне настроек.

Сообщение должно:

появляться поверх или рядом с разделом «Номинал кэша на поле»;
не перекрывать всё окно настроек;
автоматически исчезать через 2–3 секунды;
закрываться при новом корректном выборе;
обновляться, если пользователь нажал другой недопустимый номинал.

РЕКОМЕНДУЕМЫЙ ТЕКСТ

Если номинал меньше минимальной ставки:

Номинал {value} меньше минимальной ставки рулетки — {minBet}.

Если номинал больше максимальной ставки:

Номинал {value} превышает максимальную ставку рулетки — {maxBet}.

Все значения подставлять динамически.

ПРИМЕР ЛОКАЛЬНОГО УВЕДОМЛЕНИЯ

Состояние:

const [cashDenominationMessage, setCashDenominationMessage] =
  useState<string | null>(null);

Функция показа:

const cashMessageTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);

const showCashDenominationMessage = (message: string) => {
  setCashDenominationMessage(message);

  if (cashMessageTimerRef.current) {
    clearTimeout(cashMessageTimerRef.current);
  }

  cashMessageTimerRef.current = setTimeout(() => {
    setCashDenominationMessage(null);
    cashMessageTimerRef.current = null;
  }, 3000);
};

При размонтировании компонента очистить таймер:

useEffect(() => {
  return () => {
    if (cashMessageTimerRef.current) {
      clearTimeout(cashMessageTimerRef.current);
    }
  };
}, []);

Отображение:

{cashDenominationMessage && (
  <div
    className="cash-denomination-message"
    role="status"
    aria-live="polite"
  >
    {cashDenominationMessage}
  </div>
)}

СТИЛЬ УВЕДОМЛЕНИЯ

Сообщение должно быть небольшим и соответствовать дизайну настроек.

Пример требований:

.cash-denomination-message {
  margin-top: 8px;
  padding: 8px 12px;
  border: 1px solid rgba(212, 175, 55, 0.65);
  border-radius: 6px;
  background: rgba(25, 15, 8, 0.95);
  font-size: 13px;
  line-height: 1.3;
}

Использовать существующие цвета и переменные проекта. Не добавлять яркие современные неоновые цвета.

СТИЛЬ НЕДОПУСТИМОГО НОМИНАЛА

Пример:

.cash-denomination--unavailable {
  opacity: 0.45;
  cursor: not-allowed;
}

Но элемент должен продолжать получать onClick.

Не применять:

pointer-events: none;

так как это также заблокирует нажатие и сообщение не появится.

ПРИМЕР JSX

{cashDenominations.map(value => {
  const isSelected = selectedCashDenominations.includes(value);
  const isOutOfRange = value < minBet || value > maxBet;

  return (
    <button
      key={value}
      type="button"
      aria-pressed={isSelected}
      aria-disabled={isOutOfRange}
      className={cn(
        "cash-denomination",
        isSelected && "cash-denomination--selected",
        isOutOfRange && "cash-denomination--unavailable"
      )}
      onClick={() => toggleCashDenomination(value)}
    >
      {value}
    </button>
  );
})}

Если сейчас используются чекбоксы, можно оставить их визуальный компонент, но клик должен обрабатываться внешним контейнером или label, а настоящий input disabled использовать нельзя.

ЕСЛИ ИСПОЛЬЗУЕТСЯ CHECKBOX

Проблема:

<input
  type="checkbox"
  disabled={isOutOfRange}
/>

В таком виде клик не дойдёт до обработчика.

Исправить одним из способов.

Предпочтительный вариант — использовать управляемую кнопку с визуальным видом чекбокса.

Допустимый вариант — обрабатывать клик на контейнере:

<div
  role="checkbox"
  aria-checked={isSelected}
  aria-disabled={isOutOfRange}
  tabIndex={0}
  onClick={() => toggleCashDenomination(value)}
>
  <span className="checkbox-visual" />
  <span>{value}</span>
</div>

Поддержать клавиатуру:

Enter;
Space.

FIFO-ЛОГИКА

Для допустимых номиналов сохранить существующее правило выбора максимум двух значений.

Пример:

Выбрано: [100, 500]

Пользователь нажимает допустимый номинал 1000:

Результат: [500, 1000]

Пользователь нажимает недопустимый номинал 50:

Результат остаётся: [500, 1000]

Появляется сообщение:

Номинал 50 меньше минимальной ставки рулетки — 100.

Недопустимый клик не должен влиять на FIFO-порядок.

ОЧИСТКА СООБЩЕНИЯ

Уведомление необходимо скрывать:

автоматически через 3 секунды;
при закрытии настроек;
при изменении диапазона ставок;
после успешного выбора допустимого номинала;
при запуске нового Spin.

НЕ МЕНЯТЬ

диапазон минимальной и максимальной ставки;
список доступных номиналов;
FIFO-логику выбора;
максимум в два выбранных номинала;
генерацию кэш-фишек;
сохранение настроек;
расчёты выплат.

КРИТЕРИИ ГОТОВНОСТИ

При диапазоне 100–1000 номинал 50 нельзя выбрать.
При клике на 50 появляется сообщение с причиной.
При клике на 5000 появляется сообщение с причиной.
Недопустимые номиналы визуально отличаются.
Недопустимые номиналы не используют pointer-events: none.
Обработчик клика вызывается для недопустимого номинала.
Текущий выбранный набор после недопустимого клика не изменяется.
FIFO-порядок после недопустимого клика не изменяется.
Допустимые номиналы продолжают выбираться как раньше.
Сообщение автоматически исчезает через 2–3 секунды.
