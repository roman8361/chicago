ЗАДАЧА

Нужно доработать опрос дилера после Spin.

Самым первым вопросом в опросе должен быть:

“Сдача кратности комплитов”

Этот вопрос появляется только если в настройках включён хотя бы один тип комплита:

* Комплит в поле = Да
* или Комплит дюжины = Да

Если комплиты выключены, этот вопрос нужно пропустить.

---

НУМЕРАЦИЯ ВОПРОСОВ

Все вопросы опроса должны быть пронумерованы, начиная с 1.

Пример:

1. Сдача кратности комплитов
2. Serie 5/8
3. Orphelins
4. Выплата по полю

Если блок комплитов пропущен, нумерация должна начинаться со следующего фактического вопроса.

Пример, если комплитов нет:

1. Serie 5/8
2. Выплата по полю

---

ЛОГИКА ВОПРОСА “СДАЧА КРАТНОСТИ КОМПЛИТОВ”

Пользователь вводит один общий ответ:

Общая сдача с кратности комплитов

Это сумма сдачи по:

1. Неполному комплиту дюжины, если он есть.
2. Всем комплитам номеров, если они есть.

---

ИСПОЛЬЗУЕМЫЕ ДАННЫЕ

Для каждого комплита нужно знать:

* сумма комплита;
* количество фишек, необходимых для этого комплита;
* максимум рулетки;
* кратность.

Количество фишек брать из `rouletteRules.json` через `rouletteRulesService`.

Для комплита номера:

* использовать `completeBets[number].chipsRequired`.

Для неполного комплита дюжины:

* использовать `dozenComplete.chipsRequired`.
* сейчас значение должно быть 100.

---

АЛГОРИТМ РАСЧЁТА ДЛЯ ОДНОГО КОМПЛИТА

Для каждого комплита:

1. Взять сумму комплита:

amount

2. Взять количество фишек:

chipsRequired

3. Посчитать теоретическое значение “по сколько играет”:

rawPlay = amount / chipsRequired

4. Проверить максимум рулетки.

Если rawPlay > maximum:

playBeforeMultiplicity = maximum

Иначе:

playBeforeMultiplicity = rawPlay

5. Округлить вниз до ближайшего значения, кратного настройке “Кратность”:

playPerUnit = floor(playBeforeMultiplicity / multiplicity) × multiplicity

6. Посчитать принятую сумму:

acceptedAmount = playPerUnit × chipsRequired

7. Посчитать сдачу:

change = amount - acceptedAmount

Необходимо фишек:

100

Максимум рулетки:

200

Кратность:

25

Расчёт:

18825 / 100 = 188.25

188.25 не превышает максимум 200.

175

175 × 100 = 17500

Сдача:

18825 - 17500 = 1325

---

ИНТЕРФЕЙС ВОПРОСА

Для вопроса “Сдача кратности комплитов” показывать:

Заголовок:

1. Сдача кратности комплитов

Поле ввода:

Общая сдача

Кнопка:

Проверить

Пользователь вводит только одно число.

---

ПОВЕДЕНИЕ ПРОВЕРКИ

После нажатия “Проверить”:

1. Сравнить ответ пользователя с рассчитанной общей сдачей.
2. Сохранить результат проверки только в текущем состоянии опроса.
3. Перейти к следующему вопросу.

Если ответ пустой, считать его как 0.

---

ОТЧЁТ В КОНЦЕ ОПРОСА

В конце опроса, как и сейчас, вывести отчёт по каждому разделу.

Для раздела “Сдача кратности комплитов” показать:

Если ответ правильный:

Сдача кратности комплитов
✅ Верно
Ответ: 3225

Если ответ неправильный:

Сдача кратности комплитов
❌ Неверно
Ваш ответ: 3000
Правильный ответ: 3225

Расчёт:
Неполный комплит дюжины: 18825 / 100 = 188.25
Максимум: 200, кратность: 25
Округляем вниз до 175
Сдача: 18825 - 175 × 100 = 1325

Комплит №5: 5925 / 40 = 148.125
Максимум: 200, кратность: 25
Округляем вниз до 125
Сдача: 5925 - 125 × 40 = 925

Комплит №20: 1500 / 40 = 37.5
Максимум: 200, кратность: 25
Округляем вниз до 25
Сдача: 1500 - 25 × 40 = 500

Комплит №36: 3175 / 18 = 176.389
Максимум: 200, кратность: 25
Округляем вниз до 150
Сдача: 3175 - 150 × 18 = 475

Итого: 1325 + 925 + 500 + 475 = 3225

КРИТЕРИИ ГОТОВНОСТИ

* Вопрос “Сдача кратности комплитов” появляется первым.
* Вопрос появляется только если включён комплит номера или комплит дюжины.
* Если комплитов нет, вопрос пропускается.
* Все вопросы пронумерованы с 1.
* Пользователь вводит одну общую сумму сдачи.
* Считается сдача по неполному комплиту дюжины.
* Считается сдача по всем комплитам номеров.
* Количество фишек берётся из `rouletteRules.json`.
* Максимум рулетки учитывается.
* Кратность учитывается.
* Округление всегда вниз.
* В конце отчёта есть результат по этому вопросу.
* При ошибке показывается подробный расчёт.
* При правильном ответе подробный расчёт не показывается.
