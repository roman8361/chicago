ЗАДАЧА

Нужно добавить генерацию ставок “Соседи номера” на треке после Spin.

На этом этапе нужно только:

- выбрать номера соседей;
- сгенерировать сумму ставки;
- отобразить кэш-фишку на треке;
- не раскладывать ставку на straight up;
- не считать выплату по соседям.

---

ИСПОЛЬЗУЕМЫЕ НАСТРОЙКИ

Использовать настройки:

1. Количество ставок “Соседи номера”
2. Минимум рулетки
3. Максимум рулетки

---

УСЛОВИЕ ГЕНЕРАЦИИ

Если значение “Количество ставок Соседи номера” равно 0:

- ставки соседей не генерировать.

Если значение больше 0:

- сгенерировать указанное количество ставок соседей.

Максимальное значение:

37

Если пользователь ввёл значение больше 37:

- использовать 37.

---

ВЫБОР НОМЕРОВ

Для каждой ставки “Соседи номера” нужно выбрать случайный номер рулетки от 0 до 36.

Правила:

- номера не должны повторяться;
- если нужно сгенерировать 4 ставки соседей, выбрать 4 разных номера;
- если нужно сгенерировать 5 ставок соседей, выбрать 5 разных номеров;
- и так далее до 37.

Пример:

Количество ставок соседей = 4

Можно выбрать:

20, 7, 31, 0

Нельзя выбрать:

20, 7, 20, 0

---

ДАННЫЕ ИЗ JSON

В `rouletteRules.json` уже есть раздел:

`neighbours`

Он содержит список соседей для каждого номера.

На этом этапе нужно использовать этот раздел только как справочник.

Пример:

```json
"20": [33, 1, 20, 14, 31]

Это означает, что ставка “Соседи 20” в будущем будет раскладываться на:

33, 1, 20, 14, 31

Но сейчас раскладку на поле НЕ делать.

ГЕНЕРАЦИЯ СУММЫ СТАВКИ

Для каждой ставки соседей нужно сгенерировать сумму.

Алгоритм:

Взять максимум рулетки:

maximum

Посчитать нижнюю границу:

lowerBound = round(maximum / 3)

Округление можно сделать любым способом:

Math.round
Math.floor
Math.ceil

Это не критично.

Случайно выбрать базовое значение:

baseAmount

в диапазоне:

lowerBound ... maximum

Посчитать сумму ставки соседей:

neighbourAmount = baseAmount × 5

Почему × 5:

одна ставка “Соседи номера” состоит из 5 номеров:

два слева;
сам номер;
два справа.

Пример:

Минимум рулетки = 1
Максимум рулетки = 100

lowerBound = 100 / 3 ≈ 34

Случайно выбрали:

baseAmount = 67

Тогда:

neighbourAmount = 67 × 5 = 335

На треке отображается кэш-фишка со значением:

335

РАСПОЛОЖЕНИЕ НА ТРЕКЕ

Ставка соседей отображается на треке.

Если выбраны “Соседи 20”, фишка должна быть размещена на треке в позиции номера 20.

Если выбраны “Соседи 7”, фишка должна быть размещена на треке в позиции номера 7.

Использовать существующую сетку трека и координаты номеров.

Не ставить фишку приблизительно вручную.

ВНЕШНИЙ ВИД

Соседи отображаются кэш-фишкой.

Требования:

фишка должна визуально отличаться от обычных цветных фишек;
внутри фишки отображается сумма ставки соседей;
стиль должен соответствовать Chicago 1932;
фишка должна быть поверх трека;
значение должно быть читаемым.

ПРИМЕР

Настройки:

Количество ставок “Соседи номера” = 4
Минимум рулетки = 1
Максимум рулетки = 100

Система случайно выбирает номера:

20, 7, 31, 0

Для каждого номера генерируется своя ставка:

Соседи 20:
baseAmount = 67
neighbourAmount = 67 × 5 = 335

Соседи 7:
baseAmount = 42
neighbourAmount = 42 × 5 = 210

Соседи 31:
baseAmount = 88
neighbourAmount = 88 × 5 = 440

Соседи 0:
baseAmount = 50
neighbourAmount = 50 × 5 = 250

На треке появляются 4 кэш-фишки:

на позиции 20 со значением 335;
на позиции 7 со значением 210;
на позиции 31 со значением 440;
на позиции 0 со значением 250.

ЧТО НЕ ДЕЛАТЬ НА ЭТОМ ЭТАПЕ

Пока НЕ нужно:

раскладывать соседей в straight up на основном поле;
считать выплату по соседям;
добавлять соседей в проверку ответа;
добавлять соседей в отчёт;
учитывать пересечения соседей;
учитывать соседей при кэше на поле;
учитывать соседей при комплитах.

ОГРАНИЧЕНИЯ

Не менять rouletteRules.json, кроме уже существующего использования neighbours.
Не менять генерацию обычных цветных фишек.
Не менять генерацию комплитов.
Не менять генерацию комплита дюжины.
Не менять серии.
Не менять расчёты выплат.
Не менять геометрию трека.
Не менять координаты трека.
Не менять экран правил.
Не добавлять сохранение в БД или localStorage.
Ставки соседей существуют только в текущем Spin.

КРИТЕРИИ ГОТОВНОСТИ

Если “Количество ставок Соседи номера” = 0, соседи не появляются.
Если значение больше 0, генерируется указанное количество ставок соседей.
Если значение больше 37, используется 37.
Номера соседей не повторяются.
Для каждой ставки выбирается случайный номер 0–36.
Для каждой ставки генерируется сумма по формуле baseAmount × 5.
baseAmount выбирается от примерно maximum / 3 до maximum.
Фишка отображается на треке в позиции выбранного номера.
Фишка отображается как кэш-фишка с суммой внутри.
Соседи пока не участвуют в расчётах.
