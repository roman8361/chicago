ЗАДАЧА

Добавить новый вопрос в существующий опрос дилера:

“Какую сумму нужно поставить в номер с выигрышных “Соседей”?”

Вопрос относится к выигравшим ставкам “Соседи номера”.

При расчёте нужно учитывать, сколько уже фактически играет на выпавшем номере от других ставок.

---

УСЛОВИЕ ПОЯВЛЕНИЯ ВОПРОСА

Вопрос показывать только в том случае, если сыграла хотя бы одна ставка “Соседи номера”.

Ставка соседей считается сыгравшей, если выпавший номер входит в массив этой ставки из:

rouletteRules.json
→ neighbours

Если соседи сгенерированы, но выпавший номер не входит ни в одну ставку соседей, вопрос НЕ показывать.

---

СМЫСЛ ВОПРОСА

Пользователь должен определить, какую сумму с выигравших ставок “Соседи номера” ещё можно поставить в выпавший номер Straight Up с учётом максимума стола.

Перед постановкой выигравших соседей нужно проверить, сколько уже фактически играет на Straight Up выпавшего номера.

Учитывать:

- серии;
- цветные ставки на поле;
- кэш на поле;
- комплиты номеров;
- комплит дюжины.

Если номер уже играет по максимуму, правильный ответ:

0

Если до максимума осталось меньше, чем сумма с выигравших соседей, поставить можно только остаток до максимума.

---

ШАГ 1. НАЙТИ ВСЕ ВЫИГРАВШИЕ СТАВКИ “СОСЕДИ”

Для каждой сгенерированной ставки “Соседи номера”:

1. Взять номер ставки соседей.
2. Получить список 5 номеров из:

rouletteRules.json
→ neighbours

3. Проверить:

neighbourNumbers.includes(winningNumber)

Если `true`, ставка соседей сыграла.

Нужно проверить ВСЕ ставки соседей.

Один выпавший номер может входить сразу в несколько ставок соседей.

---

ШАГ 2. ПОСЧИТАТЬ ОБЩУЮ СУММУ С ВЫИГРАВШИХ СОСЕДЕЙ

Для каждой выигравшей ставки соседей:

amountPerNumber = neighbourAmount / 5

Сложить значения всех выигравших соседей:

winningNeighboursAmount = sum(amountPerNumber)

---

ПРИМЕР

Соседи 20:

150

По JSON:

[33, 1, 20, 14, 31]

150 / 5 = 30

Соседи 31:

200

По JSON:

[20, 14, 31, 9, 22]

200 / 5 = 40

Выпал номер:

14

Обе ставки сыграли.

Общая сумма с выигравших соседей:

30 + 40 = 70

---

ШАГ 3. ПОСЧИТАТЬ, СКОЛЬКО УЖЕ ИГРАЕТ НА ВЫПАВШЕМ НОМЕРЕ

Нужно проверить только позицию:

Straight Up {winningNumber}

Например, если выпал номер 14:

straightUp:14

Посчитать все суммы, которые уже фактически играют на этой позиции.

Учитывать:

1. Серии.
2. Цветные ставки на поле.
3. Кэш на поле.
4. Комплиты номеров.
5. Комплит дюжины.

Сами ставки “Соседи номера” на этом шаге НЕ добавлять.

Они являются новой суммой, которую сейчас нужно определить для постановки.

---

ШАГ 4. УЧЁТ СЕРИЙ

Для каждой активной серии:

1. Взять сумму серии.
2. Взять `divisor` из `rouletteRules.json`.
3. Взять кратность из настроек.
4. Посчитать реальную ставку серии после сдачи:

rawPlay = amount / divisor

playPerUnit =
floor(rawPlay / multiplicity) * multiplicity

5. Взять реальные позиции серии из:

trackBets[seriesKey].bets

6. Найти только позицию:

straightUp:{winningNumber}

Если серия имеет Straight Up на выпавшем номере:

seriesAmount = playPerUnit * chips

Добавить эту сумму в уже играющую сумму номера.

---

ВАЖНО

Не считать серию сыгравшей по массиву `numbers`.

Для расчёта занятого лимита Straight Up использовать только реальные позиции:

trackBets.bets.straightUp

Например:

Orphelins имеет Straight Up 1.

Zero Spiel имеет Straight Up 26.

Остальные split/street/corner позиции не занимают лимит Straight Up номера.

---

ШАГ 5. УЧЁТ ЦВЕТНЫХ СТАВОК НА ПОЛЕ

Найти цветные фишки именно на:

Straight Up {winningNumber}

Сумма:

colorAmount = chipsCount * colorNominal

Где:

- `chipsCount` — количество цветных фишек на позиции;
- `colorNominal` — номинал цвета из настроек.

Добавить сумму в уже играющую сумму номера.

---

ШАГ 6. УЧЁТ КЭША НА ПОЛЕ

Найти кэш-фишку именно на:

Straight Up {winningNumber}

Использовать фактическую сумму кэша.

Добавить её в уже играющую сумму номера.

---

ШАГ 7. УЧЁТ КОМПЛИТОВ НОМЕРОВ

Для каждого активного комплита номера:

1. Посчитать, по сколько реально играет комплит после сдачи по кратности.

Использовать ту же существующую логику расчёта комплитов.

2. Получить ставки комплита из:

rouletteRules.json
→ completeBets
→ bets

3. Найти только позицию:

straightUp:{winningNumber}

4. Если комплит имеет эту позицию:

completeAmount = completePlayPerUnit * chips

Добавить сумму в уже играющую сумму номера.

---

ВАЖНО ПРО ПЕРЕСЕЧЕНИЯ КОМПЛИТОВ

Несколько комплитов номеров могут иметь одну и ту же Straight Up позицию.

Нужно проверить ВСЕ активные комплиты.

Если несколько комплитов ставят на выпавший номер Straight Up, их суммы складываются.

---

ШАГ 8. УЧЁТ КОМПЛИТА ДЮЖИНЫ

Если активен комплит дюжины:

1. Посчитать, по сколько реально играет комплит дюжины после сдачи по кратности.
2. Получить ставки нужной дюжины из:

rouletteRules.json
→ dozenComplete
→ dozens
→ bets

3. Найти позицию:

straightUp:{winningNumber}

4. Если комплит дюжины ставит на этот Straight Up:

dozenCompleteAmount =
dozenCompletePlayPerUnit * chips

Добавить сумму в уже играющую сумму номера.

---

ШАГ 9. УЧЕСТЬ УЖЕ ОТДАННУЮ СДАЧУ

В предыдущих вопросах дилера уже рассчитывалась сдача:

- с пересечений комплитов;
- с пересечений ставок трека и поля.

Поэтому нельзя повторно считать суммы сверх максимума как реально играющие.

После суммирования уже существующих ставок на Straight Up выпавшего номера ограничить занятую сумму максимумом:

effectiveExistingAmount =
min(existingAmount, maximum)

Где:

existingAmount =
seriesAmount
+ colorAmount
+ cashAmount
+ numberCompletesAmount
+ dozenCompleteAmount

Это означает:

если по предыдущим правилам на позиции получилось 130 при максимуме 100 и 30 уже должны были быть отданы сдачей, в текущем вопросе считаем, что реально играет:

100

---

ШАГ 10. ПОСЧИТАТЬ СВОБОДНЫЙ ЛИМИТ НОМЕРА

Максимум Straight Up:

straightUpLimit = maximum

Посчитать:

availableAmount =
max(0, straightUpLimit - effectiveExistingAmount)

---

ШАГ 11. ПОСЧИТАТЬ ПРАВИЛЬНЫЙ ОТВЕТ

Правильный ответ:

amountToPlace =
min(winningNeighboursAmount, availableAmount)

ОГРАНИЧЕНИЯ

- Не менять генерацию соседей.
- Не менять генерацию серий.
- Не менять генерацию комплитов.
- Не менять генерацию ставок поля.
- Не менять rouletteRules.json.
- Не считать выплату соседей.
- Не учитывать split, street, corner или six-line при определении занятого лимита номера.
- Проверять только Straight Up выпавшего номера.
- Не хардкодить позиции серий или комплитов.
- Все правила брать из `rouletteRules.json`.
- Вносить минимально необходимые изменения.

---

КРИТЕРИИ ГОТОВНОСТИ

- Вопрос появляется только если сыграли соседи.
- Проверяются все выигравшие ставки соседей.
- Суммы всех выигравших соседей складываются.
- Проверяется Straight Up выпавшего номера.
- Учитываются серии.
- Учитываются цветные ставки.
- Учитывается кэш.
- Учитываются все комплиты номеров.
- Учитывается комплит дюжины.
- Уже отданная сдача не считается повторно.
- Если номер уже играет по максимуму, ответ 0.
- Если свободного лимита меньше суммы соседей, ответ равен свободному лимиту.
- Если свободного лимита достаточно, ставится вся сумма с выигравших соседей.
- Пользователь вводит одну общую сумму.
- При ошибке показывается подробный расчёт.
