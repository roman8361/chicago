---

УСЛОВИЕ ПОЯВЛЕНИЯ ВОПРОСА

Вопрос “Сдача с пересечения на поле комплитов” показывать только если в настройках включён хотя бы один комплит:

* Комплит в поле = Да
* или Комплит дюжины = Да

Если комплиты не включены, этот вопрос не задавать.

После этого вопроса остальные вопросы должны идти как раньше.

Нумерация вопросов должна оставаться последовательной.

---

НА ЭТОМ ЭТАПЕ

Пока реализовать расчёт только для:

Комплит дюжины

Комплиты номеров пока не учитывать в этом вопросе. Их добавим следующей итерацией.

---

СМЫСЛ ВОПРОСА

Пользователь должен посчитать общую сдачу, которая возникает из-за пересечения комплита дюжины с уже стоящими ставками на поле.

Комплит дюжины ставится полностью.

Если вместе с уже стоящими ставками на поле позиция превышает максимум разрешённой ставки, превышение возвращается игроку как сдача.

---

КАК ПОСЧИТАТЬ “ПО ЧЁМ ИГРАЕТ” КОМПЛИТ ДЮЖИНЫ

У комплита дюжины есть сгенерированная сумма.

Пример:

Комплит дюжины = 18825

Из `rouletteRules.json` взять:

dozenComplete.chipsRequired = 100

Кратность = 25

Расчёт:

18825 / 100 = 188.25

Округляем вниз до ближайшей кратности 25:

175

Значит комплит дюжины играет по:

175

---

ДАННЫЕ СТАВОК КОМПЛИТА ДЮЖИНЫ

После определения “по сколько играет” нужно взять из `rouletteRules.json` нужную дюжину:

dozenComplete.dozens[]

Внутри нужной дюжины есть список ставок:

* straightUp
* splits
* streets
* corners
* sixLines

У каждой позиции есть количество фишек.

Пример:

```json
{
  "numbers": [1],
  "chips": 1
}
```

Если комплит дюжины играет по 175, то на эту позицию комплит ставит:

175 × 1 = 175

Пример split:

```json
{
  "numbers": [1, 2],
  "chips": 2
}
```

Комплит ставит:

175 × 2 = 350

---

ЛИМИТЫ ПО ТИПАМ СТАВОК

Использовать максимум рулетки из настроек.

Пример:

Минимум = 5
Максимум = 200

Тогда максимумы по позициям:

* Straight Up: 200
* Split: 400
* Street: 600
* Corner: 800
* Six-Line: 1000

Формула:

* Straight Up = maximum × 1
* Split = maximum × 2
* Street = maximum × 3
* Corner = maximum × 4
* Six-Line = maximum × 5

---

ЧТО СЧИТАТЬ ПЕРЕСЕЧЕНИЕМ

Для каждой позиции комплита дюжины нужно проверить, есть ли на этой же позиции уже ставка на поле.

Учитывать:

1. Цветные фишки на поле
2. Кэш-фишки на поле

---

НОМИНАЛ ЦВЕТНЫХ ФИШЕК

Если на позиции стоит цветная фишка, её сумма считается так:

сумма цветной ставки = количество цветных фишек × номинал цвета

Номинал цвета брать из настроек.

---

НОМИНАЛ КЭША

Если на позиции стоит кэш-фишка, использовать её фактическую сумму.

---

РАСЧЁТ ПЕРЕСЕЧЕНИЯ

Для каждой позиции:

1. Посчитать сумму ставки комплита на этой позиции:

completePositionAmount = completePlayAmount × chips

2. Посчитать сумму уже стоящих ставок на этой позиции:

existingAmount = colorAmount + cashAmount

3. Посчитать общий размер позиции:

totalAmount = completePositionAmount + existingAmount

4. Получить максимум для этой позиции:

positionLimit

5. Если totalAmount <= positionLimit:

сдача = 0

6. Если totalAmount > positionLimit:

сдача = totalAmount - positionLimit

Важно:

Комплит дюжины ставится полностью.

Сдача отдаётся только с уже стоящих ставок на поле, которые превысили лимит.

---

ПРИМЕР

Максимум рулетки = 200
Кратность = 25
Комплит дюжины = 18825
chipsRequired = 100

18825 / 100 = 188.25

Округляем вниз до кратности 25:

175

Комплит играет по:

175

На Straight Up 5 комплит дюжины ставит:

175 × 1 = 175

На этой же позиции уже стоит кэш:

50

Общая сумма:

175 + 50 = 225

Максимум Straight Up:

200

Превышение:

225 - 200 = 25

Сдача с этой позиции:

25

---

ПРОВЕРЯТЬ ВСЕ ПОЗИЦИИ ДЮЖИНЫ

Нужно проверить все позиции из JSON выбранной дюжины:

* все straightUp
* все splits
* все streets
* все corners
* все sixLines

Сдачу считать по каждой позиции отдельно.

Итоговый правильный ответ:

сумма всех превышений по всем позициям комплита дюжины.

ОТЧЁТ

В конце опроса добавить результат по этому вопросу.

Если ответ правильный:

Сдача с пересечения на поле комплитов
✅ Верно
Ответ: 25

Если ответ неправильный:

Сдача с пересечения на поле комплитов
❌ Неверно
Ваш ответ: 0
Правильный ответ: 25

Расчёт показывать только при ошибке.

В расчёте показать только позиции, где была сдача.

Пример:

Комплит дюжины играет по 175.

Straight Up 5:
Комплит: 175 × 1 = 175
Кэш на поле: 50
Итого на позиции: 225
Лимит Straight Up: 200
Сдача: 225 - 200 = 25

Итого сдача: 25

КРИТЕРИИ ГОТОВНОСТИ

* Вопрос появляется вторым после “Сдача кратности комплитов”.
* Если комплиты выключены, вопрос не появляется.
* Если включён комплит дюжины, вопрос появляется.
* Комплит дюжины играет по значению, округлённому вниз до кратности.
* Ставки комплита берутся из `rouletteRules.json`.
* Проверяются все позиции выбранной дюжины.
* Учитываются цветные фишки на поле.
* Учитываются кэш-фишки на поле.
* Сдача считается только при превышении лимита позиции.
* Комплит считается приоритетным и ставится полностью.
* Пользователь вводит одну общую сумму сдачи.
* В отчёте при ошибке показывается подробный расчёт.
