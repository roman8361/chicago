ЗАДАЧА

Исправить визуальный Focus Mode для вопроса:

«Посчитайте сдачу с кратности приема ставок "комплит".»

Сейчас посторонние ставки становятся прозрачными и бледными. Это выглядит неправильно.

Нужно создать настоящий эффект затемнения игрового стола, при котором комплиты остаются яркими и визуально светятся поверх затемнённого поля.

---

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ

При появлении вопроса:

«Посчитайте сдачу с кратности приема ставок "комплит".»

должно происходить следующее:

1. Основное поле рулетки затемняется.
2. Трек затемняется.
3. Все обычные ставки под затемнением остаются видимыми, но выглядят тёмными.
4. Все комплиты отображаются поверх затемнения.
5. Комплиты сохраняют свои исходные цвета и яркость.
6. Вокруг комплитов появляется мягкое голубое свечение.

Визуально должно выглядеть так, будто стол находится в полумраке, а ставки «Комплит» подсвечены отдельным источником света.

---

НЕ ИСПОЛЬЗОВАТЬ OPACITY ДЛЯ ЗАТЕМНЕНИЯ СТАВОК

Не делать так:

```css
.non-focused-bet {
    opacity: 0.3;
}

Такой подход делает ставки прозрачными и бледными.

Также не нужно отдельно менять прозрачность:

цветных фишек;
кэш-фишек;
серий;
соседей;
элементов трека.

Все эти элементы должны затемняться общим тёмным слоем.

ПРАВИЛЬНЫЙ ПОДХОД

Использовать отдельный полупрозрачный чёрный overlay, расположенный поверх всего игрового поля и трека.

Слои должны располагаться в следующем порядке:

1. Фон и геометрия рулетки
2. Все обычные ставки
3. Ставки серий и соседей
4. Затемняющий overlay
5. Комплиты
6. Свечение комплитов

Комплиты должны находиться выше overlay по z-index.

ЗАТЕМНЯЮЩИЙ СЛОЙ

Пример для HTML-контейнера:

.roulette-focus-overlay {
    position: absolute;
    inset: 0;
    background: rgba(0, 0, 0, 0.62);
    pointer-events: none;
    z-index: 40;
    transition: opacity 200ms ease;
}

Рекомендуемая сила затемнения:

background: rgba(0, 0, 0, 0.55);

или:

background: rgba(0, 0, 0, 0.65);

Начать с 0.62.

Важно: overlay должен закрывать одновременно:

основное поле;
трек;
все ставки, кроме комплитов.

КОМПЛИТЫ ПОВЕРХ ЗАТЕМНЕНИЯ

Контейнер или SVG-группа комплитов должны находиться выше overlay.

Пример:

.complete-bets-layer {
    position: absolute;
    inset: 0;
    z-index: 50;
    pointer-events: none;
}

Комплиты не должны получать уменьшенную прозрачность:

.complete-bet {
    opacity: 1;
    filter: none;
}

СВЕЧЕНИЕ КОМПЛИТОВ

Добавить мягкое голубое свечение вокруг визуального маркера комплита.

Для HTML:

.complete-bet.focus-highlight {
    filter:
        drop-shadow(0 0 4px rgba(74, 220, 255, 0.95))
        drop-shadow(0 0 10px rgba(74, 220, 255, 0.75))
        drop-shadow(0 0 18px rgba(74, 220, 255, 0.45));
}

Для SVG можно использовать тот же filter: drop-shadow(...).

Свечение должно применяться:

к рамке комплита;
к букве C;
к сумме комплита, если она отображается вместе с маркером.

Не добавлять сильное свечение ко всей ячейке номера.

МЯГКАЯ ПУЛЬСАЦИЯ

Можно добавить очень лёгкую пульсацию света:

@keyframes complete-focus-glow {
    0%,
    100% {
        filter:
            drop-shadow(0 0 4px rgba(74, 220, 255, 0.85))
            drop-shadow(0 0 10px rgba(74, 220, 255, 0.60));
    }

    50% {
        filter:
            drop-shadow(0 0 7px rgba(74, 220, 255, 1))
            drop-shadow(0 0 16px rgba(74, 220, 255, 0.85));
    }
}

.complete-bet.focus-highlight {
    animation: complete-focus-glow 1.8s ease-in-out infinite;
}

Пульсация должна быть медленной и ненавязчивой.

Она не должна:

увеличивать размер комплита;
двигать его;
мигать;
ухудшать читаемость буквы C.

ЕСЛИ РУЛЕТКА ЦЕЛИКОМ НАРИСОВАНА В SVG

Использовать отдельные SVG-группы:

<svg>
    <g id="roulette-base">
        {/* поле и трек */}
    </g>

    <g id="regular-bets">
        {/* цвет, кэш, соседи, серии */}
    </g>

    {focusMode === "complete-multiplicity" && (
        <rect
            className="roulette-focus-overlay"
            x="0"
            y="0"
            width="100%"
            height="100%"
        />
    )}

    <g
        id="complete-bets"
        className={
            focusMode === "complete-multiplicity"
                ? "complete-bets-layer focus-highlight"
                : "complete-bets-layer"
        }
    >
        {/* комплиты */}
    </g>
</svg>

CSS:

svg .roulette-focus-overlay {
    fill: rgba(0, 0, 0, 0.62);
    pointer-events: none;
}

svg .complete-bets-layer.focus-highlight {
    filter:
        drop-shadow(0 0 5px rgba(74, 220, 255, 0.95))
        drop-shadow(0 0 12px rgba(74, 220, 255, 0.65));
}

ВАЖНО ДЛЯ SVG

Если комплиты сейчас отрисовываются внутри общей группы ставок, необходимо:

вынести их в отдельную SVG-группу;
отрисовать эту группу после затемняющего прямоугольника;
не копировать комплиты поверх уже существующих;
обеспечить одну отрисовку каждого комплита.

Нельзя просто поднять z-index SVG-элемента внутри одной группы: внутри SVG порядок слоёв обычно определяется порядком элементов в DOM.

ЗАТЕМНЯТЬ ВЕСЬ СТОЛ, А НЕ ТОЛЬКО ФИШКИ

Под затемнением должны находиться:

зелёное сукно;
клетки поля;
цифры;
линии;
трек;
названия серий;
обычные ставки;
фишки соседей;
фишки серий.

Это создаст настоящий эффект фокуса.

Но геометрия и содержимое должны оставаться различимыми.

ЧТО ОСТАЁТСЯ БЕЗ ЗАТЕМНЕНИЯ

Поверх затемнения отображаются только:

комплиты;
буквы C;
суммы комплитов;
голубые контуры комплитов.

Текст вопроса, поле ответа и кнопки находятся вне игрового overlay и не изменяются.

ВЫИГРЫШНЫЙ НОМЕР

На первом этапе выигрышный номер также оставить под общим затемнением.

Не выделять его отдельно, потому что текущий вопрос относится только к кратности приёма комплита, а выигрышный номер для расчёта не нужен.

ВКЛЮЧЕНИЕ РЕЖИМА

const isCompleteFocus =
    focusMode === "complete-multiplicity";

Отрисовка:

<RouletteBase />
<RegularBets />
<TrackBets />

{isCompleteFocus && <FocusOverlay />}

<CompleteBets highlighted={isCompleteFocus} />

ОТКЛЮЧЕНИЕ РЕЖИМА

При переходе к следующему вопросу:

setFocusMode("none");

После отключения:

overlay плавно исчезает;
свечение комплитов отключается;
стол возвращается к обычному состоянию.

НЕ ИЗМЕНЯТЬ

Не менять:

геометрию рулетки;
положение ставок;
размеры комплитов;
размеры буквы C;
цвета комплитов;
суммы;
генерацию;
расчёты;
порядок вопросов.

Изменяется только способ визуального выделения.

КРИТЕРИИ ГОТОВНОСТИ

Поле и трек выглядят действительно затемнёнными, а не прозрачными.
Обычные ставки остаются под тёмным слоем.
Комплиты находятся поверх затемнения.
Цвета комплитов остаются яркими.
Вокруг комплитов присутствует мягкое голубое свечение.
Нет дублирования комплитов.
Геометрия поля не изменяется.
Затемнение включается только для первого вопроса.
После перехода к следующему вопросу эффект полностью отключается.
Переключение происходит плавно.
