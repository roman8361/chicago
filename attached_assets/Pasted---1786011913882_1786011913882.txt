Необходимо доработать генерацию серий и выбор выигрышного номера.

# Главное правило

Если в текущем раунде присутствует хотя бы одна ставка на серию, минимум одна серия должна обязательно сыграть.

Выигрышный номер должен входить в покрытие хотя бы одной активной серии.

Нельзя генерировать раунд, в котором присутствуют серии, но ни одна из них не выигрывает.

# Какие серии участвуют

Правило должно применяться ко всем доступным сериям:

- Serie 5/8;
- Orphelins;
- Serie 0/2/3;
- Zero Spiel.

Использовать фактический состав номеров каждой серии из действующей конфигурации.

Не дублировать состав серий в новой логике и не создавать отдельные списки, которые могут разойтись с основной конфигурацией.

# Если активна одна серия

Если в раунде присутствует только одна серия, выигрышный номер необходимо выбрать из номеров, покрываемых этой серией.

В результате эта серия должна обязательно сыграть.

Пример:

активна только Orphelins.

Выигрышный номер выбирается только из фактического набора номеров Orphelins.

Orphelins обязательно выигрывает.

# Если активно несколько серий

Если присутствует несколько серий:

- минимум одна серия должна сыграть;
- может сыграть только одна серия;
- могут сыграть несколько серий;
- могут сыграть все активные серии, если выбранный номер входит в их общее покрытие;
- результат должен зависеть от случайно выбранного выигрышного номера.

Не требуется принудительно делать выигрышными все активные серии.

# Serie 0/2/3 и Zero Spiel

Если одновременно активны:

- Serie 0/2/3;
- Zero Spiel,

не нужно обязательно выбирать номер, на котором сыграют обе серии.

Допустимы разные случайные сценарии:

- сыграла только Serie 0/2/3;
- сыграл только Zero Spiel;
- сыграли обе серии.

Какой сценарий получится, должно зависеть от выбранного выигрышного номера и фактического пересечения покрытий этих серий.

Нельзя всегда выбирать номер из их пересечения.

Нельзя также выбирать номер вне обеих серий.

# Если активны все серии

Если активны все четыре серии:

- выигрышный номер должен быть выбран случайно из объединения номеров всех активных серий;
- минимум одна серия должна сыграть;
- не требуется, чтобы сыграли все серии;
- конкретная выигрышная серия или несколько серий определяются выбранным номером.

Фраза «выбирается одна из серий случайным образом» должна быть реализована без жёсткого исключения возможных пересечений.

Рекомендуемый вариант:

1. Случайно выбрать одну из активных серий как основную выигрышную серию.
2. Случайно выбрать выигрышный номер из покрытия этой серии.
3. После выбора номера проверить остальные активные серии.
4. Если выбранный номер входит и в другие серии, они также считаются выигрышными.

Так гарантированно играет минимум одна случайно выбранная серия, но при пересечениях могут сыграть несколько.

# Рекомендуемый алгоритм

1. Сформировать список всех активных серий.

2. Если список пуст:
   - специальное правило серий не применять;
   - выигрышный номер выбирать по остальным действующим правилам.

3. Если активна одна серия:
   - выбрать выигрышный номер из её покрытия.

4. Если активно несколько серий:
   - случайно выбрать одну активную серию;
   - получить фактический набор номеров этой серии;
   - выбрать случайный номер из этого набора.

5. После выбора номера определить все активные серии, содержащие этот номер.

6. Проверить, что количество выигрышных серий не меньше одной.

Такой алгоритм обеспечивает:

- обязательный выигрыш хотя бы одной серии;
- случайный выбор основной выигрышной серии;
- возможность выигрыша нескольких серий;
- отсутствие обязательного одновременного выигрыша Serie 0/2/3 и Zero Spiel.

# Альтернативный допустимый вариант

Можно выбрать выигрышный номер из объединения покрытий всех активных серий.

При этом каждый уникальный номер должен участвовать в выборе один раз.

После выбора определить все серии, содержащие номер.

Этот вариант также гарантирует выигрыш хотя бы одной серии, но вероятность выбора конкретной серии будет зависеть от количества уникальных номеров в её покрытии.

Выбери один подход и используй его последовательно. Не смешивай два разных механизма в разных частях приложения.

Предпочтительно использовать случайный выбор основной серии, а затем случайный выбор номера внутри неё, поскольку требование сформулировано как случайный выбор одной из активных серий.

# Взаимодействие с соседями и комплитами

Выигрышный номер может одновременно зависеть от нескольких обязательных правил:

- хотя бы один комплит должен задеть выигрышный номер;
- хотя бы одна ставка «Соседи номера» должна сыграть;
- хотя бы одна серия должна сыграть.

Нельзя отдельно выбрать выигрышный номер для серий, затем перезаписать его при обработке соседей или комплитов.

Необходимо сформировать единый допустимый набор номеров, удовлетворяющий всем активным ограничениям.

Для серий условие:

выигрышный номер входит в покрытие хотя бы одной активной серии.

Для соседей:

выигрышный номер входит в покрытие хотя бы одной ставки соседей.

Для комплитов:

выигрышный номер соответствует действующему правилу касания комплитов.

Если общий набор допустимых номеров непустой, случайно выбрать номер из него.

Если общий набор пустой:

- повторно сгенерировать связанные ставки;
- либо повторно сгенерировать весь раунд по существующему механизму;
- не нарушать молча одно из обязательных правил.

# Важное уточнение о случайности

При нескольких сериях результат не должен быть всегда одинаковым.

Нужно обеспечить возможность разных раундов:

- в одном раунде выигрывает только Orphelins;
- в другом — только Serie 5/8;
- в другом одновременно Serie 0/2/3 и Zero Spiel;
- в другом выигрывает одна из них;
- при всех активных сериях выигрыш распределяется случайно.

Не требуется обеспечивать строго равномерную статистику выигрышей, если это отдельно не задано. Однако не должно быть постоянного приоритета первой серии в списке.

# Проверка после генерации

После окончательного выбора выигрышного номера выполнить валидацию.

Если активных серий нет:

- специальная проверка не требуется.

Если есть хотя бы одна активная серия:

- определить все серии, содержащие выигрышный номер;
- убедиться, что список не пустой.

Если ни одна серия не сыграла, раунд считается некорректным и должен быть сгенерирован повторно.

# Что нельзя менять

Не менять:

- состав серий;
- реальные позиции серий;
- количество частей каждой серии;
- расчёт ставки «по сколько играет серия»;
- кратность приёма серий;
- визуальное размещение фишек;
- алгоритмы расчёта сдачи;
- алгоритмы экзаменационных вопросов.

Изменить только связь активных серий с выбором выигрышного номера и общую координацию обязательных условий генерации.

# Обязательные тесты

Проверить минимум следующие сценарии:

1. Серий нет — выигрышный номер выбирается по остальным правилам.

2. Активна только Serie 5/8 — она всегда играет.

3. Активна только Orphelins — она всегда играет.

4. Активна только Serie 0/2/3 — она всегда играет.

5. Активен только Zero Spiel — он всегда играет.

6. Активны две серии без общего выигрышного номера для выбранного сценария — случайно играет одна из них.

7. Активны Serie 0/2/3 и Zero Spiel — может сыграть только Serie 0/2/3.

8. Активны Serie 0/2/3 и Zero Spiel — может сыграть только Zero Spiel.

9. Активны Serie 0/2/3 и Zero Spiel — могут сыграть обе.

10. Активны все серии — минимум одна всегда играет.

11. Активны все серии — не требуется, чтобы играли все.

12. При нескольких сериях отсутствует постоянный приоритет первой серии.

13. Выигрышный номер всегда входит в покрытие хотя бы одной активной серии.

14. Серии и соседи присутствуют одновременно — выигрышный номер удовлетворяет обоим обязательным правилам.

15. Серии и комплит присутствуют одновременно — выигрышный номер удовлетворяет обоим правилам.

16. Серии, соседи и комплиты присутствуют одновременно — номер удовлетворяет всем активным правилам.

17. Если общего допустимого номера нет, запускается повторная генерация.

18. После генерации выполняется итоговая проверка, что сыграла хотя бы одна серия.

После выполнения кратко сообщи:

- как выбирается основная выигрышная серия;
- как выбирается выигрышный номер;
- почему при нескольких сериях может сыграть одна или несколько;
- как обрабатываются Serie 0/2/3 и Zero Spiel;
- как правило серий объединено с условиями соседей и комплитов.
