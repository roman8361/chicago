ЗАДАЧА

Добавить анимацию Spin со звуком перед генерацией результата раунда.

У меня есть готовый аудиофайл со звуком вращения/падения шарика рулетки.

Длительность аудиофайла:

2 секунды.

После нажатия кнопки:

“SPIN”

приложение должно 2 секунды показывать анимацию рулетки и проигрывать аудиофайл.

Только после завершения этих 2 секунд нужно:

- определить выпавший номер;
- сгенерировать ставки;
- показать ставки на поле и треке;
- запустить существующий опрос дилера.

---

ОБЩИЙ FLOW

Текущее поведение:

SPIN
→ сразу генерируется раунд
→ сразу появляются ставки
→ сразу показывается результат

Новое поведение:

SPIN
→ блокируем повторный Spin
→ запускаем звук
→ показываем анимацию рулетки
→ ждём 2 секунды
→ убираем анимацию
→ генерируем/показываем результат раунда
→ показываем ставки
→ запускаем опрос дилера

---

ВАЖНО ПРО ГЕНЕРАЦИЮ

До окончания анимации пользователь не должен видеть:

- выпавший номер;
- новые цветные фишки;
- новый кэш;
- новые серии;
- новых соседей;
- новые комплиты;
- вопросы дилера текущего раунда.

Новый раунд визуально появляется только после завершения Spin-анимации.

---

СОСТОЯНИЕ SPIN

Добавить отдельное состояние, например:

isSpinning

Начальное значение:

false

При нажатии SPIN:

isSpinning = true

После завершения 2 секунд:

isSpinning = false

Пока:

isSpinning === true

запрещено повторно запускать Spin.

---

КНОПКА SPIN

Во время анимации кнопка SPIN должна быть disabled.

Повторные клики не должны:

- запускать второй звук;
- запускать второй таймер;
- генерировать второй раунд;
- менять выпавший номер;
- создавать дубли ставок.

После окончания Spin кнопка работает по существующей логике приложения.

---

АУДИОФАЙЛ

Добавить мой аудиофайл со звуком Spin в assets проекта.

Использовать существующую структуру проекта для статических ресурсов.

Не генерировать новый звук.

Не заменять мой аудиофайл другим звуком.

При нажатии SPIN:

1. Сбросить audio.currentTime в 0.
2. Запустить audio.play().
3. Одновременно запустить визуальную анимацию.

Пример логики:

audio.currentTime = 0
audio.play()

Звук должен проигрываться один раз.

Не использовать loop.

---

ДЛИТЕЛЬНОСТЬ

Длительность Spin:

2000 ms

Звук и визуальная анимация должны запускаться одновременно.

Через 2000 ms:

- завершить анимацию;
- скрыть колесо;
- показать новый раунд.

Не добавлять дополнительные задержки после звука.

---

АНИМАЦИЯ РУЛЕТКИ

Не нужно создавать сложное реалистичное 3D-колесо.

Нужна простая стилизованная анимация в дизайне текущего проекта Chicago 1932.

Во время Spin поверх игрового поля показать roulette overlay.

В центре overlay разместить простое колесо рулетки.

Колесо может состоять из:

- внешнего золотистого кольца;
- тёмного внутреннего круга;
- красно-чёрных секторов;
- зелёного сектора 0;
- небольшого центрального декоративного круга.

Не требуется точно рисовать все 37 номеров.

Главное — визуально понятно, что это колесо рулетки.

---

СТИЛЬ

Использовать существующий дизайн приложения:

Chicago 1932 / Art Deco.

Цвета брать из существующих CSS variables/theme проекта.

Предпочтительно использовать:

- тёмно-зелёный;
- латунный/золотистый;
- чёрный;
- тёмно-красный.

Не вводить новую яркую цветовую палитру.

Не менять дизайн основного поля.

Не менять дизайн трека.

---

АНИМАЦИЯ ВРАЩЕНИЯ

Колесо должно быстро вращаться в течение 2 секунд.

Использовать CSS animation.

Например:

@keyframes roulette-spin {
  from {
    transform: rotate(0deg);
  }

  to {
    transform: rotate(1440deg);
  }
}

Длительность:

2s

Timing function:

cubic-bezier(...) или ease-out

Предпочтительно:

- в начале колесо вращается быстро;
- ближе к концу немного замедляется.

После окончания анимации колесо скрывается.

---

OVERLAY

Во время Spin показать overlay поверх игровой зоны.

Overlay не должен менять размеры страницы или сдвигать поле.

Использовать absolute/fixed positioning относительно игрового контейнера.

Игровое поле под overlay можно немного затемнить.

Например:

background: rgba(...)

Не скрывать полностью дизайн поля.

Колесо разместить по центру игровой области.

---

ТЕКСТ ВО ВРЕМЯ SPIN

Под колесом или внутри overlay показать текст:

“NO MORE BETS”

Использовать существующий Art Deco шрифт приложения.

Текст должен быть золотистым и соответствовать текущему дизайну.

Не добавлять таймер:

2...
1...

Не показывать выпавший номер во время анимации.

---

ОЧЕНЬ ВАЖНО ПРО СУЩЕСТВУЮЩУЮ ЛОГИКУ SPIN

Сейчас в обработчике SPIN уже находится существующая логика генерации раунда.

Не переписывать эту бизнес-логику.

Нужно разделить:

1. запуск Spin-анимации;
2. существующую генерацию раунда.

Существующую генерацию вынести или вызвать только после завершения 2000 ms.

Пример архитектуры:

handleSpin()
→ startSpinAnimation()
→ wait 2000 ms
→ generateRound()

Где:

generateRound()

содержит существующую логику генерации:

- winningNumber;
- ставок поля;
- кэша;
- серий;
- соседей;
- комплитов;
- вопросов дилера.

Не дублировать эту логику.

---

ЗАЩИТА ОТ RACE CONDITION

Если пользователь быстро несколько раз нажал SPIN:

должен быть создан только один новый раунд.

Добавить проверку в начале обработчика:

if (isSpinning) return

При необходимости использовать ref/lock, если React state не гарантирует мгновенную защиту между быстрыми кликами.

---

ОЧИСТКА

Если компонент размонтируется во время Spin:

- очистить timeout;
- остановить audio;
- не выполнять обновление state размонтированного компонента.

Использовать cleanup существующего React lifecycle.

---

ОШИБКА AUDIO.PLAY

Браузер может вернуть Promise rejection при audio.play().

Не ломать Spin, если звук по какой-либо причине не проигрался.

То есть:

- обработать ошибку audio.play();
- записать ошибку в console;
- визуальная анимация и генерация раунда всё равно должны продолжиться.

---

ОГРАНИЧЕНИЯ

Не менять:

- геометрию основного поля;
- геометрию трека;
- сетку ставок;
- rouletteRules.json;
- генерацию ставок;
- расчёты дилера;
- порядок вопросов;
- финальный расчёт выплаты.

Не создавать сложную 3D-рулетку.

Не использовать сторонние animation libraries, если они ещё не используются в проекте.

Предпочтительно реализовать анимацию обычным CSS.

Внести минимально необходимые изменения.

---

КРИТЕРИИ ГОТОВНОСТИ

1. При нажатии SPIN сразу запускается аудиофайл.
2. Одновременно появляется анимация рулетки.
3. Анимация длится 2 секунды.
4. Во время анимации новые ставки не отображаются.
5. Выпавший номер во время анимации не отображается.
6. Кнопка SPIN заблокирована.
7. Повторный быстрый клик не создаёт второй раунд.
8. Через 2 секунды анимация скрывается.
9. После анимации запускается существующая генерация раунда.
10. Появляются ставки и выпавший номер.
11. Запускается существующий опрос дилера.
12. Если звук не проигрался, Spin всё равно работает.
13. Геометрия поля и трека не изменилась.
14. Все существующие расчёты работают без изменений.
