ЗАДАЧА

Изменить правило генерации суммы ставки для серии:

«Serie 5/8»

Новая сумма должна рассчитываться на основании максимума рулетки, количества ставок в серии и кратности серии.

---

ИСХОДНЫЕ ДАННЫЕ

Для расчёта использовать:

- `maxBet` — максимальная ставка рулетки;
- `seriesMultiplicity` — кратность приёма ставок для серий;
- количество ставок в Serie 5/8 = 12.

Для Serie 5/8 количество фишек/единиц ставки фиксированное:

```text
12

НОВЫЙ АЛГОРИТМ

Шаг 1. Рассчитать нижнюю границу

Взять максимальную ставку рулетки и разделить на 2:

minAmountPerBet = maxBet / 2

Пример:

maxBet = 300

300 / 2 = 150
Шаг 2. Рассчитать верхнюю границу

Взять максимальную ставку рулетки и уменьшить её на 10%.

Формула:

maxAmountPerBet = maxBet * 0.9

Пример:

maxBet = 300

300 - 10% = 270
Шаг 3. Выбрать случайную сумму на одну ставку серии

Случайным образом выбрать целое число в диапазоне:

от minAmountPerBet до maxAmountPerBet включительно

Пример:

диапазон: 150–270

случайно выбрано: 246
Шаг 4. Рассчитать общую сумму Serie 5/8

Умножить выбранную сумму на количество ставок серии:

rawSeriesAmount = randomAmountPerBet * 12

Пример:

246 × 12 = 2952
Шаг 5. Округлить общую сумму по кратности серии

Если полученная сумма не делится на кратность серии без остатка, округлить её вниз до ближайшего значения, кратного seriesMultiplicity.

Формула:

finalSeriesAmount =
  Math.floor(rawSeriesAmount / seriesMultiplicity)
  * seriesMultiplicity

Пример:

rawSeriesAmount = 2952
seriesMultiplicity = 50

2952 / 50 = 59.04

Math.floor(59.04) = 59

59 × 50 = 2950

Итоговая ставка Serie 5/8:

2950

Минимум рулетки: 5
Максимум рулетки: 300
Кратность серии: 50

Расчёт:

1. Нижняя граница:

300 / 2 = 150

2. Верхняя граница:

300 × 0.9 = 270

3. Случайное число:

246

Результат:

Ставка Serie 5/8 = 2950

ВАЖНО ПРО ДИАПАЗОН

Случайное число должно выбираться включительно:

[minAmountPerBet, maxAmountPerBet]

То есть при диапазоне 150–270 допустимы оба крайних значения:

150
270

Рекомендуемая функция:

const randomIntInclusive = (min: number, max: number): number => {
  return Math.floor(Math.random() * (max - min + 1)) + min;
};

ОКРУГЛЕНИЕ ГРАНИЦ

Так как максимум рулетки может быть нечётным или давать дробные значения, границы необходимо привести к целым числам.

Для нижней границы использовать округление вверх:

const minAmountPerBet = Math.ceil(maxBet / 2);

Для верхней границы использовать округление вниз:

const maxAmountPerBet = Math.floor(maxBet * 0.9);

Пример:

maxBet = 305

нижняя граница:
305 / 2 = 152.5
Math.ceil(...) = 153

верхняя граница:
305 × 0.9 = 274.5
Math.floor(...) = 274

Итоговый диапазон:

153–274

РЕКОМЕНДУЕМАЯ РЕАЛИЗАЦИЯ

const SERIE_FIVE_EIGHT_CHIPS_COUNT = 12;

const generateSerieFiveEightAmount = (
  maxBet: number,
  seriesMultiplicity: number
): number => {
  const minAmountPerBet = Math.ceil(maxBet / 2);
  const maxAmountPerBet = Math.floor(maxBet * 0.9);

  const randomAmountPerBet = randomIntInclusive(
    minAmountPerBet,
    maxAmountPerBet
  );

  const rawSeriesAmount =
    randomAmountPerBet * SERIE_FIVE_EIGHT_CHIPS_COUNT;

  return Math.floor(
    rawSeriesAmount / seriesMultiplicity
  ) * seriesMultiplicity;
};

ПРОВЕРКА КРАТНОСТИ

Перед расчётом проверить:

seriesMultiplicity > 0

Если кратность:

отсутствует;
равна 0;
отрицательная;
не является числом;

использовать существующее значение по умолчанию проекта или не генерировать ставку для серии.

Не допускать деление на 0.

Пример проверки:

if (
  !Number.isFinite(seriesMultiplicity) ||
  seriesMultiplicity <= 0
) {
  return 0;
}

Если в проекте уже есть общая валидация кратности, использовать её.

МИНИМАЛЬНАЯ СУММА ПОСЛЕ ОКРУГЛЕНИЯ

После округления вниз итоговая сумма не должна стать равной 0.

Если:

rawSeriesAmount < seriesMultiplicity

использовать минимально допустимое значение:

seriesMultiplicity

Рекомендуемый вариант:

const roundedAmount =
  Math.floor(rawSeriesAmount / seriesMultiplicity)
  * seriesMultiplicity;

return Math.max(seriesMultiplicity, roundedAmount);

Это защитный сценарий для маленьких значений максимума рулетки.

Для Serie 5/8 нижняя граница равна половине максимума рулетки.
Верхняя граница равна 90% максимума рулетки.
Случайное число выбирается между этими границами включительно.

Новое правило применяется только к Serie 5/8.
