Необходимо исправить момент отображения ставки комплита без сдачи.

В меню «Настройки» есть настройка:

«Показывать ставку без сдачи (комплиты, серии, соседи)».

Эта настройка определяет, когда на фишке комплита, серии или соседей вместо первоначально принятой суммы должна отображаться сумма ставки без сдачи.

# Текущая проблема

Если настройка включена и в раунде присутствует комплит, значение на фишке комплита обновляется слишком поздно.

Сейчас сумма комплита без сдачи появляется только после ответа на вопрос:

«Посчитайте общую сдачу с поля, без учета трека.»

Это неправильно.

# Требуемое поведение для комплитов

Если настройка:

«Показывать ставку без сдачи (комплиты, серии, соседи)»

включена, то значение на фишке комплита необходимо изменить на сумму без сдачи сразу после ответа на первый экзаменационный вопрос.

Не ждать ответа на вопрос:

«Посчитайте общую сдачу с поля, без учета трека.»

После завершения первого вопроса пользователь уже должен видеть на фишке комплита сумму без сдачи.

# Важно

Речь идёт не о показе правильного ответа и не о добавлении нового вопроса.

Необходимо изменить только значение, которое визуально отображается на фишке комплита.

Было:

- до первого ответа на фишке отображается первоначально принятая сумма;
- после вопроса о сдаче с поля на фишке появляется сумма без сдачи.

Должно стать:

- до ответа на первый вопрос отображается первоначально принятая сумма;
- сразу после ответа на первый вопрос на фишке появляется сумма комплита без сдачи;
- во всех следующих вопросах отображается уже сумма без сдачи.

# Пример

Сумма комплита:

3650.

Сдача с кратности комплита:

50.

Ставка без сдачи:

3600.

До ответа на первый вопрос на фишке отображается:

3650.

Сразу после ответа на первый вопрос на фишке должно отображаться:

3600.

Не нужно ждать вопроса:

«Посчитайте общую сдачу с поля, без учета трека.»

# Несколько комплитов

Если в раунде несколько комплитов, после ответа на первый вопрос необходимо обновить каждый комплит отдельно.

На каждой фишке должна отображаться рассчитанная для неё сумма без сдачи.

Не объединять несколько комплитов в одну сумму.

# Комплит номера и комплит дюжины

Исправление должно работать для:

- комплита номера;
- комплита дюжины;
- нескольких комплитов номера;
- нескольких комплитов дюжины;
- одновременного наличия комплитов номера и дюжины.

# Если настройка выключена

Если настройка:

«Показывать ставку без сдачи (комплиты, серии, соседи)»

выключена, текущее поведение не менять.

На фишке должна продолжать отображаться первоначально принятая сумма в соответствии с действующей логикой приложения.

# Серии и соседи

Изменение касается только комплитов.

Не менять момент обновления значений для:

- серий;
- ставок «Соседи номера».

Для серий и соседей текущее поведение работает правильно и должно остаться без изменений.

# Что нельзя менять

Не менять:

- алгоритм расчёта суммы комплита без сдачи;
- расчёт сдачи с кратности комплита;
- правильные ответы на экзаменационные вопросы;
- порядок вопросов;
- вопрос «Посчитайте общую сдачу с поля, без учета трека»;
- логику серий;
- логику соседей;
- генерацию ставок.

Изменить только момент визуального обновления суммы на фишке комплита.

# Обязательные проверки

Проверить минимум:

1. Настройка включена, присутствует один комплит номера.

2. Настройка включена, присутствует комплит дюжины.

3. Настройка включена, присутствует несколько комплитов.

4. До ответа на первый вопрос отображается первоначальная сумма комплита.

5. Сразу после ответа на первый вопрос отображается сумма комплита без сдачи.

6. Не требуется ждать ответа на вопрос:
   «Посчитайте общую сдачу с поля, без учета трека.»

7. При переходе к следующим вопросам сумма без сдачи сохраняется.

8. После вопроса о сдаче с поля повторного изменения значения не происходит.

9. При выключенной настройке поведение не меняется.

10. Поведение серий не изменилось.

11. Поведение соседей не изменилось.

12. Алгоритм расчёта суммы без сдачи не изменился.

После выполнения кратко сообщи:

- после какого события теперь обновляется значение на фишке комплита;
- подтверждение, что это настройка, а не экзаменационный вопрос;
- подтверждение, что серии и соседи не изменялись.
