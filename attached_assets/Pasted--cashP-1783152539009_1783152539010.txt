ЗАДАЧА

Добавить последний вопрос в существующий опрос дилера:

“Гость просит выплатить через {cashPayout}. Посчитайте остаток выплаты в цвете.”

Это финальный вопрос опроса дилера.

---

СМЫСЛ ВОПРОСА

Общая выплата уже рассчитана в предыдущем вопросе:

“Посчитайте общую сумму выплаты?”

Теперь часть общей выплаты нужно отдать кэшем.

Оставшуюся часть выплаты нужно отдать цветными фишками игрока.

Пользователь должен посчитать:

СКОЛЬКО ЦВЕТНЫХ ФИШЕК нужно отдать игроку.

---

ТЕРМИНЫ

totalPayout — общая сумма выплаты.

cashPayout — сумма, которую гость просит выплатить через кэш.

colorNominal — номинал цветной фишки игрока.

colorAmount — оставшаяся сумма выплаты в цвете.

colorChips — количество цветных фишек для выплаты.

---

ГЕНЕРАЦИЯ CASH PAYOUT

Нужно автоматически сгенерировать значение:

cashPayout

Сумма может быть любой.

Требования делать cashPayout круглой или “красивой” цифрой НЕТ.

Главное — корректно подобрать остаток выплаты в цвете.

---

ГЛАВНЫЕ УСЛОВИЯ

После выбора cashPayout должно выполняться:

colorAmount = totalPayout - cashPayout

Оставшаяся сумма должна без остатка делиться на номинал цвета:

colorAmount % colorNominal === 0

Количество цветных фишек:

colorChips = colorAmount / colorNominal

Количество цветных фишек должно быть:

colorChips <= 200

Также количество цветных фишек должно быть больше 0:

colorChips > 0

Итого допустимый диапазон:

1 <= colorChips <= 200

---

РЕКОМЕНДУЕМЫЙ АЛГОРИТМ ГЕНЕРАЦИИ

Не нужно случайно генерировать cashPayout и потом много раз проверять его.

Надёжнее сначала сгенерировать количество цветных фишек.

Алгоритм:

1. Взять общую выплату:

totalPayout

2. Взять номинал цвета:

colorNominal

3. Посчитать максимальное количество цветных фишек, которое физически можно отдать из этой выплаты:

maxPossibleColorChips =
floor(totalPayout / colorNominal)

4. Ограничить максимум значением 200:

maxColorChips =
min(200, maxPossibleColorChips)

5. Случайно выбрать:

colorChips

в диапазоне:

1 ... maxColorChips

6. Посчитать сумму выплаты в цвете:

colorAmount =
colorChips * colorNominal

7. Посчитать сумму выплаты через кэш:

cashPayout =
totalPayout - colorAmount

8. Показать пользователю cashPayout в тексте вопроса.

---

ВАЖНО

cashPayout не должен быть отрицательным.

Желательно, чтобы часть выплаты действительно шла через кэш.

Поэтому:

cashPayout > 0

Если при выбранном colorChips получилось:

cashPayout === 0

нужно выбрать другое количество цветных фишек.

---

ПРАВИЛЬНЫЙ ОТВЕТ

Пользователь должен ввести количество цветных фишек:

colorChips

Не сумму остатка.

Не сумму кэша.

Именно количество цветных фишек.

---

ПРИМЕР 1

Общая выплата:

2450

Цвет играет по:

10

Система выбрала:

colorChips = 95

Сумма выплаты в цвете:

95 × 10 = 950

Сумма через кэш:

2450 - 950 = 1500

Показываем вопрос:

“Гость просит выплатить через 1500. Посчитайте остаток выплаты в цвете.”

Расчёт пользователя:

2450 - 1500 = 950

950 / 10 = 95

Правильный ответ:

95

---

ПРИМЕР 2

Общая выплата:

5670

Цвет играет по:

20

Система выбрала:

colorChips = 150

Сумма выплаты в цвете:

150 × 20 = 3000

Сумма через кэш:

5670 - 3000 = 2670

Показываем вопрос:

“Гость просит выплатить через 2670. Посчитайте остаток выплаты в цвете.”

Расчёт пользователя:

5670 - 2670 = 3000

3000 / 20 = 150

Правильный ответ:

150

---

УСЛОВИЕ ПОЯВЛЕНИЯ ВОПРОСА

Вопрос показывать только если можно корректно разделить выплату на:

- часть через кэш;
- часть через цвет.

То есть существует хотя бы одно значение colorChips, при котором:

1 <= colorChips <= 200

colorAmount = colorChips × colorNominal

colorAmount < totalPayout

cashPayout = totalPayout - colorAmount

cashPayout > 0

Если такого варианта нет, вопрос пропустить.

- Последний вопрос появляется после расчёта общей выплаты.
