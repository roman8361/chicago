ЗАДАЧА

Нужно доработать механику проверки ответа после Spin.

Теперь после Spin пользователь должен отвечать не только по выплате с поля, но и по активным ставкам на треке.

На этом этапе реализуем два типа проверок:

1. Расчёт сдачи и принятой ставки по сериям трека.
2. Расчёт выплаты по основному полю рулетки.

ВАЖНО

Ставки на поле уже реализованы.

Ставки серий на треке уже отображаются.

Теперь нужно добавить пошаговый опрос пользователя и итоговый отчёт.

---

ИСПОЛЬЗУЕМЫЕ СЕРИИ

Работаем с четырьмя сериями:

1. Serie 5/8
2. Orphelins
3. Serie 0/2/3
4. Zero Spiel

Порядок опроса строго слева направо по треку:

1. Serie 5/8
2. Orphelins
3. Serie 0/2/3
4. Zero Spiel
5. Выплата по основному полю

---

НОВАЯ НАСТРОЙКА

В настройки нужно добавить новое поле:

Кратность

Тип поля: числовое

Допустимые значения: от 10 до 1000

Значение по умолчанию: 10

Если пользователь ничего не ввёл, использовать 10.

Если введено значение меньше 10, использовать 10.

Если введено значение больше 1000, использовать 1000.

Это поле используется для расчёта принятой ставки по серии и сдачи.

---

ЛОГИКА РАСЧЁТА СЕРИЙ

У каждой серии есть делитель:

Serie 5/8:
делитель = 6

Orphelins:
делитель = 5

Serie 0/2/3:
делитель = 9

Zero Spiel:
делитель = 4

Для каждой активной серии после Spin уже есть сгенерированное значение ставки.

Нужно рассчитать:

1. По сколько играет серия.
2. Какая сдача должна быть отдана.

Формула:

rawPerUnit = amount / divisor

playPerUnit = округлить rawPerUnit ВНИЗ до ближайшего значения, кратного настройке "Кратность"

acceptedAmount = playPerUnit × divisor

change = amount - acceptedAmount

Пользователь должен ответить:

1. По сколько играет серия.
2. Какая сдача.

---

ПОВЕДЕНИЕ КНОПКИ "ПРОВЕРИТЬ"

Для вопроса по серии:

Проверяются оба поля:

1. По сколько играет.
2. Сдача.

После проверки результат сохраняется во внутреннем списке ответов.

После проверки текущей серии система переходит к следующему вопросу.

Для вопроса по полю:

Проверяется сумма выплаты по основному полю.

После этого показывается итоговый отчёт.

---

ИТОГОВЫЙ ОТЧЁТ

После завершения всех вопросов показать отчёт.

В отчёте должны быть все проверки:

* Serie 5/8, если была активна
* Orphelins, если была активна
* Serie 0/2/3, если была активна
* Zero Spiel, если была активна
* Выплата по полю

Для каждого пункта показать:

1. Название проверки.
2. Был ли ответ правильный.
3. Ответ пользователя.
4. Правильный ответ.

Если пользователь ошибся, дополнительно показать расчёт правильного ответа.

Если пользователь ответил правильно, подробный расчёт не показывать.

---

ФОРМАТ ОТЧЁТА ДЛЯ СЕРИИ

Если пользователь ответил правильно:

Serie 5/8
✅ Верно
По сколько играет: 160
Сдача: 40

Если пользователь ошибся:

Serie 5/8
❌ Неверно
Ваш ответ: по сколько играет 150, сдача 100
Правильный ответ: по сколько играет 160, сдача 40

Расчёт:
Ставка серии: 1000
Делитель: 6
Кратность: 10
1000 / 6 = 166.66
Округляем вниз до ближайшей кратности 10 = 160
Принятая сумма: 160 × 6 = 960
Сдача: 1000 - 960 = 40

---

ФОРМАТ ОТЧЁТА ДЛЯ ПОЛЯ

Если пользователь ответил правильно:

Выплата по полю
✅ Верно
Ответ: 1940

Если пользователь ошибся:

Выплата по полю
❌ Неверно
Ваш ответ: 1900
Правильный ответ: 1940

Расчёт:
Показать список только выигравших ставок на поле и формулу по каждой ставке.

Пример:

Straight Up 17: 3 фишки × 10 × 35 = 1050
Split 17-20: 4 фишки × 10 × 17 = 680
Corner 13-14-16-17: 2 фишки × 10 × 8 = 160
Six-Line 16-21: 1 фишка × 10 × 5 = 50

Итого: 1940

---

ВАЖНЫЕ ПРАВИЛА

1. Считаем только чистую выплату без возврата ставки.
2. По сериям сейчас считаем только:

   * по сколько играет;
   * сдачу.
3. По сериям сейчас НЕ считаем выигрыш по выпавшему номеру.
4. Выплата по полю считается как раньше.
5. Ставки серий не должны влиять на выплату по полю.
6. Если нет активных серий, сразу показывать вопрос по выплате поля.
7. Если пользователь оставил поле пустым, считать ответ как 0.
8. После нового Spin очищать предыдущие ответы и предыдущий отчёт.

КРИТЕРИИ ГОТОВНОСТИ

* В настройках есть поле “Кратность” от 10 до 1000.
* После Spin формируется очередь вопросов.
* Активные серии спрашиваются в порядке: Serie 5/8, Orphelins, Serie 0/2/3, Zero Spiel.
* Для каждой активной серии отображаются два поля: “По сколько играет” и “Сдача”.
* После проверки серии система переходит к следующей активной серии.
* После серий система спрашивает выплату по полю.
* После проверки выплаты по полю показывается отчёт.
* В отчёте правильные ответы помечаются как ✅.
* Ошибки помечаются как ❌.
* Расчёт показывается только для ошибочных ответов.
* Для Serie 5/8 используется делитель 6.
* Для Orphelins используется делитель 5.
* Для Serie 0/2/3 используется делитель 9.
* Для Zero Spiel используется делитель 4.
* Округление всегда выполняется вниз до ближайшей кратности.
* Выплата по полю считается без возврата ставки.
