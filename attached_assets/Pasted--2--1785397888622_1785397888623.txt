Необходимо изменить условие появления вопроса:

«2. Посчитайте общую сдачу с поля, без учета трека.»

# Текущая логика

Сейчас этот вопрос задаётся только при одновременном выполнении двух условий:

- на поле присутствуют ставки поля (цветные фишки и/или кэш);
- присутствуют ставки комплит.

Из-за этого вопрос не задаётся, если на поле есть только цветные фишки или кэш без комплитов.

Это неправильно.

---

# Новая логика

Вопрос:

«2. Посчитайте общую сдачу с поля, без учета трека.»

должен задаваться всегда, когда на игровом поле присутствуют ставки поля.

Под ставками поля понимаются:

- цветные фишки;
- кэш-фишки.

Наличие или отсутствие комплитов больше не должно влиять на появление этого вопроса.

---

# Когда вопрос должен задаваться

Задавать вопрос, если присутствует хотя бы одно из условий:

- есть хотя бы одна цветная фишка;
- есть хотя бы одна кэш-фишка.

Неважно, есть ли при этом:

- комплиты;
- серии;
- соседи.

---

# Примеры

## Пример 1

Есть только цветные фишки.

Вопрос должен быть задан.

---

## Пример 2

Есть только кэш.

Вопрос должен быть задан.

---

## Пример 3

Есть цветные фишки и кэш.

Вопрос должен быть задан.

---

## Пример 4

Есть цветные фишки и комплиты.

Вопрос должен быть задан.

---

## Пример 5

Есть кэш и комплиты.

Вопрос должен быть задан.

---

## Пример 6

Есть цветные фишки, кэш и комплиты.

Вопрос должен быть задан.

---

# Когда вопрос не должен задаваться

Если на поле полностью отсутствуют ставки поля:

- нет цветных фишек;
- нет кэш-фишек,

то вопрос задавать не нужно.

Даже если присутствуют:

- комплиты;
- серии;
- соседи.

---

# Что нельзя менять

Не менять:

- текст вопроса;
- номер вопроса;
- алгоритм расчёта сдачи;
- правильный ответ;
- порядок остальных вопросов;
- логику комплитов;
- логику серий;
- логику соседей.

Необходимо изменить только условие, при котором вопрос включается в экзамен.

---

# Обязательные проверки

Проверить минимум:

1. Есть только цветные фишки — вопрос появляется.

2. Есть только кэш — вопрос появляется.

3. Есть цветные фишки и кэш — вопрос появляется.

4. Есть цветные фишки и комплиты — вопрос появляется.

5. Есть кэш и комплиты — вопрос появляется.

6. Есть цветные фишки, кэш и комплиты — вопрос появляется.

7. Есть только комплиты — вопрос не появляется.

8. Есть только серии — вопрос не появляется.

9. Есть только соседи — вопрос не появляется.

10. Нет ставок поля — вопрос не появляется.

После выполнения кратко сообщи:

- какое новое условие используется для появления вопроса;
- подтверждение, что наличие комплитов больше не влияет на появление вопроса;
- подтверждение, что расчёт и правильный ответ не изменились.
