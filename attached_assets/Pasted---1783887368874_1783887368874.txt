ДОПОЛНЕНИЕ К ТЗ

Изменить способ генерации цветных ставок на поле.

---

КЭШ

Для кэш-ставок логика остаётся прежней.

Каждая кэш-ставка представляет собой одну ставочную позицию.

Например:

- Straight Up
- Split
- Street
- Corner
- Six-Line

На этой позиции отображается одна кэш-фишка с рассчитанной суммой.

Кэш не нужно раскладывать на несколько позиций.

---

ЦВЕТ

Для цветных ставок использовать другую логику.

Каждый выбранный номер-центр должен максимально заполнять разные выигрышные позиции вокруг этого номера.

То есть не нужно складывать все цветные фишки одной позиции на один Split или один Corner.

Цветные фишки должны быть распределены по максимально возможному количеству разных ставок вокруг выбранного номера.

---

ПРИМЕР

Центральный номер:

17

Допустимые позиции вокруг него:

- Straight Up 17
- Split 14-17
- Split 17-20
- Street 16-17-18
- Corner 13-14-16-17
- Corner 16-17-19-20
- Six-Line 13-14-15-16-17-18
- Six-Line 16-17-18-19-20-21

Если для этого номера необходимо поставить, например, 24 цветные фишки,

не нужно делать:

Split 14-17 → 24

Нужно максимально заполнить разные позиции.

Например:

Straight Up 17 → 3

Split 14-17 → 4

Split 17-20 → 3

Street 16-17-18 → 2

Corner 13-14-16-17 → 4

Corner 16-17-19-20 → 3

Six-Line 13-14-15-16-17-18 → 3

Six-Line 16-17-18-19-20-21 → 2

Итого:

24

Это лишь пример распределения.

Конкретное распределение должно быть случайным.

---

ПРИНЦИП РАСПРЕДЕЛЕНИЯ

Для каждого выбранного номера:

1. Получить список всех допустимых позиций вокруг этого номера.

2. Перемешать список случайным образом.

3. Начать распределять цветные фишки по разным позициям.

4. Пока остаются свободные позиции, стараться сначала поставить хотя бы одну фишку на новую позицию.

5. Лишь после того, как все доступные позиции уже использованы или закончились позиции, разрешается добавлять дополнительные фишки на уже использованные позиции.

Главный приоритет — разнообразие ставок.

---

ВАЖНО

Это правило действует:

- для выигрышных цветных номеров;
- для проигрышных цветных номеров.

То есть вся генерация цветных ставок должна выглядеть максимально естественно независимо от того, содержит ли позиция выпавший номер.

---

НЕ ИЗМЕНЯТЬ

Не менять:

- распределение 70/30;
- количество жирных и нежирных номеров;
- общее количество цветных фишек;
- обязательное наличие выигрышной жирной позиции;
- запрет пересечения цвета и кэша;
- генерацию кэш-ставок.

Меняется только способ раскладки цветных фишек внутри каждой выбранной области.

---

КРИТЕРИИ ГОТОВНОСТИ

- Кэш продолжает ставиться одной ставкой на одну позицию.
- Цветные фишки распределяются по максимально возможному количеству разных ставок вокруг выбранного номера.
- Не происходит концентрации всех цветных фишек на одной позиции, если вокруг номера есть другие допустимые позиции.
- Правило применяется как для выигрышных, так и для проигрышных цветных номеров.
- Общая сумма цветных фишек остаётся неизменной.
- Остальная логика генерации продолжает работать без изменений.
