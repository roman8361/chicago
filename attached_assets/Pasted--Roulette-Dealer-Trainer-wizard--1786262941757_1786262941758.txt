Продолжаем пошаговое развитие Roulette Dealer Trainer.

Уже реализован wizard создания тренировки:

```text
Создать тренировку
        ↓
Выбор игры
        ↓
Настройки выбранной игры
        ↓
Выбор дилеров
```

На предыдущем этапе после выбора `ROULETTE` пользователь получает существующий полный набор настроек Roulette, а состояние wizard содержит:

```ts
{
  gameType: "ROULETTE",
  gameConfig: {
    ...RouletteSettings
  }
}
```

Сейчас нужно реализовать ТОЛЬКО следующий этап:

**множественный выбор дилеров для назначения этой конфигурации тренировки.**

Пока НЕ создавать `TrainingTemplate` и `TrainingAssignment`.

## 1. Экран выбора дилеров

Маршрут:

`/manager/training/new/dealers`

или уже существующий маршрут этого шага.

На странице показать:

```text
Новая тренировка

Игра: Roulette

Выберите дилеров
```

Ниже должен отображаться текущий список дилеров руководителя.

Используй существующий источник дилеров, который уже применяется в кабинете руководителя.

Не создавай отдельный тестовый список.

## 2. Множественный выбор

У каждого дилера должен быть checkbox.

Например:

```text
Выберите дилеров

☐ Иванов Иван Иванович
☐ Петров Пётр Сергеевич
☐ Сидоров Алексей Андреевич
```

Можно выбрать:

* одного дилера;
* нескольких дилеров;
* всех дилеров.

Это именно множественный выбор.

## 3. Состояние wizard

После этого этапа состояние wizard должно концептуально выглядеть так:

```ts
{
  gameType: "ROULETTE",

  gameConfig: {
    ...RouletteSettings
  },

  dealerIds: [
    "dealer-1",
    "dealer-2"
  ]
}
```

В `dealerIds` хранить только идентификаторы дилеров.

Не сохранять полные объекты Dealer внутри Training Wizard.

## 4. Выбрать всех

Добавь функцию:

`Выбрать всех`

При нажатии должны быть выбраны все отображаемые дилеры.

Например:

```text
[ Выбрать всех ]

☑ Иванов Иван Иванович
☑ Петров Пётр Сергеевич
☑ Сидоров Алексей Андреевич
```

## 5. Снять выбор

Добавь:

`Снять выбор`

После нажатия все checkbox должны стать невыбранными.

## 6. Счётчик выбранных

Покажи количество выбранных дилеров.

Например:

```text
Выбрано дилеров: 3
```

При выборе/снятии checkbox значение должно обновляться.

## 7. Предварительный выбор дилера

У нас уже существует сценарий, когда руководитель открывает карточку конкретного дилера и нажимает:

`Создать тренировку`.

Если wizard был запущен из карточки конкретного дилера, этого дилера желательно автоматически отметить на экране выбора дилеров.

Например:

руководитель находился на:

`Иванов Иван Иванович`

и нажал:

`Создать тренировку`.

После прохождения игры и настроек:

```text
Выберите дилеров

☑ Иванов Иван Иванович
☐ Петров Пётр Сергеевич
☐ Сидоров Алексей Андреевич
```

Но руководитель должен иметь возможность:

* снять Иванова;
* выбрать других;
* выбрать сразу нескольких.

То есть исходный dealerId — только предварительный выбор, а не ограничение.

Если текущий wizard ещё не сохраняет `sourceDealerId`/initialDealerId, добавь минимальную поддержку такого контекста.

## 8. Возможность создавать тренировку не из карточки дилера

Архитектура должна поддерживать и будущий сценарий:

```text
Кабинет руководителя
        ↓
Тренировки
        ↓
Создать тренировку
```

без предварительно выбранного дилера.

В этом случае все checkbox изначально пустые.

Поэтому экран SelectDealersPage не должен требовать наличие исходного dealerId.

## 9. Кнопка "Назад"

Кнопка:

`Назад`

должна вернуть пользователя к настройкам выбранной игры:

```text
Выбор дилеров
      ↓
Настройки Roulette
```

При возврате настройки не должны теряться.

Если затем снова нажать `Далее`, выбранные ранее дилеры также желательно сохранить в текущем wizard.

## 10. Возможность корректировать выбор

Это важное требование.

На текущем этапе пользователь должен иметь возможность свободно:

```text
Настройки
   ↓
Дилеры
   ↓
Назад
   ↓
Настройки
   ↓
Далее
   ↓
Дилеры
```

и ранее выбранные дилеры должны оставаться отмеченными.

То есть wizard должен хранить весь черновик:

```text
gameType
+
gameConfig
+
dealerIds
```

до завершения процесса или отмены.

## 11. Кнопка "Далее"

Пока вместо создания TrainingTemplate кнопка:

`Далее`

должна вести на следующий временный этап — подтверждение.

Добавь маршрут, например:

`/manager/training/new/review`

На нём пока можно сделать минимальный экран:

```text
Проверка тренировки

Игра:
Roulette

Выбрано дилеров:
3

[ Назад ]
```

Сам полноценный экран подтверждения будет следующим этапом.

## 12. Нельзя продолжить без дилеров

Если не выбран ни один дилер:

`Далее`

должна быть disabled либо выводить:

`Выберите хотя бы одного дилера`.

Нельзя создавать тренировку без назначения хотя бы одному дилеру.

## 13. Пустой список дилеров

Если у руководителя ещё нет дилеров, экран не должен ломаться.

Показать:

```text
Дилеры ещё не добавлены.

Сначала добавьте дилера.
```

И кнопку:

`Перейти к дилерам`

которая возвращает в раздел управления дилерами.

## 14. Не копировать данные дилеров

Не создавать внутри wizard конструкции вида:

```ts
selectedDealers: [
  {
    id,
    fullName
  }
]
```

Источник истины по дилерам остаётся отдельным.

Wizard хранит:

```ts
dealerIds: string[]
```

ФИО для отображения берётся из текущего списка Dealer.

## 15. Пока НЕ создавать TrainingTemplate

После нажатия `Далее` ещё НЕ нужно:

* сохранять TrainingTemplate;
* создавать TrainingAssignment;
* записывать что-либо в localStorage тренировок;
* генерировать Spin;
* запускать Roulette.

Пока только собираем данные.

## 16. Пока НЕ реализовывать редактирование созданной тренировки

Возможность изменять список дилеров после создания будет отдельным этапом.

Сейчас редактируется только текущий черновик wizard до создания.

## 17. Не менять Roulette

Не изменять:

* Roulette Settings;
* Spin;
* генераторы;
* racetrack;
* вопросы;
* звуки;
* игровое поле.

Этот этап касается только выбора дилеров.

## 18. Проверка

Проверь сценарий:

1. Открываю карточку Иванова.
2. Нажимаю `Создать тренировку`.
3. Выбираю Roulette.
4. Заполняю настройки.
5. Перехожу к выбору дилеров.
6. Иванов уже отмечен.
7. Дополнительно выбираю Петрова.
8. Отображается `Выбрано дилеров: 2`.
9. Нажимаю `Выбрать всех` — отмечаются все.
10. Нажимаю `Снять выбор` — снимаются все.
11. Выбираю Иванова и Петрова.
12. Нажимаю `Назад`.
13. Меняю настройку Roulette.
14. Снова нажимаю `Далее`.
15. Иванов и Петров по-прежнему выбраны.
16. Без выбранных дилеров нельзя продолжить.
17. Нажимаю `Далее`.
18. Открывается временный экран проверки.
19. TrainingTemplate ещё не создан.

## 19. Проверка универсального запуска

Также проверь, что SelectDealersPage архитектурно работает без исходного дилера.

Если wizard запускается без `initialDealerId`:

```text
☐ Иванов
☐ Петров
☐ Сидоров
```

То есть никто не выбран автоматически.

1. какие файлы созданы;
2. какие файлы изменены;
3. какой маршрут используется для выбора дилеров;
4. откуда загружается список дилеров;
5. как хранится `dealerIds`;
6. как реализован `Выбрать всех`;
7. как реализован `Снять выбор`;
8. как работает предварительный выбор дилера при запуске из его карточки;
9. как сохраняются выбранные дилеры при переходах Назад/Далее;
10. куда теперь ведёт кнопка `Далее`;
11. подтверждение, что TrainingTemplate/Assignment пока не создаются;
12. подтверждение, что Roulette не изменялась.

Выполни только этот этап.

Не переходи самостоятельно к созданию TrainingTemplate, Assignment или генерации Spin.
