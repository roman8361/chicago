Необходимо доработать генерацию ставок «Соседи номера» и выбор выигрышного номера.

# Главное правило

Если в текущем раунде присутствует хотя бы одна ставка «Соседи номера», минимум одна из этих ставок должна обязательно сыграть.

Это означает, что выигрышный номер должен входить в покрытие хотя бы одной сгенерированной ставки «Соседи номера».

# Если создана одна ставка соседей

Если присутствует только одна ставка «Соседи номера», выигрышный номер необходимо выбрать из пяти номеров, которые она покрывает:

- центральный номер;
- два соседа слева;
- два соседа справа.

В результате единственная ставка соседей должна обязательно оказаться выигрышной.

# Если создано несколько ставок соседей

Если присутствует несколько ставок «Соседи номера»:

- минимум одна ставка должна обязательно сыграть;
- могут сыграть несколько ставок;
- не требуется, чтобы сыграли все ставки;
- количество сыгравших ставок должно определяться случайным образом.

Нельзя всегда выбирать номер, который покрывается всеми соседями.

Нельзя также допускать раунд, в котором не сыграла ни одна ставка соседей.

# Рекомендуемый порядок генерации

1. Сгенерировать все ставки «Соседи номера» в соответствии с текущими настройками.

2. Для каждой ставки определить пять номеров, которые она покрывает.

3. Сформировать объединённый список всех номеров, покрываемых хотя бы одной ставкой соседей.

4. Случайно выбрать выигрышный номер из этого объединённого списка.

5. После выбора проверить, какие ставки соседей содержат выбранный номер.

6. Убедиться, что выиграла хотя бы одна ставка.

Такой подход естественным образом позволяет получить разные сценарии:

- сыграла только одна ставка соседей;
- сыграли две ставки;
- сыграли несколько ставок;
- сыграли все ставки, если случайно выбран общий номер.

# Важно сохранить случайность

При нескольких ставках соседей не нужно сначала жёстко выбирать одну «обязательную выигрышную ставку», а затем ограничивать выбор только её номерами, если это делает результат предсказуемым.

Предпочтительно выбирать выигрышный номер из объединения покрываемых номеров всех ставок.

Тогда вероятность выигрыша конкретной ставки зависит от фактического пересечения её покрытия с покрытиями других соседей.

Повторяющиеся номера в объединённом списке должны учитываться только один раз, если всем допустимым выигрышным номерам требуется одинаковая вероятность.

# Пример 1. Одна ставка соседей

Создана ставка:

«Соседи 17».

Она покрывает пять номеров по порядку колеса.

Выигрышный номер выбирается только из этих пяти номеров.

Следовательно, ставка «Соседи 17» обязательно играет.

# Пример 2. Несколько ставок без пересечения

Созданы:

- «Соседи 17»;
- «Соседи 32».

Их покрытия не пересекаются.

Выигрышный номер случайно выбирается из объединения двух наборов.

В результате сыграет одна из двух ставок.

Какая именно — определяется случайно.

# Пример 3. Несколько пересекающихся ставок

Созданы:

- «Соседи 13»;
- «Соседи 17».

Некоторые номера входят сразу в оба покрытия.

Если выбран уникальный номер первой ставки — играет только первая.

Если выбран уникальный номер второй — играет только вторая.

Если выбран общий номер — играют обе ставки.

Таким образом:

- минимум одна ставка всегда играет;
- несколько ставок могут сыграть;
- результат остаётся случайным.

# Взаимодействие с другими генерациями

Выигрышный номер может одновременно зависеть от нескольких обязательных условий генерации.

Например, в раунде могут присутствовать:

- комплит дюжины, который должен задеть выигрышный номер;
- комплит номера, который должен задеть выигрышный номер;
- соседи, минимум одна ставка которых должна сыграть;
- другие ставки с обязательным попаданием в выигрышный номер.

Нельзя последовательно выбирать выигрышный номер отдельно для каждой генерации и перезаписывать его.

Необходимо сформировать общий список допустимых выигрышных номеров, удовлетворяющих всем активным обязательным условиям.

Для соседей условие выглядит так:

выигрышный номер входит в покрытие хотя бы одной ставки «Соседи номера».

Если пересечение допустимых номеров всех активных правил непустое, выбрать выигрышный номер случайно из этого пересечения.

Если пересечение пустое, нельзя молча нарушать одно из правил. Необходимо повторно сгенерировать связанные ставки или применить существующий механизм повторной генерации раунда.

# Проверка после генерации

После окончательного выбора выигрышного номера выполнить валидацию:

- если ставок соседей нет — специальная проверка не требуется;
- если есть хотя бы одна ставка соседей — количество выигравших ставок должно быть не меньше одной.

Если проверка не пройдена, раунд считается сгенерированным некорректно и должен быть пересоздан.

# Что нельзя менять

Не менять:

- количество номеров в ставке «Соседи номера»;
- порядок определения двух соседей слева и двух справа;
- европейский порядок номеров рулетки;
- алгоритм расчёта суммы ставки соседей;
- кратность соседей;
- визуальное расположение ставок;
- алгоритмы экзаменационных вопросов.

Изменить только связь генерации ставок соседей с выбором выигрышного номера.

# Обязательные тесты

Проверить минимум:

1. Ставок соседей нет — выигрышный номер выбирается по прежним правилам.

2. Есть одна ставка соседей — она всегда играет.

3. Есть две непересекающиеся ставки соседей — играет ровно одна из них.

4. Есть две пересекающиеся ставки — может сыграть одна или обе.

5. Есть несколько ставок соседей — минимум одна всегда играет.

6. При нескольких ставках не требуется, чтобы сыграли все.

7. Выигрышный номер всегда входит в объединённое покрытие ставок соседей.

8. Покрытие корректно рассчитывается на границе порядка колеса.

9. Соседи номера 0 корректно обрабатываются.

10. Повторяющиеся номера в объединённом списке не создают ошибку.

11. Соседи одновременно с комплитом дюжины — выигрышный номер удовлетворяет обоим правилам.

12. Соседи одновременно с комплитом номера — выигрышный номер удовлетворяет обоим правилам.

13. При отсутствии общего допустимого номера запускается повторная генерация связанных ставок или всего раунда.

14. После генерации выполняется итоговая проверка, что сыграла хотя бы одна ставка соседей.

После выполнения кратко сообщи:

- как формируется множество допустимых выигрышных номеров для соседей;
- как обеспечивается выигрыш хотя бы одной ставки;
- почему при нескольких соседях могут сыграть одна или несколько ставок;
- как правило соседей объединено с другими зависимостями выигрышного номера.
