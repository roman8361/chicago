Для вопроса:

«Посчитайте сдачу с пересечений ставок на треке со ставками на поле, без учета ставок „комплит“.»

необходимо затемнить только фишки ставок «комплит», расположенные на основном игровом поле.

Требования:

1. Не затемнять всё основное поле целиком.

2. Не затемнять трек.

Полностью яркими должны оставаться:

- ставки серий на треке;
- ставки «соседи номера» на треке;
- цифры и разметка трека;
- обычные ставки на основном поле;
- цветные фишки на поле;
- кэш-фишки;
- клетки, линии и цифры основного поля.

3. Затемнить только фишки, которые относятся к сгенерированным ставкам «комплит».

Это касается всех фишек конкретного комплита, размещённых на поле:

- straight;
- split;
- street;
- corner;
- six-line;
- специальных позиций с нулём;
- комплита дюжины, когда он присутствует.

4. Затемнение должно определяться по типу ставки, а не по координатам.

Нельзя затемнять все фишки, которые случайно находятся в тех же клетках.

Необходимо проверять принадлежность фишки к ставке «комплит», например:

- `source === "complete"`;
- `betGroup === "complete"`;
- `isCompleteBet === true`;
- `completeId != null`.

5. Затемнять следует только визуальное отображение фишек «комплит».

Не изменять:

- сумму ставки;
- расчёты;
- координаты;
- размеры;
- порядок фишек;
- данные игрового раунда;
- логику пересечений.

6. Для фишек «комплит» применить тот же уровень затемнения, который используется в остальных режимах Focus Mode.

Например:

opacity: COMPLETE_DIMMED_OPACITY;

или отдельный полупрозрачный тёмный слой непосредственно над каждой фишкой «комплит».

7. Не использовать общий overlay поверх основного поля, потому что он затемнит обычные ставки и разметку поля.

8. Если в одной позиции объединены обычная ставка и ставка «комплит», необходимо затемнить только визуальную часть, относящуюся к комплиту.

Если приложение хранит объединённую фишку как один объект, нужно разделить отображение по источникам ставки либо отрисовать отдельный затемнённый слой для суммы комплита.

9. Изменение должно применяться только для этого вопроса.

Для остальных вопросов текущие режимы затенения оставить без изменений.

Рекомендуемый отдельный режим:

focusMode = DIM_COMPLETE_BETS_ONLY;

Пример логики отображения:

const isDimmed =
    focusMode === DIM_COMPLETE_BETS_ONLY
    && chip.source === "complete";

Итоговый результат:

- весь трек остаётся полностью ярким;
- основное поле остаётся полностью ярким;
- обычные ставки на поле остаются яркими;
- затемняются исключительно фишки ставок «комплит»;
- пользователь визуально исключает комплиты из расчёта, но продолжает видеть пересечения ставок трека с обычными ставками на поле.
